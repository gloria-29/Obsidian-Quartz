# 纯文本生活组织法

## 概述

纯文本生活组织法是一种利用纯文本（.txt）文件进行个人信息与任务管理的方法。它凭借极简、强大、灵活和低门槛的特性，成为一种高效且"未来兼容"的个人组织方法。

## 核心优势

| 优势 | 说明 |
|------|------|
| **未来兼容** | .txt 格式通用，50 年后任何计算机都能读取 |
| **速度轻量** | 几乎不占空间，打开极快，无加载时间 |
| **全平台** | 所有设备都支持读写 .txt 文件 |
| **无限灵活** | 完全控制权，可根据思维设计系统 |
| **无依赖** | 不依赖任何商业软件 |

## 三种核心方法

### 方法一：单一大型文本文件法 (OBTF)

将所有笔记、任务和想法记录在一个不断增长的文件中。

**结构示例：**
```plaintext
# Log

2025-09-12
- Note: 主题演讲很成功，需要给团队发后续邮件
- Task: 打电话给修车厂询问维修状态 @事务
- Idea: 能否在第四季度报告中使用新分析工具？ #项目A

2025-09-11
- Task: 回家路上买菜 #事务
- Note: 和 @李四 讨论了服务器迁移计划 #项目A
```

**关键技巧：**
- 日期戳格式：`YYYY-MM-DD`
- 标签系统：`#项目`、`@人物`、`+类型`
- 定期回顾：利用 `Ctrl+F` 搜索特定条目

### 方法二：基于 todo.txt 的多文件系统

为不同用途创建专用文件：

| 文件 | 用途 |
|------|------|
| `inbox.txt` | 临时收件箱 |
| `todo.txt` | 主任务清单 |
| `projects.txt` | 项目笔记 |
| `calendar.txt` | 未来约会 |
| `done.txt` | 已完成任务 |
| `notes.txt` | 通用参考 |

**todo.txt 核心语法：**
```plaintext
x 2025-09-12 2025-09-10 完成季度预算提案 +财务 @工作
(A) 2025-09-10 打电话给修车厂 @事务 due:2025-09-15
(B) 2025-09-11 搜索12月会议航班 +旅行
```

- `x` 表示已完成
- `(A)` `(B)` 表示优先级
- `+项目名` 标记项目
- `@情境名` 标记情境
- `due:YYYY-MM-DD` 截止日期

### 方法三：混合系统

结合前两种方法的优点：
- 使用 OBTF 作为"收件箱"
- 定期整理到 todo.txt 等专用文件
- 保持灵活性的同时增加结构性

## 与其他系统的对比

| 维度 | 纯文本 | [[Obsidian]] | Notion | Todoist |
|------|--------|--------------|--------|---------|
| **依赖** | 无 | 软件 | 服务 | 服务 |
| **格式** | .txt | .md | 专有 | 专有 |
| **速度** | 极快 | 快 | 中 | 中 |
| **灵活** | 极高 | 高 | 中 | 低 |
| **学习** | 极低 | 中 | 中 | 低 |

## 云同步方案

- **Dropbox**: 跨设备同步
- **Google Drive**: 免费 15GB
- **OneDrive**: Windows 集成
- **Git**: 版本控制和备份

## 使用场景

1. **任务管理**: 每日待办和项目跟踪
2. **日记记录**: 快速记录想法和事件
3. **知识收集**: 碎片化信息整理
4. **项目规划**: 项目目标和步骤
5. **习惯追踪**: 简单的习惯记录
