# AI驱动的书籍知识图谱

## 概述

AI驱动的书籍知识图谱是一种利用AI技术将电子书转换为交互式知识图谱的完整工作流程。它涵盖了从环境准备到最终发布的完整流程，支持EPUB、PDF、TXT等格式，生成可在[[Obsidian]]中浏览的知识库。

## 工作流程

```
电子书 (EPUB/PDF/TXT)
    ↓ 格式转换
AI知识解析 (Gemini CLI)
    ↓ 宏观分析
生成任务清单 (todo.md)
    ↓ 节点填充
批量处理知识节点 (10-50个/批)
    ↓ 双向链接
自动建立 [[wikilinks]]
    ↓ 文件整理
知识库目录结构
    ↓ 发布
Obsidian / Quartz / GitHub Pages
```

## 核心组件

| 组件 | 用途 |
|------|------|
| **MinerU** | PDF 智能解析工具 |
| **BookTools** | 自定义书籍处理工具链 |
| **Gemini CLI** | AI 交互接口 |
| **Obsidian** | 本地知识库浏览 |
| **Quartz** | 在线发布框架 |

## 格式转换

| 格式 | 工具 | 说明 |
|------|------|------|
| **EPUB** | BookTools | 一键转换 |
| **PDF** | MinerU | 智能解析 |
| **TXT** | 直接使用 | 无需转换 |

## AI 知识解析工作流

### 第一阶段：宏观分析
- 全书结构分析
- 生成任务清单 (todo.md)
- 创建宏观蓝图文件

### 第二阶段：节点填充
- 批量处理知识节点（每次 10-50 个）
- 自动建立双向链接
- 实时更新任务状态

### 第三阶段：文件整理
- 自动分类整理生成的文件
- 创建完整的知识库目录结构
- 提供备份文件管理

## 目录结构

```
书籍名称/
├── wiki/                    # AI 处理文件
│   ├── 书籍名称.md          # 完整内容
│   ├── 书籍名称-宏观蓝图.md # 结构分析
│   ├── todo.md              # 任务记录
│   └── GEMINI.md            # AI 模板
└── backup/                  # 备份文件
    ├── 书籍名称.md          # 原始内容
    └── ...
```

## 发布选项

### 本地使用
- [[Obsidian]]: 支持双向链接、图谱视图、全文搜索
- 直接在本地知识库中浏览

### 在线发布
- Quartz 框架部署
- 支持 GitHub Pages、Vercel、Netlify
- 自动生成静态网站

## 核心优势

| 优势 | 说明 |
|------|------|
| **自动化** | 从格式转换到知识提取全自动 |
