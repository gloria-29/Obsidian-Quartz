# Grok

> xAI 推出的 AI 模型，深度集成 X (Twitter) 平台，擅长 X List 总结、语义搜索和定时任务自动化。

## 核心特点

- 可直接读取任意公开推文内容，包括引用、回复、父帖、子回复及完整线程
- 支持 X 高级搜索运算符（from: since: until: min_faves: 等），用中文描述即可调用
- 支持语义搜索（Semantic Search），理解意思而非关键词匹配
- 可深度分析用户画像：通过发帖时间+内容推断作息、性格倾向、情绪基调
- 支持 X 视频逐帧+字幕深度解析
- 可自动汇总指定 X List 信息流，省去手动翻页

## Grok Tasks 功能

- 在 tasks.grok.com 创建定时任务，每天/每周自动跑 X 查询
- 结果摘要推送到邮箱或通知，实现"躺着看热点"
- 典型用例：每日早上8点自动收到"昨天 AI 领域最大进展"精选摘要
- 适合信息猎手：可批量筛选指定账号过去24小时互动量最高的帖子
