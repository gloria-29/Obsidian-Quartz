# Codex (OpenAI Coding Agent)

## 概述

Codex 是 OpenAI 推出的 AI 编程代理，基于 Codex 模型（GPT-4 系列优化版本）。它与 [[Claude Code]] 类似，但由 OpenAI 开发，专注于代码生成、调试和项目管理。Codex 提供了独特的 Prompt Lab 功能，可用于非编程场景如图像生成。

## 核心功能

| 功能 | 说明 |
|------|------|
| **代码生成** | 根据自然语言描述生成代码 |
| **代码理解** | 分析和解释现有代码 |
| **调试** | 识别和修复代码错误 |
| **项目管理** | 创建和管理项目文件 |
| **Prompt Lab** | 非编程场景的提示词实验 |
| **多语言支持** | Python, JavaScript, TypeScript 等 |

## Prompt Lab 功能

Prompt Lab 是 Codex 的特色功能，允许用户在非编程场景中使用：

### 自动生成生活照片
根据源文献，Prompt Lab 可以：
- 根据描述生成高质量生活照片
- 支持多种风格和场景
- 可调整参数如光线、构图、色调
- 适合社交媒体内容创作

### 使用示例
```
Prompt: "一个阳光明媚的午后，咖啡馆窗边，一杯拿铁，一本打开的书"
→ 生成符合描述的生活照片
```

## 与 Claude Code 的对比

| 维度 | Codex | Claude Code |
|------|-------|-------------|
| **开发商** | OpenAI | Anthropic |
| **基础模型** | GPT-4 系列 | Claude 系列 |
| **优势** | Prompt Lab, 生态集成 | 深度代码理解, MCP 支持 |
| **价格** | 按 token 计费 | 按 token 计费 |
| **特色** | 非编程场景应用 | 事件驱动 Hook 系统 |

## 使用场景

1. **代码开发**: 快速生成和调试代码
2. **内容创作**: 使用 Prompt Lab 生成图像
3. **学习辅助**: 理解和解释代码逻辑
4. **自动化**: 集成到 CI/CD 流程

## 局限性

- 需要 OpenAI API 密钥（付费）
- 复杂项目可能需要多次交互
- 对特定框架的支持可能不完善
- 网络访问受限
