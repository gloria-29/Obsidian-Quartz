# Crawl4AI

> GitHub 47K+ Stars的开源LLM友好型Web爬虫，输出干净Markdown，专为RAG管线优化。

## 核心特性

- **LLM友好输出**：生成干净的Markdown格式，适合RAG管线
- **Playwright驱动**：支持Chromium/Firefox/WebKit无头浏览
- **FastAPI服务**：Docker部署提供RESTful API
- **BM25启发式过滤**：从爬取内容中提取核心信息
- **支持排除/包含模式**：CSS选择器精确控制爬取范围

## 使用场景

- 为AI研究系统提供结构化网页数据
- 批量爬取特定主题文章
- 构建个人知识库的网页内容获取层
