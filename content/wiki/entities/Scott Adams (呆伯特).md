# Scott Adams (呆伯特创作者)

## 概述

史考特·亚当斯（Scott Adams）是漫画《呆伯特》（Dilbert）的创作者，通过幽默讽刺的方式揭示现代职场中的荒诞、无效管理以及员工心理变化。《呆伯特》被翻译成 19 种语言，在 57 国超过 2000 份报刊连载。

## 核心观点

| 观点 | 说明 |
|------|------|
| **职场本质是"笨蛋加工厂"** | 工作使理性的人变得荒诞 |
| **幽默是职场压力的释放阀** | 把员工的沉默抱怨转化为可共鸣的笑点 |
| **技术革命呈钟摆式周期** | 新技术→热情→泡沫破裂→情绪回落 |
| **工作表现与晋升基本无关** | 顿悟后感到"解放" |

## 《呆伯特》经典人物

| 人物 | 特点 |
|------|------|
| **Pointy-Haired Boss (PHB)** | 秃顶、不懂技术却爱发号施令的无能上司 |
| **狗伯特** | 刻薄的狗，一针见血指出职场真相 |
| **Exactly 同事** | 只会说"Exactly"，无实质贡献却被视为核心参与者 |
| **聪明女同事** | 能力出众却被忽视 |

## 时间线

| 年份 | 事件 |
|------|------|
| **1989** | 《呆伯特》正式连载于报纸 |
| **1995** | 成为全球第一个在互联网免费连载的漫画 |
| **2000** | 互联网泡沫破裂，职场情绪回落 |
| **2026** | 史考特·亚当斯逝世，享年 68 岁 |

## 作者个人经历

- 在银行和电话公司各工作八年
- 尝试攻读 MBA 却仍未获晋升
- 意识到工作表现与晋升无关后，转而全职创作漫画
- 经历婚姻失败、声带痉挛、晚期前列腺癌

## 文化影响

- 畅销书《呆伯特法则》销量超千万
- 管理学术语中出现 "PHB"，用于研究无能管理者
- 典型情景（无效会议、假装忙碌）成为职场语言的一部分
