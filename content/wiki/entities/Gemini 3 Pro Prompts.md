# Gemini 3 Pro Prompts

## 概述

Gemini 3 Pro Prompts 是一组精选的 AI 提示词集合，展示了 Gemini 3 Pro 在多模态理解、高复杂度代码生成（特别是前端和 3D 交互）以及文化主题应用快速原型设计方面的强大能力。

## 核心能力

| 能力 | 说明 |
|------|------|
| **多模态理解** | 图像、文本、代码的统一理解 |
| **3D 渲染** | Three.js、GLSL 着色器、WebGL |
| **前端开发** | HTML/CSS/JavaScript 单文件生成 |
| **物理模拟** | 齿轮系统、流体、粒子 |
| **教育可视化** | SVG 动画、交互式演示 |

## 提示词分类

### 1. 高级 3D 渲染与图形编程
- **奢华 3D 腕表产品体验页面**: Next.js, Three.js, React Three Fiber, GLSL
- **音频响应 Mandelbulb 分形**: 光线步进、12,000 个实例化粒子
- **3D 积木应用**: 类似 Minecraft 的 3D 砖块搭建环境
- **Three.js 博物馆漫游场景**: 第一人称 3D 环境
- **3D 魔方网页应用**: 可打乱、自动求解和手动操作

### 2. 网站原型设计与 UI/UX 风格
- **新粗野主义网站设计**: 突破界限、流畅滚动、鲜艳色彩
- **未来主义加密货币仪表盘**: 深色模式、玻璃拟态、霓虹光效
- **高端瑞士风格着陆页**: 瑞士现代、Bento 布局
- **AI 游戏未来感着陆页**: 大量动画、未来科技感

### 3. 创新交互式 Web 应用
- **复古宝丽来相机应用**: 实时摄像头、照片冲印动画
- **复古摩托罗拉寻呼机打字机**: 寻呼机缓慢打出卡片
- **类 Word 富文本编辑器**: 单 HTML 文件实现 Word 功能

### 4. 教育与科学可视化
- **动态点云狭义相对论网页**: 点云效果解释相对论
- **特斯拉 FSD 道路识别**: SVG 动态绘制 FSD 识别过程
- **多级齿轮联动系统动画**: 精确展示机械驱动链
- **电容式触摸屏原理动画**: 教育性技术原理动画

### 5. 文化及垂直主题应用
- 中国传统文化主题应用
- 生活场景融入应用设计
