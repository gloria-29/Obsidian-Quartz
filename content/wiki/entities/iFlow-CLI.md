# iFlow CLI

> 终端运行的 AI 编程助手，分析代码仓库、执行编程任务、理解上下文，支持免费模型和 MCP 服务器。

## 核心特点

- 终端原生运行，分析代码仓库并执行编程任务
- 免费模型支持：Kimi K2、Qwen3 Coder、DeepSeek v3 等
- 预配置 MCP 服务器和专业代理
- 支持自然语言驱动开发
- 类似 [[Claude Code]] 的终端 AI 编程体验
