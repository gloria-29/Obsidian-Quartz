# iFlow CLI

## 概述

iFlow CLI 是一款直接在终端中运行的 AI 编程助手，能够分析代码仓库、执行编程任务、理解上下文需求。它提供多种免费 AI 模型选择（Kimi K2、Qwen3 Coder、DeepSeek v3 等），预配置了 MCP 服务器和专业代理，支持自然语言驱动开发。作为终端原生的 AI 编程工具，它与 [[Claude Code]]、[[Codex (OpenAI Coding Agent)]] 等工具处于同一赛道，但以免费模型的差异化定位吸引开发者。

## 核心功能

### 功能特点
- **终端原生运行**：直接在 CLI 中理解项目上下文、读取文件、编写代码
- **免费模型支持**：Kimi K2、Qwen3 Coder、DeepSeek v3 等多种免费模型可选
- **预配置 MCP 服务器**：开箱即用的 MCP 集成，无需手动配置
- **专业代理**：预置针对不同开发场景的代理配置
- **自然语言驱动**：用自然语言描述需求，AI 自动完成编码任务
- **代码仓库分析**：理解项目整体结构和代码逻辑
- **跨平台支持**：Windows/macOS/Linux 均可运行

### 使用场景
- **快速原型开发**：用自然语言描述需求快速生成代码
- **代码审查和重构**：分析和优化现有代码
- **Bug 修复**：描述问题，AI 定位并修复
- **文档生成**：自动生成代码文档和注释
- **学习辅助**：通过 AI 交互理解代码原理

## 关键概念

- **AI 编程助手**：利用大语言模型辅助编程的 CLI 工具
- **MCP 集成**：通过 Model Context Protocol 扩展工具链
- **免费模型差异化**：区别于 Claude Code 等付费工具的免费开源模型支持
