# Gemini

## 概述

Gemini 是 Google 的旗舰 AI 模型系列，深度嵌入 Google 的各个产品和服务。从 Gemini 2.5 Flash/Pro 到 Gemini 3.0 Pro，持续在多模态理解、代码生成、AI Agent 等领域突破。Gemini 提供 AI Studio（免费使用）、Gemini CLI（支持 MCP）、Google One AI Premium 订阅等多种使用方式。

## 重要版本

- **Gemini 2.5 Flash Image Preview**：即 Nano Banana 图像编辑模型，具备图像生成和编辑能力
- **Gemini 2.5 Pro**：高性能主力模型，用于 SEO Agent、AI Agent、代码生成等场景，具有 100 万 tokens 上下文窗口
- **Gemini 3.0 Pro**：新一代多模态模型，支持文本、图像、音频、视频同时处理，被李继刚用于 AI 诤友等创意应用
- **Gemini CLI**：命令行接口，原生支持 MCP（Model Context Protocol）配置

## 生态

### 使用方式
- **AI Studio**：免费测试平台，适合开发者快速实验 Gemini 能力
- **Google One AI Premium**：订阅制（$19.99/月），解锁最强模型和 2TB 存储
- **土区 Workspace 方案**：土耳其区 Google Workspace 年付仅约 280 元，获取 Gemini Advanced
- **Gemini CLI**：终端使用，支持 MCP 协议连接外部工具
- **Gemini API**：直接 API 调用，付费 tier 有更高配额

### 核心能力
- **多模态理解**：文本、图像、音频、视频的同时理解与推理
- **代码生成**：Three.js、GLSL、3D 渲染等高级代码生成
- **AI Agent**：通过 Gem 定制功能创建自定义 Agent（如时序管家 Chronos Butler）
- **MCP 协议**：Gemini CLI 和 API 原生支持 MCP
- **Google I/O 2026**：Gemini 成为 Google 所有产品的核心 AI 引擎

## 关键概念

- **Gem（定制对话）**：Gemini 平台的自定义 Agent 功能，可设定角色、指令集和交互规则
- **AI Studio**：Google 的 AI 模型实验平台，免费使用 Gemini 系列模型
- **食物噪音抑制**：Gemini 在健康管理中的应用方向之一
