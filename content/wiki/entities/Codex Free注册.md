# Codex Free 注册方法

## 概述

Codex Free 注册是一种免费使用 [[Codex (OpenAI Coding Agent)]] 的方法，通过虚拟电话号码（VOIP）绑定 OpenAI 账号，实现 0 元接码注册。

## 核心发现

| 发现 | 说明 |
|------|------|
| **VOIP 检测弱** | OpenAI 对虚拟号码的检测力度很弱 |
| **成功率高** | 测试 5 个号码，4 个成功绑定 12 个账号 |
| **速度快** | 约 2 分钟绑定一个账号 |
| **成本低** | 使用免费虚拟号码服务 |

## 注册步骤

### 1. 准备工作
- 美国 IP 地址（推荐家宽或干净 IP）
- Outlook 邮箱（可创建别名）
- 虚拟号码服务（TextNow 或 TextFree）

### 2. 注册虚拟号码

#### TextNow 注册
1. 手机在美国/加拿大代理下注册
2. 把手机时间调到美国时间（时区匹配梯子）
3. Google 账号直接点击进入
4. 填写电话区号（选冷门地区，避免豹子号）

#### TextFree 注册
- 逻辑类似 TextNow
- 同样需要美国/加拿大代理

### 3. 绑定 OpenAI 账号
1. 注册或登录 OpenAI 账号
2. 在添加手机号时输入虚拟号码
3. 接收验证码完成绑定
4. 一个手机号可绑定 3 个 OA 账号

### 4. 批量注册
- Outlook 邮箱创建别名（1 个邮箱 = 3 个别名）
- 退出登录，手搓新的虚拟号码账号
- 重复绑定流程

## 注意事项

| 注意点 | 说明 |
|--------|------|
| **IP 干净** | 万人骑 IP 有概率不通过 |
| **冷门地区** | 别选热门地区的号码 |
| **别扭号码** | 选不顺眼的数字，被使用过的几率低 |
| **适度使用** | 不要竭泽而渔，注册几个够用即可 |
| **二级权限** | 帖子上了二级权限保护 |

## 虚拟号码服务

| 服务 | 说明 |
|------|------|
| **TextNow** | 美国/加拿大虚拟号码 |
| **TextFree** | 类似 TextNow |
| **其他** | App Store/Google Play 里有很多类似服务 |

- 适合个人开发者和学习者
