# obsidian-to-notionnext-batch

## 概述

obsidian-to-notionnext-batch 是一个 [[Obsidian]] 插件，可以将 Obsidian 笔记批量发布到 Notion。它支持自定义模板和样式，保持 Markdown 格式和链接，适合博客和知识库发布。

## 核心功能

| 功能 | 说明 |
|------|------|
| **批量发布** | 一次性发布多个笔记到 Notion |
| **格式保持** | 保持 Markdown 格式和链接 |
| **自定义模板** | 支持自定义发布模板 |
| **样式设置** | 可配置发布样式 |

## 使用场景

1. **博客发布**: 将 Obsidian 笔记发布为博客
2. **知识库同步**: 将本地知识库同步到 Notion
3. **团队协作**: 与团队共享笔记内容
4. **内容分发**: 多平台内容分发

## 配置步骤

1. 安装插件
2. 配置 Notion API Token
3. 选择目标数据库
4. 设置发布模板
5. 选择要发布的笔记
6. 执行批量发布

## 与其他工具的对比

| 维度 | obsidian-to-notionnext | Notion 原生 | [[Obsidian]] Publish |
|------|----------------------|-------------|---------------------|
| **批量** | 支持 | 不支持 | 不支持 |
| **格式** | Markdown | 专有 | Markdown |
| **价格** | 免费 | 免费/付费 | 付费 |
