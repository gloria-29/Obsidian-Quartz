# 即梦 (Jimeng) AI图像生成

## 概述

即梦（Jimeng）是字节跳动推出的 AI 图像生成工具，最新版本 4.0 模型在图像质量和生成速度上都有显著提升。本文档提供了即梦 4.0 模型的提示词手册，帮助用户更好地使用该工具。

## 核心功能

| 功能 | 说明 |
|------|------|
| **文生图** | 根据文字描述生成图像 |
| **图生图** | 基于参考图像生成新图像 |
| **风格迁移** | 将图像转换为指定风格 |
| **高清放大** | 提升图像分辨率 |

## 提示词技巧

### 1. 基础结构
```
[主体] + [风格] + [环境] + [光线] + [质量]
```

### 2. 风格关键词
- 写实风格: `realistic, photo, 8k, detailed`
- 动漫风格: `anime, manga, cel shading`
- 油画风格: `oil painting, impressionist`
- 水彩风格: `watercolor, soft edges`

### 3. 质量提升词
- `masterpiece` — 杰作
- `best quality` — 最佳质量
- `highly detailed` — 高度详细
- `professional` — 专业级

## 使用场景

1. **社交媒体**: 生成配图和封面
2. **设计工作**: 快速生成设计原型
3. **创意探索**: 探索不同的视觉风格
4. **内容创作**: 为文章和视频生成配图
