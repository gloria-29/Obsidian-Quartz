# 冰岛冬季旅行规划

## 概述

这是一个针对预算 30,000 RMB 的单人冬季冰岛 11 日半自助旅行规划（2026年1-2月）。以雷克雅未克为主要基地，通过预订当地分日导览团完成主要景点游览。

## 预算分解

| 类别 | 预算 (RMB) | 占比 | 说明 |
|------|-----------|------|------|
| 往返机票 (PEK-KEF) | 7,000 | 23.3% | 提前 6-9 个月预订 |
| 住宿 (9晚) | 7,200 | 24.0% | 青旅/民宿私人房间 |
| 核心长途团 | 5,100 | 17.0% | 2日南岸&蓝冰洞 |
| 其他导览团 | 2,400 | 8.0% | 黄金圈/熔岩/极光 |
| 餐饮及杂项 | 7,700 | 25.7% | 大量自炊 |
| 机场接送 | 450 | 1.5% | 巴士接送 |
| **总计** | **30,000** | **100%** | |

## 三大冬季主题

1. **北极光** — 专业导览团最大化机会，建议预算两次
2. **冰川地貌** — 蓝冰洞、冰河湖
3. **火山地质** — 黄金圈、熔岩隧道

## 关键建议

- **冬季装备**: 防水防风三层穿衣系统，保暖登山靴，便携充电宝
- **北极光**: 不可控，但专业导览团最大化机会
- **交通**: 冬季不推荐自驾，选择定点导览团
- **餐饮**: Bónus 超市自炊是省钱关键
- **预订优先级**: 机票 > 2日南岸蓝冰洞团 > 其他
