# LINUX DO

## 概述

LINUX DO（linux.do）是一个以技术为主题的社区论坛，以互助氛围好、技术干货密度高、资源更新及时著称。论坛涵盖从服务器部署、科学上网、AI 工具到开发资源等广泛的技术话题，是中文技术社区中重要的信息集散地和福利资源分享平台。

## 核心内容

### 常见板块
- **部署教程**：Serv00、HuggingFace、Cloudflare Workers、科学上网、Oracle Cloud 等
- **工具推荐**：虚拟信用卡、接码平台、免费 VPN、虚拟主机
- **AI 相关**：DeepSeek、Grok 提示词、MCP 协议入门、LLM API 资源
- **福利资源**：L 站福利项目信息汇总、破解软件库、免费 API Key 共享
- **开发调优**：Windows/VSCode 教程、Docker 优化、服务器运维
- **翻译相关**：AI 检测写作、翻译智能体、双语工具

### 特色资源
- **AI 公益站汇总**：Gemini API 共享池、CloseAI API、DeepSeek API 等免费/低价 AI 资源
- **Claude Code 教程**：Windows/VSCode 下使用、Docker 化代理、接入 Gemini 1M 上下文
- **用户等级体系（Lv0-Lv3）**：不同等级访问不同资源，激励社区贡献

## 关键概念

- **社区互助**：成员之间大规模共享资源和经验
- **AI 资源公益化**：通过逆向工程和开源工具降低 AI 工具使用门槛
- **用户等级**：基于贡献的分级访问体系
