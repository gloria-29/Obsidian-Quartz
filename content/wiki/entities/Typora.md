# Typora

## 概述

Typora 是一款极简风格的 Markdown 编辑器，以"所见即所得"（WYSIWYG）的编辑体验著称。区别于传统的分屏双栏编辑器，Typora 将编辑和预览合二为一，击键即渲染，提供流畅的无干扰写作体验。通过社区插件（如 obgnail/typora_plugin）可大幅扩展功能，使其成为知识工作者的强大写作工具。

## 核心功能

### 功能特点
- **所见即所得**：输入 Markdown 语法即可实时渲染，无需切换编辑/预览模式
- **极简界面**：无工具栏、无侧边栏干扰，专注写作本身
- **主题系统**：支持自定义 CSS 主题，可高度个性化编辑界面
- **多种输出格式**：支持导出为 PDF、HTML、Word、LaTeX、EPUB 等
- **图片管理**：支持自动上传图片到图床，插入即发布
- **大纲视图**：内置文档导航，快速跳转到任意标题
- **聚焦模式**：可高亮当前段落，淡化其余内容
- **数学公式**：原生支持 LaTeX 数学公式渲染
- **流程图支持**：支持 Mermaid 图表渲染

### 使用场景
- **技术写作**：程序员的技术博客、文档编写
- **学术写作**：论文草稿、LaTeX 导出
- **笔记记录**：课堂笔记、会议记录
- **博客发布**：作为 Markdown 源文件编辑器，配合 Hexo/Hugo/VitePress 等发布
- **阅读模式**：直接阅读 Markdown 文件

## 关键概念

- **所见即所得（WYSIWYG）**：编辑时实时渲染最终效果，所见即所得
- **社区插件**：通过 obgnail/typora_plugin 等插件扩展 Typora 的 Markdown 编辑能力
- **配置即代码**：Typora 主题和设置通过 CSS/JSON 文件管理
