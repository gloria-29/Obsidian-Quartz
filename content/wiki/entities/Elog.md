# Elog

> 开放式跨平台博客同步 CLI 工具，支持从多种写作平台批量导出 Markdown 并发布到主流博客框架。

## 核心特点

- 支持从语雀、Notion、FlowUs、飞书等写作平台批量导出为 Markdown
- 支持同步到 Hexo、VitePress、Hugo 等静态博客框架
- 支持直接发布到 Halo、WordPress、Confluence
- 内置图床支持：本地、腾讯云 COS、阿里云 OSS、七牛云、又拍云、GitHub
- 支持 GitHub Actions + Webhooks + Pipeline 持续集成自动化
