# GLP-1 Girl（Nyk | The GLP1 Girl Code）

> YouTube 频道"The GLP1 Girl Code"的创作者 Nyk（又称 Nikki），以亲身经历分享使用 GLP-1 药物减重的真实体验、副作用管理与心理调适。她从最高体重 277 磅（用药时为 258 磅）减重超过 95 磅，其核心理念是"药物是工具，而非魔法"，最终目标是帮助女性实现精神解放和可持续的健康生活。

## 个人减重历程

| 指标 | 数值 |
|------|------|
| 起始时间 | 2023年3月（实为2022年3月） |
| 起始体重 | 258 磅（约 117 公斤） |
| 历史最高体重 | 277 磅（约 125.6 公斤） |
| 当前体重 | 181 磅 |
| 总减重（药物辅助） | 约 75-80 磅 |
| 相对最高体重总减重 | 约 95 磅 |

### 减重阶段

1. **初始阶段（司美格鲁肽）**：前6个月减重约40磅，第一个月减重近9磅。副作用：腹泻和硫磺嗝
2. **过渡阶段（替西帕肽）**：9个月后转换，精力提升但减重放缓，约两年减掉40磅
3. **平台期**：180磅区间遭遇数月体重停滞，曾尝试非处方GLP-1滴剂导致反弹14磅

## 核心理念

### 药物是工具，不是魔法

GLP-1 药物的核心作用是"平息食物噪音"，为行为改变创造心理空间。药物本身不直接燃烧脂肪，真正起作用的依然是热量缺口。使用者必须主动参与——控制饮食、坚持运动。

### 精神解放是最大的胜利

Nyk 反复强调，体重减轻虽显著，但药物带来的最大益处是**消除"食物噪音"**——持续不断对食物的渴望和思考。这种解放提供了前所未有的精神空间，使其能够专注于工作、家庭和生活目标。

### 一致性优于完美

不必追求每天都严格遵守计划。即使偶尔放纵，第二天立即回到正轨，避免"全有或全无"的节食心态。进步来自于持续，而非完美。

## 关键概念

| 概念 | 定义 |
|------|------|
| **食物噪音 (Food Noise)** | 大脑中持续存在的侵入性食物念想，与生理饥饿脱节 |
| **最低有效剂量 (LED)** | 能控制食物噪音、减重且副作用可控的最低剂量 |
| **非体重成就 (NSV)** | 与体重数字无关的积极变化：精力增加、衣服尺码变小、自信心提升 |
| **20% 法则** | 临床上成功减重通常指减去初始体重的15-20% |
| **分次给药** | 将单次剂量分两次注射以管理副作用 |
| **微量给药** | 在标准剂量间微调，缓慢爬升 |

## 核心策略

### 1. 药物策略
- 严格遵循"最低有效剂量"原则
- 剂量升级标准：体重连续停滞约四周 且 食物噪音回归
- 为度假等生活事件可暂时中断用药
- 结论："司美格鲁肽和替西帕肽一样好"，个体反应存在差异

### 2. 营养策略
- **蛋白质优先**：每日目标 90-100 克，即使不饿也主动摄入
- **不放弃喜欢食物**：仍吃披萨和快餐，药物提供份量控制（以前能吃一整盒披萨，现在吃两片就够）
- **没有"作弊餐"概念**：吃蛋糕只是"过你的生活"
- **把饮水当"全职工作"**，并补充电解质

### 3. 副作用管理——将不适视为"反馈"

| 副作用 | 根本原因/信号 | 应对 |
|--------|-------------|------|
| **全身性疲劳** | 能量不足/营养缺乏/水合不足 | 补充B12和L-甲基叶酸，高蛋白早餐 |
| **腹泻与硫磺嗝** | 食物选择不当（高糖、油腻）或吃得太多太快 | 调整饮食，放慢进食速度 |
| **恶心** | 长时间空腹 | 醒来30分钟内进食高蛋白食物 |
| **便秘** | 消化蠕动减慢/缺乏纤维 | 每天服用纤维补充剂 |
| **食物噪音回归** | 药物效力不足或周期性饥饿 | 追踪周期，必要时谨慎增加剂量 |

### 4. 心理调适
- **区分生理饥饿与情绪性进食**：药物创造了"暂停键"，但情绪性饥饿需要自己治愈
- **应对平台期**：将焦点从体重秤转移到非体重成就 (NSVs)
- **身体意象障碍**：快速减重导致心理认知脱节
- **摆脱节食文化**：摒弃"惩罚性饮食"观念

### 5. 社区力量
Nyk 创建了免费社区"Her Glow Era"和付费会员社区"The GLP1 Girl Code"，提供情感支持、经验分享、问责制和共同庆祝。她评价："拥有一个社群让我的 GLP-1 旅程轻松了10倍。"

## "五月挑战"五大习惯

为突破平台期发起的挑战：
1. **每天吃早餐**（特别是高蛋白早餐）
2. **每周锻炼至少三次**（力量训练优先）
3. **摄入足量蛋白质**（每日 90-100 克）
4. **全面追踪**（使用 ChatGPT 和 PEP App）
5. **每周称重一次**（避免每日称重带来的心态波动）

## 非体重成就 (NSVs) 具体体现

- **身体机能**：轻松系鞋带、用浴巾完全包裹自己、舒适坐进飞机座位、陪孩子奔跑
- **服装尺寸**：从 24 码降至 10 码
- **健康指标**：A1C 和胆固醇水平下降，脱离糖尿病前期
- **自信心**：敢于穿泳衣、拍照，学会说"不"
- **心理健康**：摆脱深度抑郁，"食物噪音"的消除是长期坚持的最大动力

## 长期管理视角

### 将肥胖视为慢性疾病
Nyk 认为肥胖和食物噪音可能是一种**慢性脑部疾病**，GLP-1 药物可能需要长期甚至终身使用，类似于治疗焦虑或抑郁症的药物。停药后食物噪音和体重反弹的经历强化了她的这一信念。

### 响应者差异
- **快速响应者**与**慢速响应者**均属正常，无优劣之分
- 最终结果可能趋同，不必因初期减重速度慢而气馁
- 社交媒体上的\"独角兽故事\"不代表普遍经验

### 药物获取途径
- **品牌药**：Wegovy（司美格鲁肽）、Zepbound（替西帕肽）
- **复方药物**：由持牌药房根据医生处方配制，使用与品牌药相同的活性成分，合法但未经 FDA 批准，通常更具成本效益
- **远程医疗**：如 Amble（司美格鲁肽起价$135/月，替西帕肽$289/月）
- **GLP-1 滴剂**：作为注射替代方案，但效果可能不如注射

### 蛋白质摄入小窍门
- 无糖果冻粉加蛋白粉
- 高蛋白奶昔
- 火腿/火鸡片包裹芝士棒
- 即使不饿也要主动摄入，维持能量和肌肉量

### 运动的角色演变
- 减重初期几乎不需要运动来启动减重
- 运动在体重下降、身体机能改善后作为追求更健康生活方式的补充手段
- 后期每周三次力量训练
- 运动是突破平台期和长期维持的关键
