# LINUX DO 社区

## 概述

LINUX DO（L站）是一个活跃的技术社区，专注于 AI 工具、开源项目和免费资源分享。社区提供了大量 AI 服务的使用教程、绕过限制的方法以及自建方案，是获取最新 AI 工具信息的重要来源。

## 核心 AI 服务

### 1. Gemini CLI
- Windows/Mac/Linux 配置教程
- 登录失败解决方案
- Deno 部署方案
- MCP 集成（如查询 [[Obsidian]] 笔记）

### 2. Claude Code
- Windows 和 VSCode 使用教程
- API 免费调用方案
- Docker 化代理和中转方案
- 接入 Gemini 1M 上下文

### 3. AugmentCode
- 无限邮箱重置
- 插件重置脚本
- 自动注册脚本
- AURA-X 协议提示词库

### 4. Cursor
- 教育邮箱白嫖 Pro 版
- MCP 次数倍增（500 次抵 2500 次）
- 内置规则和提示词优化
