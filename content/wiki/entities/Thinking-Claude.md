# Thinking-Claude

## 概述

Thinking-Claude 是由一名 17 岁高中生开发的开源提示词项目（GitHub: richards199999/Thinking-Claude），旨在让 Claude 在回答前进行结构化深度思考，显著提升其推理能力。该项目在 GitHub 和 AI 社区中获得了广泛关注，是提示词工程领域"让模型自我思考"范式的早期代表。

## 核心功能

### 核心理念
- **强制深度思考**：通过在提示词中引导 Claude 在最终回答前展示完整的推理过程
- **结构化推理**：将复杂问题分解为清晰的思考步骤
- **自我验证**：每一步推理后进行逻辑自检
- **透明度**：让用户可见 AI 的思考过程，增加可信度
- **零成本提升**：无需额外 API 调用，仅通过提示词设计优化回答质量

### 技术特点
- **纯提示词方案**：不依赖模型 API 的额外参数或特殊功能
- **通用性**：适用于多种 Claude 模型版本
- **简洁实现**：提示词结构清晰，可被理解和修改
- **社区影响**：启发了一系列"思考提示词"的衍生作品

### 使用场景
- **复杂推理任务**：数学、逻辑、编程等需要多步推理的场景
- **分析与决策**：需要全面考虑多个因素的决策辅助
- **代码审查**：系统性分析代码问题
- **学习辅导**：展示解题思路和推理过程

## 关键概念

- **链式思考（Chain-of-Thought）**：引导模型逐步展示推理过程的提示技术
- **自我提问**：AI 在执行任务时对齐人进行内心对话式的自我质询
- **无参数优化**：仅通过提示词设计提升质量，不改变模型参数
