# memos

## 概述

memos 是一款隐私优先的轻量笔记/说说服务，开源项目。类似 Flomo 的自托管替代品，以其简洁轻量和丰富的生态系统获得开发者社区喜爱。围绕 memos 发展出了 cflow、Echo-Noise、memos.top、Memospot、MeowNocode 等多种衍生项目和工具。

## 核心功能

### 功能特点
- **隐私优先**：自托管部署，数据完全自主控制
- **轻量简洁**：类似说说（Twitter/微博风格）的笔记体验
- **开源生态**：GitHub 社区活跃，众多魔改和周边工具
- **API 开放**：提供 Memos API，支持第三方客户端和展示页接入
- **Markdown 支持**：完整的 Markdown 编辑和渲染
- **标签系统**：灵活的标签分类管理
- **多用户**：支持多用户独立使用

### 生态项目
- **cflow**：魔改版 memos（Vespa314/cflow），添加标签分类、阅读打卡、随机回顾、OSS/S3/R2 图床等功能
- **Echo-Noise**：基于 Ech0 的说说系统，Go+Vue 技术栈，支持多平台推送，可部署到 fly.io/zeabur/railway/vercel
- **memos.top**：静态展示页（eallion），纯 HTML/CSS/JS，兼容新旧版 API
- **Memospot**：桌面客户端，无需 Docker，Windows/macOS/Linux 支持
- **MeowNocode**：基于 Cloudflare Pages+D1 的无服务器方案

## 关键概念

- **自托管**：用户自行部署和维护，数据完全自有
- **魔改生态**：基于开源核心的深度定制衍生项目
- **说说式笔记**：以时间线为主的碎片化笔记体验
