# 电子书转思维导图

## 概述

电子书转思维导图是一种利用 AI 技术将电子书内容自动转换为结构化思维导图的工作流程。它可以帮助读者快速理解书籍结构、提取关键概念、建立知识网络。

## 工作流程

```
电子书 (EPUB/PDF/TXT)
    ↓ 内容提取
AI 分析 (结构/概念/关系)
    ↓ 知识提取
思维导图生成
    ↓ 可视化
Markdown/HTML/图片
```

## 核心步骤

### 1. 内容提取
- EPUB: 直接解析 XML
- PDF: 使用 OCR 或解析工具
- TXT: 直接读取

### 2. AI 分析
- 全书结构分析
- 章节关系识别
- 关键概念提取
- 知识点分类

### 3. 思维导图生成
- 层级结构构建
- 双向链接建立
- 标签分类
- 摘要生成

## 使用场景

1. **快速阅读**: 10 分钟理解一本书的结构
2. **知识整理**: 提取关键概念和关系
3. **复习回顾**: 通过思维导图快速复习
4. **分享交流**: 将书籍精华可视化分享

## 技术实现

### 工具链
- **内容提取**: Calibre、pypdf、epub2txt
- **AI 分析**: [[Claude Code]]、[[DeepSeek V4]]
- **思维导图**: Markmap、Mermaid、XMind
- **可视化**: [[Obsidian]]、浏览器渲染

### 示例代码
```python
# 使用 AI 提取书籍结构
import openai

def extract_book_structure(book_text):
    response = openai.chat.completions.create(
        model="deepseek-v4-pro",
        messages=[{
            "role": "user",
            "content": f"请分析以下书籍内容，提取章节结构和关键概念：

{book_text[:5000]}"
        }]
    )
    return response.choices[0].message.content
```
