# Alexey Guzey

> 俄罗斯裔博客写作者，以《Why You Should Start a Blog Right Now》一文闻名，倡导所有人都应该开始写博客。

## 核心特点

- 代表作《Why You Should Start a Blog Right Now》影响广泛，被多次翻译和引用
- 核心观点：即使觉得没什么可说的、即使没人读，也应该开始写博客
- 写作建议实用：从反复给朋友的建议、个人经历、反驳他人观点等角度切入
- 推荐"最危险的写作应用程序"练习法——不满意的初稿直接从头重写
- 强调写作是思考的工具，不是结果的展示
