# Buzzing

## 概述

Buzzing 是一个帮助中文用户浏览国外社交媒体和新闻热门讨论的聚合平台。它通过提供母语（中文）快速导读的方式，让用户能够迅速了解国外热点话题，并在感兴趣时深入阅读原文。平台汇集了来自 Hacker News、经济学人、彭博社、BBC、路透社等 30+ 权威来源的内容。

## 核心功能

| 功能 | 说明 |
|------|------|
| **多源聚合** | 30+ 国外权威媒体和社交媒体 |
| **中文导读** | 母语快速导读，降低阅读门槛 |
| **深度链接** | 感兴趣可跳转原文深度阅读 |
| **分类浏览** | 科技、政治、经济、社会、科学、文化 |
| **每日更新** | 实时追踪全球热点 |

## 覆盖来源

| 类别 | 来源 |
|------|------|
| **科技** | Hacker News, Product Hunt, Dev.to, Ars Technica |
| **财经** | 彭博社, 金融时报, 雅虎财经 |
| **新闻** | BBC, 路透社, Politico, 天空新闻 |
| **深度** | 经济学人, 大西洋周刊, 纽约客, 卫报 |
| **科学** | 自然杂志, Phys.org, Big Think |

## 内容特点

### 1. 科技与创新
- AI 发展动态（OpenAI, Gemini, Claude）
- 技术趋势和创业故事
- 开发实践和工具推荐

### 2. 地缘政治
- 国际冲突和外交动态
- 区域政治和经济合作
- 安全和灾难事件

### 3. 经济金融
- 全球资本市场动态
- 行业和企业发展
- 政策和监管变化

### 4. 社会文化
- 社会议题和政策讨论
- 文化评论和人物洞察
- 科技与伦理探讨

## 使用场景

1. **信息获取**: 快速了解全球热点
2. **跨文化研究**: 理解国际视角
3. **趋势追踪**: 追踪科技和商业趋势
4. **学习英语**: 中英对照阅读

## 与其他工具的对比

| 维度 | Buzzing | 微信公众号 | RSS 阅读器 |
|------|---------|-----------|-----------|
| **来源** | 30+ 国外媒体 | 国内为主 | 用户自选 |
| **语言** | 中文导读 | 中文 | 原文 |
| **门槛** | 低 | 低 | 中 |
| **深度** | 可跳转原文 | 平台内 | 原文 |
