# DeepWiki

## 概述

DeepWiki 是由 Cognition（Devin AI 的开发商）推出的 AI 驱动文档平台，为每个 GitHub 仓库自动生成可交互的最新文档。用户可以直接与仓库文档进行对话式问答，无需阅读冗长的 README 或 API 说明。DeepWiki 的文档由 Devin 自动维护更新，确保始终与最新代码同步。

## 核心功能

### 功能特点
- **自动文档生成**：为任意 GitHub 仓库生成结构化、可交互的文档
- **对话式问答**：直接向文档提问，获取精准答案
- **自动更新**：仓库代码更新时，文档自动同步更新
- **Devine 驱动**：由 AI 编程代理 Devin 维护文档的准确性和时效性
- **仓库深度覆盖**：覆盖主流开源项目的详细文档

### 使用场景
- **快速上手新库**：通过问答快速理解一个不熟悉的仓库如何使用
- **API 查询**：直接查询某个函数的参数、返回值和使用方法
- **架构理解**：通过对话了解项目的整体架构和设计理念
- **问题排查**：在开发中遇到问题时快速查找文档中的解决方案

## 关键概念

- **Devin**：Cognition 开发的 AI 编程代理，自动执行代码任务
- **交互式文档**：可对话、可查询、可持续更新的新一代文档形式
- **AI 驱动的知识维护**：用 AI 替代人工维护文档的时效性和准确性
