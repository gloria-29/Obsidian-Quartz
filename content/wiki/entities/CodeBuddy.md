# CodeBuddy

## 概述

CodeBuddy 是腾讯推出的 AI CLI 编程工具，采用 IDE + CLI 双形态设计。其独特之处在于"编程+设计"的融合思想——不仅生成代码，还兼顾 UI 设计质量。在快速原型能力上尤为突出，号称 10 分钟可以做出 8 个网站。与 [[Claude Code]]、[[Codex (OpenAI Coding Agent)]]、[[iFlow-CLI]] 等同属终端 AI 编程工具赛道。

## 核心功能

### 功能特点
- **IDE + CLI 双形态**：既可在终端中运行，也可在 IDE 中使用，灵活切换
- **编程+设计思想**：同时关注代码质量和 UI 设计，生成的页面具有专业视觉效果
- **快速原型能力**：极高效率的代码生成速度，10 分钟可完成 8 个网站
- **腾讯生态集成**：与腾讯云的开发工具和 AI 能力深度整合
- **自然语言驱动**：用自然语言描述需求即可生成应用
- **代码理解**：分析现有代码库，理解项目结构

### 使用场景
- **快速原型开发**：从需求到 Demo 的极速落地
- **全栈开发**：从后端 API 到前端界面的完整生成
- **学习与参考**：通过 AI 生成的代码学习最佳实践
- **页面设计**：兼顾功能实现的 UI 设计的场景

## 关键概念

- **双形态**：同时支持 IDE 插件和 CLI 两种使用方式
- **编程+设计**：CodeBuddy 区别于其他 AI 编程工具的差异化定位
- **腾讯生态**：依托腾讯云的 AI 能力和基础设施
