# Nano Banana Pro Prompts

## 概述

Nano Banana Pro 是一组高质量的 AI 提示词集合，专注于图像生成领域。这些提示词经过精心设计，可以帮助用户生成高质量、风格多样的 AI 图像。

## 核心特点

| 特点 | 说明 |
|------|------|
| **高质量输出** | 经过优化的提示词模板 |
| **风格多样** | 涵盖多种艺术风格 |
| **易于使用** | 即拿即用的提示词 |
| **持续更新** | 社区驱动的提示词库 |

## 使用场景

1. **创意设计**: 生成独特的艺术作品
2. **内容创作**: 为社交媒体生成配图
3. **原型设计**: 快速生成设计原型
4. **灵感启发**: 探索不同的视觉风格
