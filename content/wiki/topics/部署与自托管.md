# 部署与自托管

各种自托管和部署方案汇总，从免费平台到自建服务器。

## 部署平台

### 免费云平台
- **Cloudflare Workers** — 免费边缘计算平台，支持大量免费服务（CDN、SSL、DDoS防护、R2存储）
- **Serv00** — 免费虚拟主机，适合个人项目
- **Oracle Cloud** — 永久免费VPS（甲骨文实例），适合需求较高的自部署
- **HuggingFace** — ML模型部署和Spaces应用托管
- **腾讯EdgeOne** — 免费CDN且支持中国大陆加速（需ICP备案）

### 容器化部署
- **Docker + Docker Compose** — 容器化部署标准方案
- **Portainer** — 容器管理面板，管理本地及远端容器
- **Homelab实践**：4c16g服务器可承载Nginx Proxy Manager、Syncthing、Uptime-Kuma等20+服务

## 自托管工具

### AI应用
- **LobeChat** — AI聊天助手（Postgres+S3），支持New-API
- **Open NotebookLM** — 开源NotebookLM替代品
- **Dify** — 开源LLM应用开发平台，支持RAG和Agent构建
- **n8n** — 低代码自动化（定时备份、每日早报、AI文章总结）

### 个人服务
- **memos系列** — 说说笔记，轻量级个人记录
- **TriliumNext** — 笔记软件，Trilium的重构优化版
- **Vaultwarden** — 密码托管（Bitwarden自托管版）
- **Gitea** — 本地Git仓库
- **NocoDB** — 低代码数据库
- **Home Assistant** — 智能家居管理（小米设备桥接HomeKit）

### 媒体与CMS
- **microfeed**（Cloudflare）：轻量CMS，输出网页/RSS/JSON Feed
- **SurfSense**：Docker Compose部署的个人RAG系统

## 网络工具
- **siteproxy** — 反向代理免翻访问
- **Proxypool** — 免费代理节点池
- **科学上网教程**

## 关键工具/概念
- **自托管（Self-hosting）** — 个人拥有和控制服务器与数据
- **Cloudflare Workers** — 免费边缘计算平台
- **Docker Compose** — 多容器部署的标准编排工具
- **Homelab** — 家庭服务器的综合运维实践
