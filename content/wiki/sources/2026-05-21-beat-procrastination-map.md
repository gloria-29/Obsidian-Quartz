# 战胜拖延作战地图全景解析

> 一套为学术人群及 INFJ 量身定制的结构化时间管理系统，从战略规划到高效执行的终极指南。

## 核心观点
- 三大支柱：每周规划（战略层）x 每日专注（战术层）x 持续复盘，形成闭环
- 六步规划流程：收集任务 -> 四象限排序 -> 时间块规划 -> 能量匹配 -> 预留缓冲 -> 固定重复
- 九大反拖延技术覆盖行为、心理、环境三个维度：任务分解、两分钟规则、五分钟启动法、减少决策疲劳、任务批处理、诱惑捆绑、70%准备原则
- 多任务切换真实代价：中断后重新专注需 23 分钟，效率损失约 40%
- 方法论组合建议：番茄法提专注 + GTD 管全局 + 艾森豪威尔定优先级

## 关键概念
- [[Eisenhower Matrix]] — 艾森豪威尔四象限，高效人士在 Q2（重要不紧急）停留最久
- [[番茄工作法]] — 25 分钟专注 + 5 分钟休息的基础循环
- [[GTD]] — Getting Things Done 五步工作流：捕获-澄清-组织-反思-执行
- [[蔡加尼克效应]] — 一旦开始任务，大脑的完成驱动力就会推动持续下去
