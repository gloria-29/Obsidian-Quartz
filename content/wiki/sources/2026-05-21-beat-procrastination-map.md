# 战胜拖延作战地图全景解析

## 概要

一套为学术人群及 INFJ 量身定制的结构化时间管理系统，从战略规划到高效执行的终极指南。整合了 GTD、番茄工作法、艾森豪威尔矩阵等主流方法论，覆盖行为、心理、环境三个维度的九大反拖延技术。

## 核心内容

### 三大支柱
- **每周规划**（战略层）：收集任务 → 四象限排序 → 时间块规划 → 能量匹配 → 预留缓冲 → 固定重复
- **每日专注**（战术层）：专注块执行，减少任务切换
- **持续复盘**：形成闭环，持续优化

### 六步规划流程
1. 收集所有任务（Capture）
2. 四象限排序（艾森豪威尔矩阵）
3. 时间块规划（Time Blocking）
4. 能量匹配——高认知任务安排在精力高峰
5. 预留缓冲——应对突发和过渡
6. 固定重复——建立例行节奏

### 九大反拖延技术
- **行为维度**：任务分解、两分钟规则、五分钟启动法
- **心理维度**：减少决策疲劳、诱惑捆绑、70%准备原则
- **环境维度**：任务批处理、物理环境优化、数字干扰隔离

### 方法论组合建议
- 番茄法提专注 + [[GTD]] 管全局 + 艾森豪威尔矩阵定优先级
- 多任务切换代价：中断后重新专注需 **23分钟**，效率损失约 **40%**

## 关键概念
- **[[Eisenhower Matrix]]** — 艾森豪威尔四象限，高效人士在 Q2（重要不紧急）停留最久
- **[[番茄工作法]]** — 25分钟专注 + 5分钟休息的基础循环
- **[[GTD]]** — Getting Things Done 五步工作流：捕获-澄清-组织-反思-执行
- **蔡加尼克效应** — 一旦开始任务，大脑的完成驱动力就会推动持续下去
- **两分钟规则** — 能两分钟内完成的事立即执行
