### [](https://linux.do/t/topic/757481#p-6934320-h-2)支持：
- 1. docker 一键部署（推荐使用 docker compose）
- 2. httpx 异步方案已实现，支持高并发场景
- 3. 满血非流（反正我没遇到过截断 !:tieba003:）
- 4. 有佬发现了代码里写的小彩蛋，是的，你所有在网页创建的 agent 都会无缝添加到 2api 上，所以把全模型列表贴一下吧
- ](https://linux.do/t/topic/757481/53)
- &gt;

### [](https://linux.do/t/topic/757481#p-6934320-h-3)不支持：
- 1. 系统提示词
- 2. 图像多模态
- 3. 参数调节

### [](https://linux.do/t/topic/757481#p-6934320-h-4)怎么用？
- 1. 重中之重的是，你要学会自己创建账号
- 2. 把你自己创建的公司域名记下来，如示例中的 &#96;watchingforlinuxdo.retool.com&#96;
- 3. 把两个鉴权 &#96;accessToken&#96; 和 &#96;xsrfToken&#96; 存下来（一周存活期）
- 4. 保存到 &#96;retool.json&#96; 中，如下：
- &#96;&#96;&#96;
- &quot;domainname&quot;: &quot;xxxx.retool.com&quot;,
