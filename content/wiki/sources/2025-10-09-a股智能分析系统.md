# A股智能分析系统

## 概要
基于 AKShare 和 CrewAI 的开源 A 股智能分析平台，通过 4 个专业化 AI Agent 协作，覆盖实时行情、财务数据、资金流向和市场情绪等多维度分析。项目发布在 GitHub，适合对 AI 辅助投资感兴趣的用户。

## 核心内容
### 多 Agent 协作架构
- 基于 CrewAI 框架，构建 4 个专职 AI 角色，各司其职
- Agent 之间协同工作，综合多维度数据给出分析结论

### 功能覆盖
- 实时行情查询：获取 A 股个股和大盘最新数据
- 财务数据分析：读取公司财报、利润表等关键指标
- 资金流向追踪：监控主力资金、北向资金等动向
- 市场情绪感知：综合新闻、舆论等信息判断市场情绪

### 技术栈
- AKShare：开源金融数据接口，免费获取 A 股数据
- CrewAI：多 Agent 编排框架，定义角色和任务流程
- 项目开源在 GitHub，可本地部署和二次开发

## 关键概念
- **CrewAI**: 多 AI Agent 协作编排框架，支持角色定义、任务分配和结果汇总
- **AKShare**: 开源 Python 金融数据接口库，覆盖 A 股、港股、期货等多种市场
- **AI Agent**: 具有特定能力的自主智能体，可独立完成数据分析任务并与其他 Agent 协作
