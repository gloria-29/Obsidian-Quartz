# SurfSense 项目阅读笔记

> 开源 [[NotebookLM]] / Perplexity 替代品，可连接 20+ 外部数据源的 AI 研究代理，支持自托管和本地 LLM。

## 概要

SurfSense 是由 MODSetter 团队（Rohan Verma）开发的开源项目，定位为 [[NotebookLM]] 和 Perplexity 的增强替代方案。其核心价值在于将用户的个人知识库与多种外部数据源深度集成，构建一个统一、私密且高效的研究和知识管理环境。项目使用 cording12/next-fast-turbo 模板生成，2025 年 10 月活跃开发中，已有公开路线图并接受社区贡献。

## 核心内容

### 功能特性

- **外部数据源连接**：支持 Slack、Linear、Jira、ClickUp、Confluence、Notion、Airtable、Gmail、Google Calendar、YouTube、GitHub、Discord、Luma 及搜索引擎（Tavily、LinkUp），未来将支持更多连接器
- **个人知识库**：支持 50+ 文件格式（文档、图片、音视频），提供三种 ETL 服务可选——LlamaCloud（50+ 格式，增强解析）、Unstructured（34+ 格式）、Docling（本地处理、无 API 密钥、隐私优先）
- **AI 交互与检索**：自然语言对话 + 引用答案（类 Perplexity），采用两层 RAG 分层索引 + 混合搜索（语义 + 全文 + 互易排名融合 RRF），支持 100+ LLM、6000+ Embedding 模型及主流 Reranker（Cohere、Flashrank 等）
- **播客生成代理**：20 秒内生成 3 分钟播客，支持 OpenAI、Azure、Google Vertex AI 及本地 Kokoro TTS，可将聊天对话转为音频内容
- **隐私优先**：兼容 Ollama 等本地 LLM，完全可自托管，用户对数据拥有完全控制权
- **浏览器扩展**：Manifest v3（Plasmo 框架），可保存需登录认证的网页内容

### 技术架构

| 层级 | 技术栈 |
|------|--------|
| 后端 | FastAPI + PostgreSQL/pgvector + SQLAlchemy + Alembic + LangGraph + LangChain + LiteLLM + FastAPI Users（JWT/OAuth 认证） |
| 前端 | Next.js 15（App Router + 服务器组件）+ React 19 + TypeScript + Tailwind CSS 4.x + Shadcn + Framer Motion + Vercel AI SDK + React Hook Form + Zod |
| 部署 | Docker Compose，内置 pgAdmin 数据库管理 |
| 分块 | Chonkie + LateChunker（基于 Embedding 模型最大序列长度优化）+ AutoEmbeddings |

### 部署方式

- **Docker 安装**：所有依赖容器化，含 pgAdmin，通过 `.env` 配置，支持全栈或仅核心服务部署
- **手动安装（推荐）**：更多控制和定制化选项，适用于 Windows、macOS、Linux
- 前置条件：PGVector 设置 + ETL 服务选择（LlamaCloud / Unstructured / Docling）+ 其他 API 密钥

## 关键概念

- **RAG 即服务**：SurfSense 提供 RAG as a Service API 后端，可独立调用
- **混合搜索**：语义搜索 + 全文检索通过互易排名融合（RRF）结合，提升检索精度
- **分层索引**：两层 RAG 结构，在效率和精度间取得平衡
- **ETL 服务选择**：LlamaCloud（50+ 格式）、Unstructured（34+ 格式）、Docling（本地处理、无 API）
