# MinIO对象存储解决方案

## 概要

MinIO 是一款高性能、S3 API 兼容的开源对象存储解决方案，采用 GNU AGPLv3 许可证。适用于机器学习、数据分析和应用数据存储场景，支持容器化部署、多平台安装和零停机升级。

## 核心内容

### 产品特性
- 与 Amazon S3 API 完全兼容，可无缝对接现有 S3 生态系统
- 高性能架构，适合机器学习和大数据场景
- 支持版本控制、对象锁定、桶复制等高级功能（需分布式部署）
- Erasure Coding（擦除编码）保障数据冗余，每台服务器至少需要4个存储设备

### 部署方式
- **容器化部署**：Podman/Docker 一键启动，适合开发和评估
- **macOS**：Homebrew 安装或二进制文件直接运行
- **GNU/Linux**：下载二进制文件，支持多种架构（AMD64、ARM、ppc64le）
- **Windows**：下载 exe 文件运行
- **源码编译**：需要 Go 1.24+，不推荐用于生产环境
- 默认凭证：`minioadmin:minioadmin`，默认端口：9000（API）、9001（控制台）

### 部署与运维
- 防火墙需开放 9000 端口（ufw/firewall-cmd/iptables）
- 客户端工具 mc 提供类 UNIX 命令行操作
- 零停机升级：手动替换二进制、mc admin update 或升级容器镜像
- 生产环境推荐分布式部署 + Erasure Coding

### 许可与合规
- 源代码：GNU AGPLv3
- 文档：Creative Commons Attribution 4.0
- 与 [[Deepseek2API]] 等自托管服务类似，注重数据控制权

## 关键概念

- **S3兼容性（S3 Compatibility）**: 与 Amazon S3 API 兼容，可复用现有工具和 SDK
- **Erasure Coding（纠删码）**: 数据冗余技术，将数据分片并编码存储，支持故障恢复
- **分布式部署**: 多节点集群模式，支持高可用和水平扩展
- **零停机升级**: 升级过程无需停止服务，所有操作非破坏性
