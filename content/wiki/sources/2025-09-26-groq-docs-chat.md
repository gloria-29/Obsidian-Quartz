# Groq Docs Chat

## 概要

Groq Docs Chat 是一个基于 Groq 快速推理和 Cloudflare AI 搜索的交互式文档聊天应用。它允许开发者与网站内容进行对话式交互，帮助更高效地查阅和理解技术文档。

## 核心内容

### 核心功能
- 基于 Groq 的超低延迟推理能力实现即时响应
- 集成 Cloudflare AI 搜索进行文档内容检索
- 支持开发者与任意网站内容进行交互式对话

### 技术架构
- 使用 Groq LPU 推理引擎加速 LLM 响应
- Cloudflare 提供文档索引和搜索能力
- 开源项目，提供在线演示

### 应用场景
- 快速理解复杂技术文档
- 针对特定 API 或框架进行问答式学习
- 提升开发者查阅文档的效率

## 关键概念

- **Groq**：提供超低延迟 LLM 推理的硬件和云服务公司
- **RAG (检索增强生成)**：结合文档检索和 LLM 生成的技术架构
- **LPU (Language Processing Unit)**：Groq 自研的推理加速芯片
