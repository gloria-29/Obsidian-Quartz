# MixFile — 用B站作为网盘

## 概要

MixFile 是一个利用 B 站漫画上传通道存储任意文件的开源工具，实现"无限空间、无限流量"的文件托管。文件上传前使用随机密钥加密，B 站无法审核内容本质，巧妙地将内容平台转化为通用存储后端。这是中文开源社区中"利用平台基础设施做非预期用途"的典型创新案例。

## 核心内容

### 工作原理
- 利用 B 站漫画频道的上传接口，将任意文件拆分后以漫画图片的形式上传至 B 站服务器
- 上传前使用随机密钥对文件进行加密，确保 B 站内容审核系统无法识别真实文件内容
- 文件存储在 B 站 CDN 上，借助 B 站的基础设施实现高速上传和下载

### 功能特性
- **WebDAV 支持**: 可通过 WebDAV 协议管理文件，兼容各种文件管理器
- **视频播放优化**: 内置视频播放支持，可自动缓存播放进度
- **嵌套文件搜索**: 支持在文件列表中进行搜索，方便管理大量文件
- **文件分享**: 支持生成分享链接，方便将文件分享给他人
- **跨平台**: 支持 Android 和 PC（需要 Java 8+ 环境）

### 技术实现
- 开源项目，源码托管在 GitHub: InvertGeek/MixFile
- 依赖 B 站漫画上传通道的可用性，存在平台政策变动的风险
- 随机密钥加密机制意味着密钥丢失等同于文件丢失，需妥善保管

### 局限性与风险
- 依赖 B 站未封堵该上传通道，平台政策变动可能导致工具失效
- 文件加密后无法被 B 站识别，但大量异常流量可能触发风控
- 本质上是对平台 ToS 的灰色使用，长期可用性不确定

## 关键概念

- **WebDAV**: 基于 HTTP 的文件管理协议，允许像操作本地文件系统一样管理远程文件
- **漫画通道利用**: 通过 B 站漫画上传接口存储非漫画文件，属于"通道复用"技术思路
- **随机密钥加密**: 每次上传使用随机生成的密钥加密文件，即使 B 站存储了文件也无法读取内容
- **CDN 反向利用**: 借助 B 站的内容分发网络实现高速文件分发，而非自建存储服务器
