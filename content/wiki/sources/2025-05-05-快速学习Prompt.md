# 快速学习Prompt

## 概要

一个经过实战检验的结构化 Prompt，用于快速了解任何概念和命题。该 Prompt 要求 AI 按照抽象定义、具体示例、类比对比、模式归纳四个层次逐步解析概念，并附带了多个基于不同 AI 模型（DeepSeek-r1、OpenAI-o1、Grok3）的使用示例。

## 核心内容

### Prompt 结构（四层解析法）
1. **抽象定义**（灯泡符号）：用简洁语言描述概念的本质、核心规则或目的
2. **具体示例**（书本符号）：提供2-3个典型应用场景，包含简单/复杂两种层级
3. **类比对比**（天平符号）：通过类比说明相似概念区别，或通过对比突显特征
4. **模式归纳**（大脑符号）：总结通用规律，提炼可迁移的思维模型

### 补充要求
- 补充该概念常与哪些其他概念有联系（孤立概念无法发生作用）
- 如果用户提供材料（>50字）而未给出具体概念，AI需提炼共有概念再解析
- 输出层次分明清晰

### 使用示例
- **"AI替代人类"**（DeepSeek-r1）：技术迭代引发的社会角色重构，淘汰的是可标准化劳动模式
- **"中西医之争"**（DeepSeek-r1）：两种医学范式在认知体系、方法论层面的系统性碰撞
- **"AI的作用难以超越使用者"**（DeepSeek-r1）：工具属性与人类主体性的关系问题
- **"素描和绘画灵活表达"**（OpenAI-o1）：先掌握基础形态，再多方尝试突破
- **"何为创新"**（OpenAI-o1）：打破常规创造新价值的过程
- **"职业规划"**（Grok3）：自我评估→市场研究→设定目标→制定计划→执行调整

### 关键发现
- DeepSeek-r1 对中文 Prompt 响应更好，英文 Prompt 效果下降明显
- 不同模型在同一 Prompt 下输出风格差异显著

## 关键概念

- **结构化概念解析**: 通过定义→示例→类比→归纳的递进结构理解新概念
- **可迁移思维模型**: 从具体概念中提炼的通用规律，可应用于不同领域
- **多模型对比**: 使用不同 AI 模型（DeepSeek、OpenAI、Grok）验证 Prompt 效果
- **渐进式理解**: 从抽象到具体再到模式的认知递进过程
