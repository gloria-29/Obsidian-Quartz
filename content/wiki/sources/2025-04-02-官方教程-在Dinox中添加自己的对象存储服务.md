# 在 Dinox 中添加自己的 S3 对象存储服务

## 概要

Dinox 官方教程，介绍如何将自定义 S3 对象存储服务接入 Dinox 笔记应用。教程以缤纷云（Binfen Cloud）为例，演示了从注册账号、创建桶、配置 AccessKey 到在 Dinox 中完成绑定的完整流程。S3 相比 WebDAV 具有价格低、支持外网直接渲染、隐私性好、迁移方便等优势。

## 核心内容

### S3 对象存储的优势
- 价格便宜，支持外网访问多媒体文件，笔记可在外部直接渲染
- 隐私性好：存储在自己的 S3 比官方 S3 更安全
- 极致安全场景可部署 MinIO 等开源 S3 服务到 NAS
- 数据安全性高，所有数据自己掌握
- 支持自定义域名和前缀路径，迁移方便

### 缤纷云（Binfen Cloud）设置流程
1. 注册缤纷云账号并完成实名认证
2. 进入控制台，创建桶（如 dinoxoss），选择公开桶
3. 创建子用户：左侧菜单 AccessKey，添加子用户
4. 创建 AccessKey：备注随意填写，选择对应子用户，保存生成的 AccessKey 和 SecretKey
5. 查看桶信息：在桶列表中找到创建的桶，打开公开读取和启动 HTTP/3

### 在 Dinox 中配置
1. 打开 Dinox APP → 侧边栏 → 右下角设置 → 系统设置 → 对象存储
2. 将缤纷云的 AccessKey、SecretKey、桶名、区域等信息填入对应字段
3. 使用方式：长按图片选择"替换为对象存储链接"即可上传到自己的存储

### 缤纷云优缺点
- 优点：价格便宜、速度 OK、运营 3 年较稳定
- 缺点：相比阿里云、七牛云等传统厂商仍属新厂商

## 关键概念

- **S3 对象存储**：Amazon S3 协议的对象存储服务，已成为云存储的事实标准，多家厂商提供兼容实现
- **AccessKey / SecretKey**：S3 服务的访问凭证，类似于账号密码，用于认证 API 调用
- **公开桶**：允许匿名读取的存储桶，适合存放需要外网直接访问的多媒体文件
- **HTTP/3**：新一代 HTTP 协议，提供更快的传输速度
