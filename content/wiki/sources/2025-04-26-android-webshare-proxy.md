# 安卓手机设置 Webshare 代理

> 在 Android 设备上配置 Webshare IP 代理的三种方法指南。

## 核心观点
- 方法一（推荐）：使用代理 APP（HTTP Proxy Client、Shadowsocks、V2rayNG）
- 方法二（仅 WiFi）：在 WiFi 网络设置中手动配置代理 IP 和端口
- 方法三（高级）：使用 Termux 终端创建本地转发节点
- 使用代理服务需遵守当地法律法规

## 关键概念
- [[Webshare]] — 付费 IP 代理服务提供商
- [[V2rayNG]] — Android 平台的代理客户端，支持多种协议
- [[Termux]] — Android 终端模拟器，可用于技术性网络配置
