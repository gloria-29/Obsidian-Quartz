# Codex Free 注册：0 元接码绑定教程

## 概要
来自 linux.do 社区的实操教程，介绍如何使用免费 VOIP 虚拟号码为 OpenAI Codex 账号完成手机绑定。核心发现是 OpenAI 对 VOIP 号码的检测力度远弱于金融类应用，大部分虚拟号码可以成功绑定。

## 核心内容

### 关键发现
- OpenAI 对 VOIP 号码的检测力度很弱，与 PayPal 等金融 App 完全不在一个量级
- 测试了 textfree、textnow 两家美国虚拟电话运营商，共注册 5 个手机号
- 其中 1 个号码被识别为 VOIP 无法绑定，其余 4 个成功绑定了 12 个 Codex 账号
- 一个未绑过的手机号可绑定 3 个 OpenAI 账号；Outlook 邮箱开两个别名共 3 个号
- 综合下来接近两分钟绑完一个号

### 注册操作步骤
1. 需在美国/加拿大家宽 IP 下注册虚拟运营商账号（最好家宽，万人骑 IP 有概率不通过）
2. 将手机时间调到美国时间，时区匹配梯子所在地区
3. 用 Google 账号直接登录注册，或邮箱注册（可能弹人脸识别）
4. 选择冷门地区电话区号 + 别扭的号码（降低被识别为 VOIP 的风险）
5. 绑定完 3 个账号后退出登录，重新注册新虚拟号码继续使用

### 注意事项
- 账号不一定要新注册，老号在 add phone 弹出时绑定也 OK
- 谨慎起见建议用美国 IP 新注册邮箱和 ChatGPT 账号
- 其他虚拟运营商 App（App Store / Google Play 中）理论上也可用
- 不要过度薅号，避免虚拟运营商被风控

## 关键概念
- **VOIP 虚拟号码**：通过互联网协议提供的虚拟电话号码，非实体 SIM 卡，成本极低
- **textnow / textfree**：美国免费虚拟电话运营商，提供 +1 号码
- **接码绑定**：使用虚拟号码接收验证码完成账号手机绑定的流程
