# 网络安全搜索工具汇总

## 概要

汇总了12个主流网络空间搜索引擎的对比表，涵盖 Shodan、Censys、FOFA、ZoomEye 等工具的查询语法、运算符和支持功能。这些工具用于发现互联网上的设备、服务和漏洞，是安全研究和 OSINT（开源情报）工作的基础设施。

## 核心内容

### 主流搜索引擎

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| **Shodan** | 最老牌的网络空间搜索引擎，支持图像搜索 | IoT 设备发现、暴露服务扫描 |
| **Censys** | 学术背景，数据质量高 | 证书透明度、主机资产测绘 |
| **FOFA** | 国内团队开发，中文友好 | 国内资产发现、快速检索 |
| **ZoomEye** | 知道创宇旗下，国内生态完善 | 中文资产、漏洞关联 |
| **Hunter** | 支持复杂布尔查询 | 精细化资产筛选 |
| **Quake360** | 360旗下，覆盖面广 | 国内互联网资产全景 |
| **urlscan.io** | 专注 URL 扫描和分析 | 网页安全分析、钓鱼检测 |
| **BinaryEdge** | 多源数据聚合 | 综合威胁情报 |
| **Netlas** | 新兴工具，界面友好 | 快速资产发现 |
| **Onyphe** | 法国团队，欧洲数据丰富 | 欧洲区域资产、暗网情报 |
| **FullHunt** | 专注攻击面管理 | 企业攻击面评估 |

### 查询语法差异
- 大多数使用冒号 `:` 作为键值分隔符
- FOFA 使用等号 `=`，Hunter 使用双等号 `==`
- 布尔运算符基本一致：and/or/not（大小写有差异）

## 关键概念

- **OSINT（开源情报）**: 从公开可用来源收集和分析信息的情报方法
- **网络空间搜索引擎**: 扫描并索引互联网上可访问的设备、服务和资产的专用搜索引擎
- **攻击面管理**: 识别和管理组织暴露在互联网上的所有可攻击资产
