# Organizing Life with a TXT File

## Summary
A plain-text organization system using .txt files is durable, future-proof, and infinitely flexible. Three methods: One Big Text File (OBTF), multi-file system with `todo.txt` syntax, and plain-text [[Bullet Journal]]. Emphasized by [[Cal Newport]] as `WorkingMemory.txt`.

## Core Ideas
1. **OBTF Method**: All notes/tasks in one reverse-chronological file with date stamps. Search replaces organization. Core principle: "capture everything quickly, sort later."
2. **todo.txt Syntax**: Priority markers (A/B/C), project tags (+project), context tags (@context), due dates. Machine-readable yet human-readable.
3. **Plain-Text Bullet Journal**: Monthly files with symbol keys (* task, x done, > migrated, o event, - note). Migration forces daily re-evaluation.

## Key Concepts
- **Future-proofing**: .txt format readable on any computer in 50 years
- **Cloud sync + search**: Dropbox/Google Drive + Ctrl+F as primary retrieval
- **Consistency > complexity**: Personal discipline matters more than tool sophistication
