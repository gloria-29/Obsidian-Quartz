# 电纸书需求与选择

## 概要

记录选购电子纸阅读器（电纸书）时的核心需求与候选产品评估。重点考察手写笔记功能、开放安卓系统支持以及跨平台应用兼容性，属于[[信息获取与管理]]中数字阅读工具选型的一部分。

## 核心内容

### 需求分析

| 需求 | 说明 |
|------|------|
| 手写笔记 | 支持手写批注和笔记功能，适合阅读时即时记录 |
| 多平台阅读App | 支持Kindle、微信读书等主流阅读应用 |
| 开放安卓系统 | 较高版本安卓系统，可自由安装第三方应用 |
| 外区App协同 | 支持Google账号登录，使用海外应用生态 |

### 候选产品

- **Remarkable** — 以手写体验著称的电子纸设备，但系统相对封闭，不支持安卓应用生态
- 开放安卓系统的电纸书（如文石Boox系列）更符合"多App+外区协同"的需求

### 选型考量

手写笔记与开放系统之间存在天然矛盾：专注手写的设备（如Remarkable）系统封闭；开放安卓设备手写体验可能稍逊。核心取舍在于"笔记体验优先"还是"应用生态优先"。

## 关键概念

- **电纸书 vs 平板** — 电纸书使用E-Ink屏幕，护眼且续航长；平板功能更全但长时间阅读伤眼
- **开放安卓系统** — 允许安装第三方App的安卓系统版本，区别于厂商深度定制的封闭系统
- **外区App协同** — 通过Google Play等海外应用商店安装和同步应用，需要设备支持GMS框架
