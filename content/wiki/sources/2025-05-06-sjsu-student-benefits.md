# SJSU 学生福利与申请指南

## 概要

San Jose State University（SJSU）的学生福利汇总指南，涵盖 Adobe 全家桶、Office 365、GitHub 学生包、JetBrains 全家桶、Gemini Student、Windows 虚拟机、VPN、ChatGPT EDU Plus 等多项权益。指南还包含学生证生成技巧（使用 GPT 辅助制作）和申请注意事项，建议挂 VPN 操作以提高成功率。

## 核心内容

### 可申请的学生福利
1. **VPN**：SJSU 提供的校园 VPN，质量尚可
2. **Adobe 全家桶**：学生邮箱可直接登录 Adobe，但需通过 adobelicensing.sjsu.edu 单独申请授权，约一天通过
3. **Windows 虚拟机**：通过 Windows App（windows365.microsoft.com）学生邮箱直接登录使用
4. **Office 365**：学生邮箱登录即可，包含 OneDrive 1TB 和 Microsoft 365 Copilot
5. **GitHub 学生包**：需挂 VPN，使用学生邮箱注册后在首页点击 join edu；上传学生证可参考社区技巧
6. **JetBrains**：教育许可，秒批
7. **Gemini Student**：理论可行，需验证
8. **Grok**：已有用户成功申请
9. **Autodesk 教育**：测试可直接通过
10. **ChatGPT EDU Plus**：学生免费两个月

### 申请技巧
- 不一定有邮件通知，等两三天后直接尝试重置密码，若可重置则说明账号已开通
- 建议全程挂 VPN 操作，领取成功后可不挂
- GitHub 学生包上传学生证可使用 GPT 生成符合规范的图片

### 学生证生成 Prompt 参考
- 基于官网示例图，让 GPT 生成包含个人信息的学生卡图片
- 注意替换姓名、ID、过期时间等信息
- 如遇输出格式问题，可调整 prompt 指定长方形比例

## 关键概念

- **GitHub 学生包（GitHub Student Developer Pack）**：面向学生的免费开发工具套装，包含多种付费工具的免费使用权
- **EDU 邮箱**：教育机构提供的邮箱，是申请各类学生福利的核心凭证
- **学生证生成**：利用 AI 工具生成符合规范的学生证图片，用于福利申请的身份验证
