## 核心内容

### 原创 歸藏的 AI 工具箱 2025年08月29日
- 原创 歸藏的 AI 工具箱 2025年08月29日 22:23
- 大家好我是歸藏 （guizang），今天带来在 Lovart 上使用 Nano Banana 的体验。
- 在 Nano Banana 上线的第二天 Lovart （ lovart.ai/ ）就上了，这种 Agent 不比一些聚合类应用加个按钮就行，适配新模型还是有些麻烦的，可以说相当迅速了。
- 今天看到他们还开启了周末免费活动，从今天开始到周日三天， 在 Lovart 上可以免费畅玩 Nano banana ，不会消耗任何积分。
- ⚠️注意：由于只有 Nano Banana 这一个模型免费，所以为了避免你的任务调用其他模型扣积分，你可以在输入框模型选择这里只勾选 Nano Banana。

### 其实我这几天也开发出了很多 Nano Banana
- 其实我这几天也开发出了很多 Nano Banana 和其他模型配合的玩法，图片涂鸦替代提示词的方式跟 Lovart 的画布也非常契合，这次内容就带大家看看 Nano Banana 和自动化的设计 Agent 配合有多强。
- 首先还记得我说过的 Nano Banana 用涂鸦替代提示词的方式完成对图片的精确修改吗，Lovart 左边的 Magic Canvas 天生就是用来干这个事情的。
- Nano Banana 因为有强大的世界知识，所以他是可以看懂地图的。
- 我们可以从谷歌地图上找一个地点（地标建筑）然后再放到 Magic Canvas 上画个箭头，他就知道这是什么地方。
- 然后跟点一下下方的评论图标在图片上跟 Lovart 说“Use Nano Banana to draw the photo seen by the red arrow.”

### 等他回复后我们点击下方的 Run All，等待奇迹
- 等他回复后我们点击下方的 Run All，等待奇迹就行。
- 然后他果然帮我们把祈年殿画出来了。
- 很多朋友也发现 Nano Banana 默认出图的分辨率很低，在 Lovart 你还可以直接点 Upscale 去放大图片，解决这个 Nano Banana 最大的问题。
- 搞完简单的演示教大家怎么操作之后我们整个难的，Nano Banana 可以实现超多物品在一张图片中的替换和生成，还能保持一致性。
- 所以我找了 7 件家具图片，然后用 Magic Canvas 画了一个简单的家具位置示意图，让 Nano Banana 把他们放在屋子的指定位置。

### 以往画示意图这部分你还得找个设计软件，而且还不一定
- 以往画示意图这部分你还得找个设计软件，而且还不一定会用，现在直接在 Magic Canvas 左边画框打字就行。
- 然后用下方评论按钮框选所有用到的图片输入提示词运行就行。
- 提示词：帮我使用Nano Banana根据左侧图片中标记的位置摆放所有家具，生成一张逼真的家居展示照片。
- 来看一下 Lovart 给出的结果，相当牛皮了，所有家具的位置都是对的，而且还考虑了空间关系，每个家具都跟原来的细节一致。
- 这个效果太可怕了。以后大家想要装修自己的屋子的时候只需要拍张照片，在照片上大致写一下家具的名字，再把家具给他，他就能给你家装效果图了。

### 玩完了 Magic Canvas 之后我们再来看一
- 玩完了 Magic Canvas 之后我们再来看一下结合了 Lovart 中的其他模型一起联动能做出多牛的东西出来。
- 昨天发了一个用 Nano Banana 改车最后变成完整一镜到底视频的案例，很多朋友问我怎么做，因为涉及到两个模型，有点麻烦，现在在 Lovart 里面两句话就能搞定，先看结果。
- 首先我们的素材就只是一个白模汽车模型，和一张用来参考配色的图片，这个大家随便搜索都行。
- 然后输入非常简单的提示词：
- 帮我用 Nano Banana 分别为这辆车改为第二张图的配色，然后将轮毂改为放射状，然后再在侧面增加黄色拉花，然后将车放在一个有非常好光照的车库中，最后将车变成正在赛道行驶。以上的每次改动都生成一张图片，不要一次完成。
