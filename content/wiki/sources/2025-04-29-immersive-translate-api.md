# 沉浸式翻译公益高并发 API

> 个人搭建的免费沉浸式翻译 API 服务，通过本地号池负载均衡实现高并发，基于智谱免费和付费渠道。

## 核心观点
- 构建方案：本地号池负载均衡 + 智谱(核心基座) + Grok/Gemini/DeepSeek/Qwen(辅助) + NewAPI 转发 + Cloudflare 解析
- 上线1天即处理约 2000万 Token 和 40000+ 次请求，说明沉浸式翻译的 API 消耗量巨大
- 提供三种翻译模式：通用、严谨、口语化，用户可根据需求选择
- 翻译质量定位：尚可的速度 + 尚可的质量 + 无脑操作，并非顶级大模型的逐字精翻

## 关键概念
- [[沉浸式翻译]] — 浏览器翻译插件，支持双语对照显示和多翻译引擎
- [[API 负载均衡]] — 将请求分发到多个后端模型号池以提高并发能力和可用性
- [[智谱 AI]] — 提供 GLM 系列模型的国内 AI 平台
