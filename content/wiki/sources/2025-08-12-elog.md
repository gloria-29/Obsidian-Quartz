# Elog 跨平台博客解决方案

## 概要
Elog 是一款开源的 Markdown 批量导出 CLI 工具，解决"想用舒适的写作编辑器 + 主流博客平台"的组合需求。支持从语雀/Notion/FlowUs/飞书/Wolai 等写作平台同步到 Hexo/VitePress/Hugo 等静态博客框架，也可直接发布到 Halo/WordPress/Confluence，内置多种图床支持和 GitHub Actions 自动化集成。

## 核心内容
- **写作平台支持**：Notion（Token/API）、语雀（Token/账号密码）、FlowUs（息流）、飞书云文档、Wolai（我来）、Outline
- **博客平台支持**：Hexo、VitePress、Hugo、Docusaurus、Docz、Halo、Confluence、WordPress；支持所有类似 Hexo 通过渲染本地 Markdown 生成静态站点的框架
- **图床功能**：解决在线平台图片防盗链问题，在生成 MD 前将图片上传至图床并替换链接；支持本地/腾讯云 COS/阿里云 OSS/七牛云/又拍云/GitHub，可自定义插件扩展至 Cloudflare R2、Backblaze B2
- **自动化集成**：支持 GitHub Actions + Serverless API + Webhooks 持续集成，提供多套开箱即用模板
- **CLI 命令**：elog init（初始化配置）、elog sync（同步文档）、elog clean（清理）、elog upgrade（升级）
- **开箱即用方案**：Notion+Hexo+Vercel、语雀+Hexo+Vercel、语雀+VitePress+Vercel、FlowUs+Halo、Notion+Halo 等
- **社区生态**：awesome-elog 仓库收录社区最佳实践，活跃的社区贡献者生态

## 关键概念
- **Elog**：开源跨平台博客同步工具，解耦写作平台与博客平台的选择
- **图床替换**：自动将在线平台的图片链接替换为图床地址，解决防盗链问题
- **Front Matter**：生成的 Markdown 文件包含 YAML 格式的元数据头部
- **开箱即用模板**：预配置好的写作平台 + 博客平台 + CI/CD 的完整解决方案
