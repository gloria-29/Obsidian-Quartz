# Elog — 开放式跨平台博客同步工具

批量导出 Markdown 的 CLI 工具，支持从语雀/Notion/FlowUs/飞书等写作平台同步到 Hexo/VitePress/Hugo 等博客平台，支持 Halo/WordPress/Confluence 直接发布。

**图床支持**：本地/腾讯云 COS/阿里云 OSS/七牛云/又拍云/GitHub

**自动化**：支持 GitHub Actions + Webhooks + Pipeline 持续集成
