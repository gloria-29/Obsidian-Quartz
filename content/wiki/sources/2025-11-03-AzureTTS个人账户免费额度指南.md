# Azure TTS 个人账户免费额度指南

## 概要

本指南面向非技术用户，详细介绍如何利用 Microsoft Azure 文本转语音 (TTS) 服务的免费层级生成高质量语音。通过 Azure 免费账户和 Speech Studio，无需编写代码即可每月免费使用 50 万字符的神经网络语音合成，约相当于 7-8 小时的音频内容。

## 核心内容

### 第一部分：注册与设置

- 访问 Azure 免费账户页面，使用 Microsoft 账户（Outlook/Hotmail）注册
- 身份验证需要电话号码和信用卡（仅验证身份，不产生费用，可能冻结约 1 美元）
- 在 Azure 门户中搜索 "Speech services"，创建新的语音服务资源
- 填写表单时关键选项：
  - 订阅：选择 "Free Trial"
  - 资源组：创建新组（如 MySpeechProjects）
  - 定价层级：必须选择 **Free F0** 层级
- 部署约需 1-2 分钟

### 第二部分：使用 Speech Studio 生成音频

- 访问 speech.microsoft.com，使用同一 Microsoft 账户登录
- 打开 "Audio Content Creation" 工具
- 新建文本文件，输入或粘贴待转换文本
- 右侧面板可选择语言、声音（数百种 Neural 语音）、风格、语速和音高
- 点击播放预览，满意后导出为 MP3 文件

### 第三部分：免费额度限制

- 每月 50 万字符 Neural TTS（约 7-8 小时音频）
- 实时请求限制：每 60 秒 20 次交易
- 单次请求最大音频长度：10 分钟
- 工具内单文件字符限制：3000 字符
- 超出额度后服务停止，下月 1 日重置，不会自动扣费

### 故障排除

- 音频开头缺失：可能是设备特定问题，换设备或浏览器测试
- 选择 East US 等主要区域可获得更好的语音选择和性能
- Azure 门户初次使用可能感到复杂，但日常创作只需 Speech Studio

## 关键概念

- **Neural TTS**: 基于深度学习的文本转语音技术，生成最接近真人发音的语音
- **Speech Studio**: Azure 提供的无代码 Web 工具，用于创建和管理语音内容
- **Free F0 层级**: Azure 语音服务的免费定价层级，包含基本功能和每月配额
- **语音风格 (Style)**: Neural 语音支持的表达风格，如欢快 (cheerful)、共情 (empathetic) 等
