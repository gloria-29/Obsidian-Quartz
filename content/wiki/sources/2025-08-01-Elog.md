# Elog — 跨平台Markdown博客解决方案

## 概要

Elog是一个开源的Markdown批量导出工具，解决"用最舒适的编辑器写博客"的核心需求。支持随意组合写作平台（Notion/语雀/飞书等）和博客平台（Hexo/Vitepress/Hugo等），并提供图床功能处理图片防盗链问题。

## 核心内容

### 解决的问题

写作平台和博客平台长期割裂：好用的编辑器不提供博客功能，博客平台的编辑器体验不佳。Elog将两者打通。

### 支持平台

**写作平台**：Notion、语雀、FlowUs、飞书云文档、我来Wolai

**博客平台**：Hexo、Vitepress、Hugo、Docusaurus、Halo、Confluence、WordPress

### 图床功能

解决Notion/语雀图片防盗链问题，支持上传到：

- 本地、腾讯云COS、阿里云OSS、GitHub图床、七牛云、又拍云
- 社区插件：Cloudflare R2、Backblaze B2

### 开箱即用方案

- Notion + Elog + Hexo + GitHub Actions + Vercel
- 语雀 + Elog + VitePress + GitHub Actions + Vercel
- FlowUs + Elog + Halo + GitHub Actions

## 关键概念

- **写作平台与博客平台解耦**：编辑器选择不再受博客框架限制
- **Front Matter生成**：自动生成符合各博客框架规范的元数据头
- **图床替换**：导出时自动将平台图片链接替换为可公开访问的图床链接
