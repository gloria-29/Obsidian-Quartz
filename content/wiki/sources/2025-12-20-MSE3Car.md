# MSE3Car — Office 365 E3 批量分发工具

## 概要

一个基于 Next.js 14 + Prisma 的开源工具，管理员通过 Microsoft Graph API 配置 OAuth 授权后，批量分发兑换码给用户。用户用兑换码在 Microsoft Entra（Azure AD）自动创建企业账户，可选自动分配 Office 365 E3 许可证。

## 核心内容

### 工作流程

1. **管理员配置**：在 Azure Portal 注册应用，配置 Tenant ID、Client ID/Secret 等环境变量
2. **OAuth 授权**：管理员在后台完成 Microsoft Graph API 的 OAuth 授权流程
3. **批量生成兑换码**：管理员通过后台批量或单个创建兑换码
4. **用户使用**：用户访问前台页面，输入显示名和兑换码，系统自动在 Entra 中创建账户并返回 UPN + 初始密码

### 技术栈

- 前端/后端：Next.js 14（App Router）
- 数据库：本地开发使用 SQLite，生产环境建议 Azure SQL / Postgres
- ORM：Prisma
- 认证：Microsoft Graph API + OAuth 2.0

### 所需权限

- `User.ReadWrite.All`：创建和管理用户
- `Directory.ReadWrite.All`：管理目录和许可证

### 常见问题

- 授权回调 400：同一个 OAuth code 只能用一次
- 403 获取 SKU：需管理员同意 Directory.ReadWrite.All 权限
- 分配许可证报 invalid usage location：需设置 ENTRA_USAGE_LOCATION（如 CN / US）

## 关键概念

- **Microsoft Graph API**：微软统一的 REST API，可管理 Azure AD / Entra ID 中的用户、组、许可证等资源
- **兑换码模式**：通过预生成的兑换码实现批量账户分发，避免直接暴露管理接口
- **Office 365 E3**：企业版 Office 许可证，包含完整 Office 套件和高级功能
