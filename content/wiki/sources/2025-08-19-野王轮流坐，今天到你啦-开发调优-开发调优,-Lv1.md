# 野王轮流坐，今天到你啦——Harvester API密钥采集工具

## 概要

介绍从 ai-collector 项目拆分出的开源工具 Harvester，用于从 GitHub 和 Fofa 等平台自动采集各类 AI 服务的 API Key。支持 session 池、token 池、线程池等多种限流规避策略，具有全面、快速、可配、简单四大优势。

## 核心内容

### 工具特点
1. **全** — 支持各类 AI 服务 API Key 的采集扫描
2. **快** — session 池、token 池、线程池最大化避免限流
3. **活** — 全部功能可通过配置自定义
4. **简** — 配置有默认值，搜索条件一个正则表达式全覆盖

### 使用方式
- **Github API 模式** — 需要 Github Token
- **Github Web 模式** — 需要 Github User Session（推荐）
- 获取 Session：浏览器 F12 → Application → Cookie
- 支持通过 Fofa 等服务手动搜索网址列表后加入任务

### Key 状态分类
- `Valid` — 调用接口成功，能正常使用
- `No Quota` — Key 有效但无额度
- `Wait` — 返回 429 状态码（限流）
- `Invalid` — 无效 Key

### 项目背景
- 从 ai-collector 拆分，2024 年已支持 Gemini 打野
- 作者从 2023 年开始打野，纯爱好驱动
- 未来计划抽象为面向 Github、Fofa 的通用数据采集框架

## 关键概念

- **API Key 采集（打野）** — 从公开代码仓库中搜索泄露的 AI 服务 API 密钥
- **池化策略** — 通过 session 池、token 池分散请求以规避平台限流
- **Provider 扩展** — 继承 IProvider 接口可采集其他类型的凭证（如机场订阅）
