# 自制羽衣甘蓝果蔬汁：一周轻断食饮品

## 概要
6款以羽衣甘蓝为核心食材的果蔬汁配方，覆盖一周轻断食饮品需求。每款搭配不同水果和液体基底，2分钟即可制作完成，兼顾营养补充、减脂掉秤和肠道健康。来源为小红书分享笔记。

## 核心内容
### 羽衣甘蓝的营养价值
- 超级食物代表，低热量高营养
- 富含维生素C和膳食纤维
- 具有抗氧化功效

### 6款配方
- **配方1**：羽衣甘蓝4根 + 香蕉1根 + 半颗苹果 + 半根黄瓜 + 300mL椰子水（甜而不腻）
- **配方2**：羽衣甘蓝4根 + 菠萝7小块 + 半根黄瓜 + 300mL椰子水（超级好喝）
- **配方3**：羽衣甘蓝4根 + 猕猴桃1个 + 香蕉1根 + 300mL纯净水（清肠效果显著）
- **配方4**：羽衣甘蓝4根 + 胡萝卜半根 + 香蕉1根 + 半根黄瓜 + 300mL纯净水（口感清爽）
- **配方5**：羽衣甘蓝4根 + 猕猴桃1颗 + 半根黄瓜 + 半个橙子 + 300mL纯净水（解渴养肤）
- **配方6**：羽衣甘蓝4根 + 蓝莓16颗 + 火龙果半个 + 300mL纯净水（富含花青素）

### 注意事项
- 羽衣甘蓝去掉根部，只保留叶子
- 脾胃寒凉者少喝
- 替代奶茶等高糖饮品，健康掉秤

## 关键概念
- **轻断食**：通过控制饮食热量和时间窗口来促进代谢的饮食方式
- **羽衣甘蓝（Kale）**：十字花科蔬菜，被誉为"超级食物"，营养密度极高
- **花青素**：强效抗氧化物质，蓝莓和火龙果中含量丰富
