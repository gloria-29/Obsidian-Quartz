# CodePilot 保姆级入门攻略

> 藏师傅纯 Vibe Coding 开发的全平台开源通用 Agent 客户端，支持 Claude/OpenAI 授权登录、Skills/MCP/Plugin、IM 远程连接、生成式 UI 等能力。

## 核心观点
- 全平台通用 Agent 客户端（Mac/Windows/Linux），GitHub 5100+ Star
- 支持多种模型接入：Claude 授权登录、OpenAI 授权、国产模型 Codeplan、三方 Anthropic API、Ollama 本地模型
- 助理模式与 Obsidian 深度集成，拥有长期记忆和心跳机制，项目管理+记忆整理
- 独有生成式 UI 能力：AI 可实时生成可视化图表、流程图，可 Pin 到看板持续更新
- 支持通过飞书/微信/QQ/Discord 远程连接 Agent

## 关键概念
- [[CodePilot]] — 藏师傅开发的全平台开源 Agent 客户端，Vibe Coding 产物

- [[助理模式]] — Agent 的长记忆+主动执行模式，类似龙虾的心跳机制
