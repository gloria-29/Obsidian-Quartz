# Nian 应用用户分享与问题解答

## 概要
Nian（念）是一款纯离线的 Android 笔记应用，源于已停运的「念」应用的单机版本。所有数据存储在本地手机，无需账号、不联网、无广告，支持标准记本、清单、记账、打卡、对话、计时等多种记录形式。本文档汇集了用户社区的使用分享链接和常见问题解答。

## 核心内容

### 应用定位
- 「念」停止运营后的单机离线版本，专注日常文本记录和回顾
- 所有数据保存在手机 nian 文件夹，无需第三方服务器
- 永久免费、无广告、不申请无用权限，安装包仅约 5MB
- 项目已迭代近 10 年，持续维护中

### 用户社区分享
- B站、小红书、豆瓣、酷安等平台有大量用户分享使用体验
- 用户整理了视频分享（海弈安系列）和图文攻略
- 社区反馈和问题解答集中在 GitHub Discussions 和 Telegram 群组

### 记本类型
- **标准记本**：支持封面、背景、简介，可合并和转移进展
- **清单记本**：类似 Todo，支持桌面小组件
- **记账本**：多个账本分类记录消费
- **打卡记本**：每日打卡督促习惯养成，支持 NFC 感应打卡
- **对话/问答本**：自问自答式记录
- **网址本**：记录常用网址
- **计时本**：记录场景用时，支持 NFC

### 数据管理
- 图片默认复制到 nian 文件夹，可设置剪切模式
- 音视频直接引用源文件，建议先统一存放再插入
- 手动备份：压缩 nian 文件夹拷贝至电脑或云盘
- 第三方同步方案：Syncthing（局域网）、FolderSync + 坚果云

### 常见问题
- 刷机/换机：将 nian 文件夹从旧手机拷贝到新手机根目录，保持目录位置一致
- 仅支持 Android，无 iOS 和纯血鸿蒙版本
- 不开源、不集成 WebDAV，由专业第三方工具处理同步
- 版本号格式：年.月.当月版次（如 2025.03.1）

## 关键概念
- **离线优先** — 所有数据本地存储，不依赖网络和服务器，避免应用下架、数据丢失风险
- **DeepLink 支持** — 提供 nian:// 协议的页面跳转，可与其他应用联动
- **NFC 打卡** — 通过 NFC 卡片感应快速完成打卡或计时操作
- **link 应用** — 局域网远程录入工具，可通过浏览器向手机 nian 发送文本
