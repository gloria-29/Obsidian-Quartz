# Ollama 常用指令总结

## 概要

Ollama 是一个轻量级的本地大语言模型运行框架，支持在个人电脑上运行多种开源模型。本文总结了 Ollama 的常用命令和操作方法。

## 核心内容

### 基础命令
- `ollama serve` — 启动 Ollama 服务
- `ollama list` — 查看已下载的模型列表
- `ollama pull <model>` — 下载指定模型
- `ollama run <model>` — 运行模型并进入对话

### 模型管理
- `ollama show <model>` — 查看模型详细信息
- `ollama rm <model>` — 删除指定模型
- `ollama cp <source> <dest>` — 复制模型

### 高级用法
- 支持 Modelfile 自定义模型参数
- 可通过 API 接口集成到其他应用
- 支持 GPU 加速推理

## 关键概念

- **Ollama**：开源本地 LLM 运行框架，简化模型部署流程
- **Modelfile**：自定义模型配置文件，定义系统提示词和参数
- **本地推理**：在用户设备上运行 AI 模型，无需云端服务
