# Sing-box 代理工具小白 UI 配置教程

> 从零开始，全程 UI 界面操作，手搓一份全平台通用的 Sing-box 配置文件，实现精准分流、无 DNS 泄露、低功耗无感运行。

## 核心观点
- 使用 GUI.for.SingBox 图形化面板，完全无需编写代码
- 通过规则集 + 出站设置 + 路由设置三步实现精准分流（以 Gemini 走美国节点为例）
- 三大多端同步方案：局域网扫码、配置文件导入、云端直链自动更新
- 裸核运行是关键优化：各平台通过不同设置实现后台无感运行，iPad 24小时仅耗电约 4%/天
- 内置 Sub-Store 插件用于订阅管理和格式转换

## 关键概念
- [[Sing-box]] — 新兴通用代理内核，支持 DNS 分流和多协议，替代 Clash 的方案
- [[DNS泄露]] — 代理环境下 DNS 请求未走加密通道导致的隐私泄露
- [[TUN模式]] — 虚拟网卡模式，接管全局流量，类似"总电闸"
- [[规则集]] — 汇总特定场景下所有域名/IP 的配置文件，用于精准分流
