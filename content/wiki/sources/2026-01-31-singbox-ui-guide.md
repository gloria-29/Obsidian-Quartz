# Sing-box 代理工具小白 UI 配置教程

## 概要

一篇面向新手的 Sing-box 全平台配置教程，全程使用 GUI.for.SingBox 图形界面操作，无需编写代码。涵盖订阅导入、Sub-Store 插件使用、精准分流配置（以 Gemini 走美国节点为例）、DNS 泄露防护、多端同步方案以及裸核运行优化，iPad 24小时裸核运行平均仅耗电约4%/天。

## 核心内容

### 快速上手（懒人配置）

- 解压 GUI.for.SingBox 安装包，双击打开面板，切换简体中文
- 设置页面勾选规则集，内核页面更新 singbox 内核
- 概览页面快速开始，输入 singbox 格式订阅链接保存后启动内核
- 配置页面右键复制配置文件到剪切板，粘贴为 `.json` 文件即完成基础配置

### 订阅转换

- **Sub-Store 本地转换**：插件中心搜索 sub 添加 Sub-Store 纯净版，浏览器中打开后添加订阅，选择对应格式复制
- **在线转换**：使用 sing-box-node.com 等在线工具将 Clash 订阅转为 sing-box 格式（存在订阅泄露风险）

### 精准分流配置

- **规则集**：规则集中心搜索目标网站（如 gemini），添加源文件，复制远程链接用于多端同步
- **出站设置**：为规则集创建出口，选择指定节点（如所有美国节点），类型选手动选择或自动选择
- **路由设置**：将规则集与出口关联，完成精准分流规则制定

### 多端同步方案

- **局域网扫码**：插件中心安装"共享配置到手机"，选择目标设备内核版本后扫码导入
- **配置文件导入**：生成 .json 配置文件后在其他设备从文件导入
- **云端自动同步**：将配置文件上传获取直链，其他设备填入远程 URL 即可自动更新

### 裸核运行优化

- **Windows/mac**：设置页面取消"程序退出时关闭核心"，直接关闭 GUI 面板不影响内核运行
- **Android**：VPN 设置中启用"始终开启 VPN"，后台不可见实现无感运行
- **Apple 系列**：设置中选择"按需启动-始终启动"，杀死后台即可裸核运行，可隐藏 VPN 图标

### 功耗实测

- Windows 观看 YouTube 4K 视频时占用极低
- Android（小米）正常使用6小时电量消耗可忽略
- iPad（2021款）24小时裸核运行，近一周平均耗电约4%/天

## 关键概念

- **Sing-box**：新兴通用代理内核，支持 DNS 分流和多协议，被视为 Clash 的替代方案
- **DNS 泄露**：代理环境下 DNS 请求未走加密通道而由本地网络处理，导致隐私泄露。Sing-box 基于独特的 DNS 分流特性，默认配置即无 DNS 泄露
- **TUN 模式**：虚拟网卡模式，接管所有流量（类似"总电闸"），比系统代理更不容易 DNS 泄露但速度略慢。系统代理类似"插排"，谁插谁用
- **规则集**：将特定场景下所有域名或 IP 汇总到一起的配置文件，用于实现精准分流
- **裸核运行**：关闭 GUI 面板仅保留内核进程运行，降低资源占用，各平台有不同实现方式
