# free-for.dev 免费开发者资源列表

## 概要

由 1600 多人协作维护的免费开发者级别服务汇总列表（free-for.dev），涵盖 SaaS、PaaS、IaaS 等各种免费套餐产品。仅收录"即服务"产品，需提供至少一年的免费套餐。是开发者寻找免费工具和服务的权威参考。

## 核心内容

### 资源范围
- 基础设施：云服务器、数据库、存储、CDN 等免费套餐
- 开发工具：CI/CD、代码托管、监控、日志等免费层
- API 服务：AI 模型、支付、邮件、短信等免费额度
- 学习平台：在线课程、认证考试等免费资源

### 筛选标准
- 仅限"即服务"（as-a-Service）产品
- 必须提供至少一年的免费套餐
- 非限时试用或一次性优惠
- 社区协作维护，持续更新

### 社区协作模式
- 1600+ 贡献者通过 GitHub PR 提交和审核资源
- 开源项目，透明的贡献和审核流程
- 定期更新，移除已停止免费套餐的服务

## 关键概念

- **SaaS/PaaS/IaaS** — 软件/平台/基础设施即服务，云服务的三种层次
- **Free Tier** — 云服务商提供的永久免费使用额度（非试用期）
- **社区维护** — 通过开源协作模式保持资源列表的时效性
