# 通用书籍阅读笔记提示词

> 三套不同风格的书籍阅读笔记生成 Prompt 模板，包括 Cubox/豆包版、DeepSeek版和通用版。

## 核心观点
- Cubox版结构：主旨提炼(200字) + 内容剖析(1200-2500字) + 感悟分享(100字)
- DeepSeek版结构：核心观点(400字) + 主要内容(2000字) + 个人感悟(100字)，按主题分段阐述
- 完整版结构：核心观点提炼(150字) + 主要内容(2000字，分成因/策略/思维转变各600字) + 个人感悟(300字，含观念冲击/实践联想/阅读评价)
- 所有模板均强调用自己的语言总结而非过度引用原文，结合实际例子增强实用性
