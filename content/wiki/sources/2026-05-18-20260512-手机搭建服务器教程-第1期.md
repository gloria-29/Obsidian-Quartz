# 手机搭建服务器教程：第 1 期

## 概要

linux.do 社区系列教程的第一期，讲解利用闲置手机搭建长期稳定运行服务器的前期必备条件。核心论证两个前提：具备公网 IPv6 访问能力和可 Root 的手机。作者从旁路供电、自动重启恢复、IPv6 异常恢复三个维度详细解释了为什么 Root 是长期运行的必要条件。

## 核心内容

### 条件一：公网访问

- **IPv4**：家庭宽带很少分配公网 IPv4，如有则最佳
- **IPv6**：国内家庭宽带基本都支持公网 IPv6，手机卡同样支持
- **验证方法**：访问 testipv6.cn 测试；`24` 开头地址 = 支持公网 IPv6，`fe80` 开头 = 设备支持但未分配
- **宽带 vs 手机卡**：推荐使用宽带（无流量限制、上传速度 50-200Mbps）

### 条件二：可 Root 的手机

**旁路供电**：Root 后可使用 Acc+AccA 或 QSC 控制充电行为，减少长期满电的发热损耗

**重启后自动恢复**：通过 Magisk 开机脚本自动启动 Debian、SSH、Nginx、Node.js 等服务

**IPv6 异常恢复**：编写脚本定时检查公网 IPv6，丢失后自动重连 Wi-Fi 并更新 DDNS

### 推荐手机

- 一加、摩托罗拉等容易 Root 的品牌
- 购买前先在酷安/闲鱼/淘宝确认机型是否支持 Root

## 关键概念

- **旁路供电**：让充电器直接供电给手机主板而不经过电池的供电模式
- **Acc+AccA**：Android Charge Control 应用，Root 后可控制充电阈值
- **Magisk**：Android Root 方案，支持开机脚本和模块化系统修改
- **DDNS**：动态域名解析服务，将变化的 IPv6 地址绑定到固定域名
- **Termux**：Android 终端模拟器，可在手机上运行 Linux 环境
