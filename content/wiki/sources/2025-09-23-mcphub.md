# MCPHub — MCP 服务器聚合平台

## 概要

MCPHub 是一站式 MCP 服务器聚合平台，将多个 MCP 服务器组织为灵活的流式 HTTP（SSE）端点。支持按需访问全部服务器、单个服务器或按场景分组的服务器集合，提供控制面板进行管理。

## 核心内容

### 平台架构

- 聚合多个 MCP 服务器到一个统一的 SSE 端点
- 支持分组管理：将服务器按功能场景组织为集合
- 提供 Web 控制面板进行可视化管理和监控

### 核心功能

- 一键接入：将分散的 MCP 服务器统一接入
- 灵活路由：按需选择访问全部、单个或分组服务器
- 场景化配置：为不同使用场景预设服务器组合
- 简化 MCP 服务器的管理和扩展工作

### 技术特点

- 使用 SSE（Server-Sent Events）作为通信协议
- 简化了 MCP 客户端需要管理多个连接的复杂度
- 支持动态添加和移除 MCP 服务器

## 关键概念

- **MCPHub** — MCP 服务器聚合平台，提供统一的管理和访问入口
- **SSE** — Server-Sent Events，服务器推送事件的通信协议
- **MCP** — Model Context Protocol，模型上下文协议
