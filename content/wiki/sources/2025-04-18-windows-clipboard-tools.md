# Windows 剪贴板软件推荐

> 社区推荐的 Windows 剪贴板增强工具合集，以 Clipdiary 为主要推荐方案。

## 核心观点
- Clipdiary 是社区首选推荐：免费、绿色免安装、支持文字/截图/文件等多种类型的复制历史
- 可以记录复制来源（哪个网站/应用），并直接打开原网址
- 其他备选方案：CopyQ(开源)、Ditto、EcoPaste、剪切助手、PasteMate

## 关键概念
- [[Clipdiary]] — Windows 剪贴板历史管理工具，支持多种内容类型和来源追踪
- [[Ditto]] — 老牌开源剪贴板管理工具
- [[CopyQ]] — 跨平台开源剪贴板管理器，支持脚本自定义
