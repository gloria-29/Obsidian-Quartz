# Gemini API 共享与讨论

## 概要
来自 LINUX DO 社区的讨论帖，汇总了多个免费 Gemini API 公益站和 Key 共享资源。讨论起源于使用 Cline 搭配 Gemini 2.5 Pro 写代码的场景，发现不需要购买昂贵的 GCP 赠金也能使用高质量 AI 模型。帖中持续更新了多个社区共建的 API 共享项目。

## 核心内容

### 社区资源汇总
- **GeminiKey共享池**：社区共建的 Gemini key 池子
  - https://linux.do/t/topic/513525
- **综合号池**：包含 Gemini、DeepSeek、GROQ 等多个模型
  - https://linux.do/t/topic/486675
- **Gemini 公益站**：可用于酒馆等场景
  - https://linux.do/t/topic/536462
- **Gemini 2.5 Pro 公益站**：改版后每人至少可用 5 万次
  - https://linux.do/t/topic/557872

### 2025年5月新增资源
- **CloseAI API**：支持 Gemini 2.5 Flash/Pro、DeepSeek-V3/R1、Qwen3 等模型
  - https://linux.do/t/topic/619961
- **Gemini 2.5 Pro Preview 05-06** 最新版本讨论
  - https://linux.do/t/topic/634711

### 背景与动机
- 使用 Cline（AI 代码助手）搭配 Gemini 2.5 Pro 可大幅降低编码成本
- 社区共建模式：通过公开 API Key 或搭建代理站实现免费使用
- 部分资源已删除（2025年5月13日），说明稳定性有限

## 关键概念
- 公益 API 站：社区成员搭建的免费 AI 模型接口代理服务
- Gemini 2.5 Pro：Google 的高性能 AI 模型，适用于代码生成和复杂推理
- Cline：VS Code 中的 AI 代码助手插件，支持接入多种 LLM
- 号池/Key池：共享的 API 密钥池，通过轮换使用实现免费访问
