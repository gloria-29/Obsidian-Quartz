# Free API — LLM 免费大模型接口集合

## 概要

LLM-Red-Team 维护的免费大模型 API 封装项目，聚合了国内主流大模型的免费接口，包括 Kimi（Moonshot）、跃问（阶跃星辰）、通义千问（Qwen）、智谱清言（GLM）等。支持高速流式输出、联网搜索、长文档解读、图像解析和多轮对话，为开发者提供零成本接入多种大模型的途径。

## 核心内容

### 支持的大模型
- **Kimi (Moonshot AI)**: 月之暗面的长上下文模型，擅长长文档处理
- **跃问 (阶跃星辰)**: 阶跃星辰旗下的对话模型
- **通义千问 (Qwen)**: 阿里巴巴的大语言模型系列
- **智谱清言 (GLM)**: 清华系智谱 AI 的对话模型
- 还包括其他多个国内大模型的免费接口

### 核心功能特性
- **高速流式输出**: 实时返回生成内容，用户体验接近原生 API
- **联网搜索**: 部分模型支持实时搜索互联网获取最新信息
- **长文档解读**: 支持上传和解析长篇文档，提取关键信息
- **图像解析**: 支持多模态输入，可以理解和分析图片内容
- **多轮对话**: 保持上下文连贯的连续对话能力
- **多路 token 支持**: 可配置多个 token 进行负载均衡

### 技术实现
- 项目地址：llm-red-team.github.io/free-api/
- 零配置部署，开箱即用
- 基于各模型官方接口的封装，保持 API 兼容性
- 社区维护，持续更新以应对接口变化

### 使用场景与局限
- 适合个人开发者和学习者免费体验各种大模型
- 可用于 [[AI提示词工程]] 的实验和测试
- 存在稳定性和合规性风险——非官方接口可能随时失效
- 与 [[DeepSeek]] 等直接提供免费/低价 API 的模式互补

## 关键概念

- **LLM-Red-Team**: 维护免费大模型 API 封装的开源社区项目
- **API 封装（API Wrapper）**: 通过逆向或代理方式将非公开接口转化为标准 API 格式
- **多路 Token**: 使用多个账号或 token 轮换调用，绕过单账号的速率限制

## 关联实体

- [[DeepSeek]] — DeepSeek 后来提供了官方的低价 API，是免费 API 的正规替代方案
- [[MCP]] — 免费 API 可作为 MCP 工具生态中的模型供应商
