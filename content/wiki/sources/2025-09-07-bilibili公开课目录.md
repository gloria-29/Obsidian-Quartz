# Bilibili 公开课目录

## 概要

GitHub 开源项目（elder-frog/OpenCourseCatalog），系统整理了来自 YouTube 等平台的优质公开课程资源，并搬运至 Bilibili 方便国内用户观看。涵盖多个学科领域的高质量课程，使用 GPL-3.0 许可证。

## 核心内容

### 项目概况

- **维护者**：elder-frog（B站空间：space.bilibili.com/12721139）
- **许可证**：GPL-3.0
- **目标**：打破信息壁垒，让国内用户便捷获取全球优质公开课资源
- **形式**：GitHub 目录式整理，按学科分类

### 课程来源与覆盖范围

- 主要来源为 YouTube 平台的知名大学和机构公开课
- 搬运至 Bilibili 后方便国内无翻墙观看
- 覆盖多个学科领域，包括但不限于计算机科学、人文社科、自然科学等

### 使用方式

- 通过 GitHub 仓库浏览课程目录
- 按学科或主题筛选感兴趣的课程
- 直接跳转 Bilibili 观看搬运版本

## 关键概念

- **公开课搬运**：将海外优质教育资源本地化
- **GPL-3.0 许可证**：项目采用的开源许可证
- **目录式整理**：按学科体系结构化整理课程资源
