# SJSU 学生福利和申请指南

## 概要

San Jose State University（SJSU）夏季招生的学生福利汇总指南。通过学生邮箱可免费获取 Adobe 全家桶、Office 365、JetBrains 全系列、GitHub 学生包、VPN、Windows 虚拟机等多项教育优惠资源。

## 核心内容

### 可获取的福利清单
1. **VPN** — SJSU 校园 VPN 服务
2. **Adobe 全家桶** — 学生邮箱登录 + 在线申请（约一天通过）
3. **Windows 虚拟机** — Windows App 学生邮箱直接登录
4. **Office 365** — 学生邮箱登录，OneDrive 1TB + Microsoft 365 Copilot
5. **GitHub 学生包** — 挂 VPN 操作，使用学生邮箱注册
6. **JetBrains** — 秒下号，全系列 IDE 免费使用
7. **Gemini Student** — 学生版 Gemini
8. **Grok** — 已有用户验证通过
9. **Autodesk 教育** — 教育版软件
10. **ChatGPT EDU PLUS** — 学生免费两个月

### 申请技巧
- 不一定有邮件通知，等两三天后直接尝试重置密码
- 建议挂着 VPN 领取，领取后可不挂 VPN 使用
- GitHub 学生证可用 AI 生成辅助制作
