# CBrain — 用导图重构知识结构

## 概要

CBrain 是国内独立开发者王小C打造的个人知识管理系统，融合思维导图、Markdown 编辑、知识量可视化和目标管理于一体。灵感源自 TheBrain 的网状知识结构理念，但以更轻量、更易上手的方式实现，旨在降低知识管理成本、构建可持续的知识体系。适合注重知识结构化沉淀的个人用户。

## 核心内容

### 核心设计理念
- **降低知识管理成本**: 不需要复杂配置即可开始使用，减少"管理知识的工具本身成为负担"的问题
- **构建可持续知识体系**: 强调长期积累而非一次性整理，知识量可视化让用户看到自己的成长
- **结构化沉淀**: 思维导图天然支持层级和关联结构，比纯线性笔记更符合人脑认知模式

### 核心功能
- **聚焦/全局导图模式**: 聚焦模式查看单个知识分支，全局模式纵览整个知识网络
- **vditor 编辑器**: 集成 vditor Markdown 编辑器，支持富文本和 Markdown 双模式编辑
- **知识量分析图表**: 可视化展示知识积累量的变化趋势，提供量化反馈
- **目标任务管理**: 将知识管理与目标追踪结合，学习和行动一体化
- **节点式结构**: 每个知识点是导图上的节点，可自由建立层级和关联关系
- **本地部署**: 数据存储在本地，保障隐私安全，不依赖云端服务

### 与 TheBrain 的关系
- CBrain 的设计灵感直接来自 TheBrain，两者都采用网状知识结构
- TheBrain 是商业化产品（有免费版但功能受限），CBrain 则面向个人用户提供更轻量的开源替代
- CBrain 在 TheBrain 的基础上加入了更适合中文用户的 Markdown 编辑和知识量可视化功能

### 适用场景
- 学术研究中的文献和知识脉络整理
- 个人学习体系的构建和长期维护
- 项目管理中的任务分解和进度追踪
- 写作和内容创作中的素材组织

## 关键概念

- **知识量可视化**: 通过图表将知识积累的过程量化展示，提供正反馈循环
- **节点式知识结构**: 每个知识点作为独立节点，通过关联关系形成网络，而非严格的树状层级
- **vditor**: 开源的所见即所得 Markdown 编辑器，支持多种编辑模式
- **聚焦模式**: 在庞大的知识导图中聚焦到特定分支，降低认知负荷
