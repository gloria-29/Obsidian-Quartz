# Freeplane Markdown Helper 插件

## 概要

Freeplane Markdown Helper 是一个思维导图工具 Freeplane 的辅助插件，用于在 Freeplane 和 Obsidian 之间实现双向导出和整合。

## 核心内容

### 插件功能

- 实现 Freeplane 和 Obsidian 之间的内容互通
- Markdown 格式导出和导入
- 思维导图节点与笔记的关联

### 使用场景

- 在 Freeplane 中构建思维导图，同步到 Obsidian
- 利用 Obsidian 的笔记管理能力增强 Freeplane
- 两种工具的互补使用

### 技术特点

- 插件形式集成到 Freeplane
- 支持 Markdown 作为中间格式
- 保持思维导图的结构信息

## 关键概念

- **Freeplane** — 开源的思维导图软件，功能强大
- **双向导出** — 在两个工具之间实现内容的导入和导出
- **Markdown** — 轻量级标记语言，作为工具之间的通用格式
