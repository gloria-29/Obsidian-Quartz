# 下载 GitHub 仓库特定目录

## 概要

从GitHub仓库中下载特定目录（而非整个仓库）的多种方法汇总，涵盖从GUI到CLI、从第三方工具到原生Git功能的完整方案。适用于大型仓库中只需要部分文件的场景。

## 核心内容

### 方法对比

| 方法 | 仅目录 | GUI | CLI | 适用场景 |
|------|--------|-----|-----|---------|
| GitHub网页 | 否 | 是 | 否 | 单个文件下载 |
| Download ZIP | 否 | 是 | 否 | 整个仓库 |
| DownGit | 是 | 是 | 否 | 指定目录下载 |
| GitZip扩展 | 是 | 是 | 否 | 浏览器内直接操作 |
| GitHub API | 是 | 否 | 是 | 自动化/脚本化 |
| Sparse Checkout | 是 | 否 | 是 | 无需第三方依赖 |
| npx degit | 是 | 否 | 是 | JS/TS项目最快 |

### 推荐方案

**最简单**：DownGit（粘贴URL即下载）

**最灵活**：Git Sparse Checkout
```sh
git init
git remote add origin <repo-url>
git sparse-checkout init --cone
git sparse-checkout set <folder-path>
git pull origin <branch>
```

**最快捷（JS/TS项目）**：npx degit
```sh
npx degit <user>/<repo>/<folder> <destination>
```

**脚本化**：GitHub REST API + wget/curl

## 关键概念

- **Sparse Checkout**：Git 2.25+ 支持的部分克隆功能，只下载指定目录
- **DownGit**：第三方Web工具，粘贴GitHub目录URL即可下载ZIP
- **degit**：轻量级项目脚手架工具，直接从GitHub拉取目录内容
