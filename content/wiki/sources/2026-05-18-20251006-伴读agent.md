# Agent 伴读 -- Paper Burner X 一站式 AI 翻译/阅读/分析工作站

## 概要

Agent 伴读（Paper Burner X）是一款专为学术和工作场景打造的开源、即开即用的 AI 翻译/阅读/分析工作站。纯浏览器可用，融合 Agent 智能体机制，支持长文本处理、多格式文档翻译（保留 PDF 格式）、多种 OCR 引擎、术语备择库、批量翻译等功能。作为 [[GenericAgent]] 类工具在学术场景的落地实践，体现了 [[AI工具与应用-扩展]] 中 AI 辅助阅读的发展方向。

## 核心内容

### 核心功能
- **保留格式的 PDF 翻译**：通过 MinerU 结构化翻译模式，解决传统工具破坏 PDF 格式的问题
- **AI 对话与长文本处理**：引入 Agent 机制，为 AI 提供 grep、vector search、map、fetch 等工具；支持"意群/地图"机制保持全局视角
- **多种 OCR 支持**：mistral、doc2x、mineru 三种引擎可选
- **翻译格式扩展**：导入支持 PDF/MD/TXT/DOCX/PPTX/HTML/EPUB/YAML；导出支持 DOCX/PDF 等，可选原文/译文/对比模式
- **术语备择库**：自动匹配原文块并注入固定译文，提升翻译一致性
- **提示词池**：由元提示词生成系列相似提示词，增强模型可用性
- **批量翻译**：支持整库翻译、文件夹翻译（含 GitHub 仓库）

### AI Agent 机制
- 纯浏览器环境下运行，无需本地后端
- AI 根据需求智能判断所需上下文，主动获取感兴趣内容
- 支持 Embedding 模型配置，实现向量搜索
- 成本可控：可关闭 Embedding 和意群/地图机制减少消耗
- 测试模型包括 grok-4-fast、gemini-2.5-flash 等

### MIT 研究启示：AI 依赖对认知的影响
- LLM 组论文同质性显著，人脑组多样性更强
- 大脑功能连接性随外部认知辅助增加而系统性下降
- 习惯性依赖 LLM 会损害深层语义加工能力，移除 AI 后 78% 受试者无法回忆相关内容
- **教育建议**：学习初期延迟引入 AI，先纯人脑后用 AI 的模式展现更高元认知参与

## 关键概念

- **Agent 伴读**（Paper Burner X）：开源 AI 翻译阅读工作站
- **结构化翻译**：保留 PDF 原始格式的翻译模式
- **意群/地图机制**：帮助 AI 维持长文本全局视角的技术
- **术语备择库**：提升翻译一致性的术语管理方案
- **认知负荷理论**：AI 辅助工具对学习能力的长期影响
