# 日本 xserver 永久免费 3核4G 云服务器

> 日本 xserver 提供永久免费的 VPS 方案（3c4g/2c2g），需定期签到续期，注册需日本 IP 和非 +86 手机号。

## 核心观点
- 两种免费规格：3c4g（每2天签到续期）、2c2g（每4天签到续期）
- GitHub 上有自动签到脚本可自动化续期
- 注册需要日本 IP、当地信息、非 +86 手机号（支持 TextNow/GV 等虚拟号）、信用卡验证（约2日元）
- 语音验证码是日语播报，可用 AI 语音识别提取
- 封号风险较高，作者账户第二天被封
