# 优化远程桌面 Windows 电脑以最小化功耗和延长电池寿命

> 从系统电源管理、远程连接配置、后台服务、硬件保养、网络优化五个维度优化远程桌面场景下 Windows 电脑的能效。

## 核心观点
- 电源管理：启用节能模式、限制 CPU 最大状态(50%-70%)、缩短硬盘关闭时间、禁用蓝牙等非必要硬件
- 远程连接优化：降低分辨率和颜色质量(16位色)、关闭视觉效果、设置较短会话超时(10分钟)
- 网络优化：关闭音频重定向和打印机映射、优先使用有线网络以减少 Wi-Fi 模块功耗
- 电池保养：维持电量在 20%-80%，长期插电时启用电池保护模式

## 关键概念
- [[远程桌面优化]] — 通过降低显示负载和限制会话资源来减少远程连接的系统开销
- [[Windows 电源管理]] — 控制 CPU 频率、硬盘关闭时间、USB 选择性暂停的系统电源配置
- [[电池保养策略]] — 避免极端电量(0%或100%)以延长锂电池寿命
