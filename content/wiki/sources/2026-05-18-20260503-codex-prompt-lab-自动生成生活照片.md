# Codex Prompt Lab：自动生成生活照片

## 概要

X 用户 MapleShaw（msjiaozhu）分享的 [[Codex (OpenAI Coding Agent)]] 使用技巧——利用 Codex 的代码执行能力搭建 "Prompt Lab"，自动生成逼真的生活随拍风格照片。帖子获得 8 万+ 浏览，引发社区对 AI 图像自动化生成工作流的广泛兴趣。仅使用 OpenAI Plus 即可运行，未触及 5 小时用量上限。

## 核心内容

### Prompt Lab 工作流

作者将 Codex 变成一个自动探索的个人 Prompt Agent，核心思路包括：

1. **搭建 Prompt Lab**：用 Codex 批量管理和执行图像生成提示词
2. **Gallery 打分**：让 AI 对生成结果自动评分筛选
3. **每小时自动探索**：设置定时任务让 Codex 自主生成新图
4. **外部扰动**：引入外部 prompt 或参考图片作为变化因素
5. **场景扩展**：从生活照扩展到游戏、电商、广告、文旅等场景

### 提示词设计理念

核心目标是生成"相册里翻到的生活切片"风格照片，关键设计原则：

- **追求不完美**：模糊、歪斜、手抖、构图不完美，但情绪到位
- **iPhone 相机质感**：竖屏、闪光灯、高 ISO 噪点、业余构图
- **自然动作**：mid-step、转身、低头看手机等抓拍瞬间
- **物理可信**：雨滴、运动模糊、前景玻璃/塑料质感
- **约束条件**：无水印、无品牌 logo、无可读文字、非低分辨率、非过度精修

### 社区反馈

- 普通 Plus 用户可稳定运行，无需额外 API 费用
- 有用户提出可用遗传算法+市场评分替代人工打分
- "外部扰动"机制是最受期待的进阶功能

## 关键概念

- **Prompt Lab**：利用 AI 代码执行能力搭建的自动化提示词实验环境
- **生活随拍风格（Candid）**：模拟真实手机随手拍的照片风格，强调不完美和情绪感
- **Gallery 打分**：AI 对批量生成图片进行自动质量评估的机制
- **外部扰动**：引入外部输入（prompt/图片）来打破生成模式的重复性
- **定时自动探索**：设置 cron 任务让 AI 自主迭代提示词并生成新内容
