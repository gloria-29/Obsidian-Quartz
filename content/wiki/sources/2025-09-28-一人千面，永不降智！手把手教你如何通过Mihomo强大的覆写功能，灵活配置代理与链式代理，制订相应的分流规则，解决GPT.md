# 一人千面，永不降智 — Mihomo 代理覆写与分流规则配置指南

## 概要

手把手教你通过 Mihomo（原 Clash Meta）强大的覆写功能，灵活配置代理与链式代理，制订分流规则，解决 GPT 降智问题，并实现无限试用 Cursor。核心思路是通过精细化的节点分流，让不同服务走不同的代理出口。

## 核心内容

### 解决的核心问题

- **GPT 降智**：由于 IP 信誉问题，部分代理节点会导致 ChatGPT 响应质量下降（"降智"）。通过覆写规则让 GPT 请求走高质量节点
- **Cursor 无限试用**：通过轮换不同出口 IP 绕过 Cursor 的试用限制

### Mihomo 覆写功能

Mihomo 的覆写（Override）功能允许在不修改原始配置文件的情况下，动态注入或修改：

- 代理节点分组
- 分流规则（按域名、IP、GeoIP等）
- 链式代理配置（Proxy Chain）

### 分流策略

- 为 ChatGPT 指定低延迟、高信誉的节点
- 为 Cursor 分配独立出口，轮换 IP
- 其他流量走默认代理组
- 通过规则优先级实现"一人千面"——同一设备上不同应用走不同出口

### 链式代理

多层代理嵌套，第一层代理的出口作为第二层的入口，用于进一步隐藏真实 IP 或绕过更严格的限制。

## 关键概念

- **Mihomo**：原 Clash Meta，支持 Meta 内核的代理客户端，功能比原版 Clash 更强大
- **覆写（Override）**：在不修改原始配置的情况下动态注入规则和节点配置
- **分流规则**：根据域名、IP、协议等条件决定流量走向
- **GPT 降智**：ChatGPT 因 IP 信誉降低而返回低质量响应的现象
