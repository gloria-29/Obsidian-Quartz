# DinoxAI 笔记 Claude Skill 安装与使用指南

> 与 DinoxAI 笔记系统深度集成的 OpenClaw/Claude Skill，支持创建、查询、更新笔记和 AI 问答。

## 核心观点
- DinoxAI 笔记 Skill 通过 Claude Skill 标准封装，让用户用自然语言操作笔记系统
- 支持功能：Markdown 创建笔记、语音转文字、关键词搜索、AI 问答、更新笔记
- 安装流程：克隆到 OpenClaw skills 目录 -> 安装 pip 依赖 -> 配置 API Token
- 提供 `/dinox` 斜杠命令，支持 create-md、search、ask、boxes、get、update 等子命令

## 关键概念
- [[Claude Skill]] — Anthropic 推出的 AI 能力扩展标准，通过 SKILL.md 定义工作流
- [[OpenClaw]] — 开源个人 AI 助手，支持通过聊天应用交互
- [[Dinox]] — AI 笔记系统，基于 Zettelkasten 卡片盒笔记法
