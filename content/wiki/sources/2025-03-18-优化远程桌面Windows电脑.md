# 优化远程桌面 Windows 电脑功耗配置

## 概要

针对使用远程桌面的 Windows 电脑，从系统电源管理、远程桌面会话配置、后台服务管理、硬件维护和网络优化五个维度，提供最小化功耗和延长电池寿命的具体配置建议。

## 核心内容

### 系统电源管理
- 启用节能模式，将最大处理器状态设为 50%-70%
- 缩短硬盘关闭时间（如 5 分钟），启用 USB 选择性暂停
- 禁用蓝牙、摄像头、背光键盘等非必要硬件

### 远程桌面会话配置
- 设置结束已断开会话时间为 10 分钟，减少并发连接数
- 降低分辨率和颜色深度（16 位色），关闭 Windows 动画和透明效果
- 关闭音频重定向、打印机映射等非必要数据传输

### 硬件与网络优化
- 电池保养：维持电量 20%-80%，启用电池保护模式限制充电至 80%
- 定期清理风扇灰尘确保散热良好
- 优先使用有线网络减少 Wi-Fi 模块功耗

## 关键概念

- **RDP** — Remote Desktop Protocol，Windows 远程桌面协议
- **USB 选择性暂停** — 关闭未使用 USB 设备供电以节省功耗
- **会话超时** — 自动断开闲置远程会话，释放系统资源
