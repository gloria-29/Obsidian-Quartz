# SurfSense Docker 安装指南

## 概要

SurfSense 的 Docker Compose 部署指南，这是项目推荐的首选部署方式。要求预先安装 Docker、Docker Compose 和 Git 环境，提供详细的步骤说明。

## 核心内容

### 前置条件

- 已安装 Docker 和 Docker Compose 环境
- Git 版本控制工具
- 基本的命令行操作知识

### 部署步骤

- 克隆项目仓库到本地服务器
- 使用 Docker Compose 启动服务和依赖
- 配置环境变量和网络设置
- 验证服务正常运行

### 技术特点

- Docker 化部署简化了依赖管理和环境配置
- Compose 编排支持多服务同时启动
- 适合需要快速部署 SurfSense 的用户场景
