# AI API Gateway：统一的多模型 API 网关

> 一个通用 AI API 网关服务，通过单一入口点提供 Claude、ChatGPT、Gemini 和 Midjourney 的 API 访问。

## 核心观点
- 统一网关简化多模型 API 管理：通过一个 API Key 即可访问多种 AI 模型
- 保持与原 API 兼容的请求格式，降低迁移成本
- 支持流式输出（Stream），适合实时交互场景

## 关键概念
- [[API Gateway]] — 统一管理和路由多个后端服务 API 请求的网关层
- [[Claude Code]] — Anthropic 的代码生成助手，可通过 API 调用
- [[MCP]] — Model Context Protocol，AI 模型与外部工具交互的协议
- [[Midjourney]] — AI 图像生成服务
