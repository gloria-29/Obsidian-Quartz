# 对象存储定价一览表

> 主流 S3 兼容对象存储服务商在 1TB 存储 + 1TB 出站流量基准下的价格横向对比。

## 核心观点
- 性价比最高：Backblaze B2($6/TB/月)、Hetzner($5.99/TB/月)、Wasabi($6.99/TB/月)
- Cloudflare R2 零出口流量费($15.36/TB/月)，最适合高出站流量的应用场景
- 大型云厂商(AWS/Azure/GCP)通常成本更高，不适合价格敏感用户
- 自建 [[MinIO]] 方案成本可能更低但需自行维护

## 关键概念
- [[Cloudflare R2]] — 零出口流量费的对象存储服务，适合流量密集型应用
- [[Backblaze B2]] — 极低成本的对象存储，提供3倍存储量的免费出站流量
- [[Wasabi]] — "热存储"方案，无出口流量费，有最低存储承诺
- [[S3 兼容存储]] — 遵循 Amazon S3 API 标准的第三方对象存储服务
