# 双语电子书制作操作流程

## 概要

使用 bilingual_book_maker 开源工具，通过 OpenAI API 将英文电子书（EPUB/TXT）翻译为中英双语版本的完整操作流程。工具基于 Python，支持 GPT-3.5 和 GPT-4 模型，可自定义翻译 Prompt 和批量翻译参数。

## 核心内容

### 环境准备

```bash
cd /path/to/bilingual_book_maker
export OPENAI_API_KEY=<your_key>
```

### 基本用法

- **测试运行**：`python3 make_book.py --book_name test_books/animal_farm.epub --test --language zh-hans`
- **翻译 EPUB**：`python3 make_book.py --book_name <文件路径> --language zh-hans`
- **翻译 TXT**：`python3 make_book.py --book_name <文件路径> --language zh-hans`
- **使用 Azure GPT-4**：添加 `--api_base` 和 `--deployment_id` 参数

### 可选参数

- `--test`：测试模式
- `--openai_key`：设置 API key
- `--model gpt3`：切换模型
- `--single_translate`：只输出翻译后单语版本
- `--batch_size 20`：指定批量翻译行数
- `--prompt`：自定义翻译 Prompt（支持 txt/json/参数三种方式）

### 关于模型选择

GPT-4 太贵且升级主要在数学和编程方面，翻译任务 GPT-3.5 足够，无需追求 GPT-4。

## 关键概念

- **bilingual_book_maker**：开源双语电子书制作工具，GitHub 项目
- **EPUB**：电子书标准格式，支持富文本和样式
- **批量翻译**：将文本分成多行同时翻译，提高效率
