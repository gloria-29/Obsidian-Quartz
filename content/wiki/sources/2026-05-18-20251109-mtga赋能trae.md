# MTGA 赋能 Trae：聚合国内外大模型

## 概要

通过开源工具 MTGA 结合公益 API 站，实现 Trae 编程 IDE 同时接入国内和国际大模型。MTGA v1.2.0 版本支持在 Trae 中只需添加一次模型配置，后续可在 MTGA 端直接切换模型，无需在 Trae 中重复操作。完全免费使用。

## 核心内容

### 工作原理
- MTGA 通过本地代理方式绕过 IDE 的固定模型服务商限制
- 结合公益 API 站（api.dev88.tech）提供国际大模型访问
- Trae 国内版自带国内大模型 + 公益站 API 国际大模型，实现一统天下

### 配置步骤
- 下载 MTGA v1.2.0，管理员运行
- 在公益 API 广场选择模型（如 gemini-2.5-flash），复制模型名称
- 在 MTGA 填写 API 网址、模型名称、生成密钥
- 映射模型 ID 填写 MTGA，鉴权 Key 填写 123456
- 安装证书、修改 HOSTS 后启动服务，再到 Trae 配置自定义模型

### 多模型切换
- 可在 MTGA 中新增多组模型配置（如 claude-3-5-haiku）
- 切换模型只需在 MTGA 端操作，Trae 端无需变动
- 通过公益站日志页面验证实际调用的模型

## 关键概念

- **MTGA** — 基于本地代理的模型转发工具，绕过 IDE 模型限制
- **Trae** — 字节跳动推出的 AI 编程 IDE，国内版支持自定义模型
- **公益 API** — 社区提供的免费 AI 模型接口服务
