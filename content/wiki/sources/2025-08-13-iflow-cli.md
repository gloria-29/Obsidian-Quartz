# iFlow CLI — 终端 AI 编程助手

## 概要

iFlow CLI 是一款直接在终端中运行的 AI 编程助手，能够分析代码仓库、执行编程任务、理解上下文需求。它提供多种免费 AI 模型选择，预配置了 MCP 服务器和专业代理，支持自然语言驱动开发。作为终端原生的 AI 编程工具，它与 [[Claude Code]]、[[Codex (OpenAI Coding Agent)]] 等工具处于同一赛道。

## 核心内容

### 核心特性
- **免费 AI 模型**: 提供 Kimi K2、Qwen3 Coder、DeepSeek v3 等免费模型，降低使用门槛
- **OpenAI 协议兼容**: 支持接入任何遵循 OpenAI API 协议的模型
- **MCP 服务器预配置**: 内置专业 MCP 服务器和代理，开箱即用，与 [[MCP协议与工具生态系统]] 对齐
- **自然语言驱动**: 用自然语言描述需求，AI 自动执行相应的编程任务
- **上下文理解**: 能分析整个代码仓库的结构和上下文，不只是单文件操作

### 安装与使用
- **macOS/Linux**: 通过 curl 脚本一键安装
- **Windows**: 通过 npm 或 nvm 安装
- **前置要求**: Node.js 18+
- **启动命令**: `iflow` 直接启动
- **项目初始化**: `/init` 命令让 AI 理解项目结构
- **认证方式**: iFlow 原生认证或 OpenAI 兼容 API 连接

### 与同类工具对比
- [[Claude Code]]: Anthropic 出品，基于 Claude 模型，功能更全面但需要付费
- [[Codex (OpenAI Coding Agent)]]: OpenAI 出品，推理能力强
- iFlow 的差异化在于免费模型支持和 MCP 预配置，适合预算有限的开发者
- 与 [[Trae]]、[[CodeBuddy]] 等国内 AI 编程工具形成互补生态

### 适用场景
- 个人开发者快速原型开发
- 学习和探索 AI 辅助编程的最佳实践
- 与 [[AI编程与开发工具]] 生态中的其他工具配合使用
- 需要免费模型支持的场景

## 关键概念

- **终端 AI 助手（Terminal AI Assistant）**: 在命令行终端中运行的 AI 编程工具，通过自然语言与开发者交互
- **MCP 预配置**: 提前配置好 MCP（Model Context Protocol）服务器，用户无需手动设置即可使用工具能力
- **上下文感知（Context-Aware）**: AI 能理解整个项目的代码结构、依赖关系和编码规范
