# 内容总结助手

## 概要

一套结构化的内容总结 Prompt 模板，覆盖 YouTube、PDF、书籍、文章、网页、代码等多种内容类型。通过标准化的分步骤工作流和丰富的快捷操作指令（图表、文章、引用、记忆卡片、测试题等），实现从原始内容到知识产品的高效转化。适用于 [[AI工具与应用-扩展]] 场景下的批量内容处理需求。

## 核心内容

### 输入适配策略

| 内容类型 | 处理方式 |
|----------|---------|
| YouTube 链接 | 安装字幕提取插件，复制字幕文本 |
| 网页链接 | 尝试直接访问，失败则要求用户粘贴 |
| 书籍 | 利用模型已有知识处理 |
| 代码 | 逐部分解释说明 |
| 任意文本 | 直接进入总结步骤 |

### 总结模板结构（约800字）

1. **标题** — 内容标题
2. **内容概述** — 两句话描述核心主题
3. **结论** — 本地化结论 + 6句详细阐述
4. **关键点** — 10个要点，用表情符号区分，段落形式呈现，侧重实用性
5. **本地化总结** — 10条编号列表，每项两句话
6. **快捷操作菜单** — 9种后续操作指令

### 快捷操作指令系统

- **[D]** 创建图表 — Mermaid LR 格式，自动渲染并提供下载
- **[A]** 转成文章 — Markdown 完整文章，可直接复制
- **[E]** 扩展总结 — 超过2000字的分板块详尽总结
- **[Q]** 提取引用 — 8-20条实用引用，附时间戳
- **[C]** 生成记忆卡片 — 约20张，含填空内容
- **[Z]** 创建测试题 — 约20道测试题
- **[T]** 创建表格
- **[R]** 查找更多信息 — 使用浏览器重复搜索至少4次
- **[F]** 编写FAQ

### 行为规范要求

- 分板块分析，覆盖全部内容，优先关注近期事件
- 包含具体细节（数字、地点、品牌等）体现深入理解
- 避免重复，不含无关细节
- 初次未得到结果时坚持在不同片段中继续查找
- 使用者用何种语言提问就用何种语言回复

## 关键概念

- **结构化总结模板** — 预定义的7步输出格式，确保总结的一致性和完整性
- **指令驱动交互** — 用户通过单字母命令触发后续深度操作
- **内容适配策略** — 根据输入类型（视频/网页/书籍/代码/文本）选择不同处理路径
- **本地化输出** — 所有输出随用户语言自动适配，包括标题和操作菜单
