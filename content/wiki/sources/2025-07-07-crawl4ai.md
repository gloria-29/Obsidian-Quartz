# Crawl4AI：LLM友好型Web爬虫

## 概要

Crawl4AI 是 GitHub 上排名第一的开源（Apache-2.0）Web爬虫工具，专为 LLM、AI Agent 和数据管道设计。它能将网页内容自动提取为 AI 可直接处理的 Markdown 格式，支持深度爬取、结构化数据提取、Docker 部署和 MCP 集成。截至记录时已获得 47.3k GitHub Stars，813 次提交，活跃开发中。

## 核心内容

### 设计定位
- 专为 LLM 优化的爬虫，生成智能简洁的 Markdown，适配 RAG 和微调场景
- 速度比同类工具快 6 倍，启发式算法降低对昂贵 LLM 模型的依赖
- 完全开源，无需 API Key，支持 Docker 和云部署
- 作者 UncleCode 因不满现有 SaaS 爬虫收费且质量不佳而从零构建

### 核心能力
- **Markdown 生成**: Clean Markdown（结构化输出）+ Fit Markdown（启发式去噪）+ BM25 过滤
- **结构化数据提取**: 支持 LLM 驱动提取（兼容所有主流模型）和 CSS/XPath 无 LLM 提取
- **浏览器集成**: 会话管理、代理支持、持久化用户配置、多浏览器兼容（Chromium/Firefox/WebKit）
- **深度爬取**: BFS/DFS/BestFirst 策略，内存自适应调度器动态调整并发
- **CLI 工具**: `crwl` 命令行直接爬取，支持深度爬取和 LLM 提问

### v0.6.0 新特性
- 全球感知爬取：设置地理定位、语言和时区获取本地化内容
- 表格直接转 CSV/pandas DataFrame
- 浏览器池化 + 预热，降低延迟和内存占用
- 网络流量和控制台日志捕获，MHTML 快照调试
- [[MCP]] 集成：一键连接 [[Claude Code]] 等 AI 工具（`claude mcp add --transport sse c4ai-sse https://localhost:11235/mcp/sse`）

### 部署方式
- Python 包安装：`pip install crawl4ai && crawl4ai-setup`
- Docker 部署：`docker pull unclecode/crawl4ai:0.6.0-rN`，含交互式 Playground
- 支持 PyTorch、Transformer、Cosine Similarity 等可选扩展

## 关键概念

- **Fit Markdown**: 基于启发式过滤的 AI 友好 Markdown，去除导航、广告等噪音，保留核心内容
- **LLM Extraction Strategy**: 利用 LLM 从网页中提取结构化 JSON 数据，支持 Pydantic Schema 定义
- **Browser Profiler**: 持久化浏览器配置文件，保存登录状态和 Cookie，实现多步爬取
- **MCP 集成**: 通过 [[MCP]] 协议将爬虫能力暴露给 AI 工具，实现 Agent 自主网页数据获取
