# Anx Calibre Manager — 电子书管理应用

## 概要

一款移动端优先的 Web 电子书库管理应用，与 Calibre 深度集成，提供个人 WebDAV 服务器。支持 Anx-reader 兼容设备，方便在移动设备上管理和阅读电子书。

## 核心内容

### 核心功能

- 移动端优先的 Web 界面，优化手机和平板使用体验
- 与 Calibre 电子书管理系统深度集成
- 内置个人 WebDAV 服务器，方便跨设备同步
- 支持 Anx-reader 等兼容阅读设备

### 技术特性

- 使用 GPL-3.0 开源许可证
- 支持 Docker 部署，简化安装和升级流程
- 提供多语言界面，降低使用门槛
- 基于 Web 技术，无需安装原生应用

### 使用场景

- 个人电子书库的远程管理和访问
- 在移动设备上浏览、搜索和下载电子书
- 自托管替代商业电子书管理服务

## 关键概念

- **Calibre** — 功能强大的开源电子书管理软件
- **WebDAV** — 基于 HTTP 协议的文件管理扩展，支持远程访问和同步
- **Anx-reader** — 兼容 Anx Calibre Manager 的电子书阅读设备
