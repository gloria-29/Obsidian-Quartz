# GPT-Image-1.5 实测与 Prompt 指南

## 概要

浮之静对 ChatGPT 全新旗舰图像模型 GPT-Image-1.5 进行实测体验。新版模型在生成速度、指令遵循能力和API成本方面均有显著提升，并新增 Images 创作空间功能，适合品牌电商等需要跨编辑保持视觉一致性的工作流。

## 核心内容

### 性能提升

- 生成速度最高提升4倍，大幅缩短等待时间
- 指令遵循能力显著增强：只修改要求改的部分，同时保持光照、构图与人物外观一致性
- API 侧图像输入/输出成本降低20%，降低企业级使用门槛

### 新增功能

- 新增 Images 创作空间，通过侧边栏入口访问
- 提供预设滤镜和灵感模板，降低创意启动门槛
- 适合品牌电商等需要跨编辑保持视觉一致性的工作流

### Prompt 指导要点

- 利用更强的指令遵循能力，可以精确指定修改范围而不影响整体风格
- 光照和构图一致性使得系列化内容生产更加可靠
- 品牌视觉资产管理变得更高效，团队成员可共享一致的视觉规范

## 关键概念

- **GPT-Image-1.5**：OpenAI 推出的新一代旗舰图像生成模型，在速度、质量和成本三方面均有优化
- **Images 创作空间**：ChatGPT 内置的图像创作界面，提供滤镜和模板等预设工具
- **视觉一致性**：在多次生成中保持光照、构图、人物外观等要素的统一，对品牌电商至关重要
- **指令遵循**：模型精确执行用户指令的能力，新版仅修改指定部分而不破坏整体画面
