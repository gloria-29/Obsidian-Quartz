# 安卓手机设置Webshare代理

## 横要

详细介绍在安卓手机上使用Webshare购买的IP代理的三种方法：代理APP直连、系统WiFi代理设置、以及Termux本地转发。涵盖具体操作步骤和注意事项。

## 核心内容

### 方法一：使用代理APP
- **HTTP Proxy Client**：在Google Play下载，输入Webshare代理IP、端口、用户名和密码即可连接
- **Shadowsocks**：下载安卓版，创建新配置输入服务器IP、端口、密码，选择加密方式（通常aes-256-cfb）
- **V2rayNG**：在Google Play下载，导入Webshare配置或手动设置

### 方法二：设置系统代理（仅WiFi）
1. 长按已连接的WiFi网络
2. 选择"修改网络"→ 勾选"显示高级选项"
3. 在代理设置中选择"手动"
4. 输入Webshare代理IP和端口，如需认证输入用户名密码

### 方法三：使用Termux本地转发
1. 安装Termux终端应用
2. 安装Python：`pkg install python`
3. 安装必要包：`pip install requests pysocks`
4. 创建简单的代理转发脚本将本地端口转发到Webshare代理

### 注意事项
- 使用代理服务需遵守当地法律法规
- 不同Webshare代理计划有不同限制和功能
- 根据具体服务选择合适的连接方式

## 关键概念

- **Webshare**：提供住宅/数据中心IP代理的服务商，需通过中间节点使用
- **SOCKS代理**：通用代理协议，支持TCP和UDP流量转发
- **系统代理**：Android WiFi层面的代理设置，仅对该WiFi连接生效
