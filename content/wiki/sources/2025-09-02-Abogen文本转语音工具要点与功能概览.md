# Abogen 文本转语音工具要点与功能概览

## 概要

Abogen 是一款基于 Kokoro-82M 的开源文本转语音（TTS）工具，可将 ePub、PDF、TXT 文件快速转换为高质量音频并生成同步字幕。支持 Windows/Linux/macOS 三平台，适用于有声读物制作和短视频配音。生成约 1 分钟音频仅需 5 秒。

## 核心内容

### 核心功能
- **输入**：支持 ePub、PDF、TXT 文件拖放，内置文本编辑器
- **输出**：音频（WAV/FLAC/MP3/OPUS/M4B）+ 字幕（SRT/ASS）
- **语音控制**：0.1x-2.0x 语速调节，多语言声音选择
- **语音混合器（Voice Mixer）**：混合不同语音模型创建自定义声音——同类工具中少见的特色功能

### 高级书籍处理
- **章节控制**：选择特定章节转换，可独立保存或合并为单文件
- **元数据支持**：自动为 M4B 文件添加标题、作者等标签
- **队列模式**：多文件批量处理，每个文件可保留独立配置

### 安装部署
- **Windows**：提供 `WINDOWS_INSTALL.bat` 自动化脚本（推荐），自动处理 Python + CUDA 依赖
- **Mac/Linux**：通过 `pip` 安装，针对 Apple Silicon 和 AMD ROCm 有详细说明
- **Docker**：提供完整 Dockerfile

### 关键限制
- **字幕生成目前仅支持英语**（Kokoro 库技术限制）
- 需要 Python 环境，非零配置工具

### 技术栈
- 语音合成引擎：Kokoro-82M
- GUI 框架：PyQt
- 电子书解析：EbookLib
- 开源许可：MIT

## 关键概念

- **Kokoro-82M**：轻量级高质量 TTS 模型，82M 参数
- **Voice Mixer**：Abogen 独特功能，通过混合不同语音模型创建个性化声音
- **同步字幕**：音频播放时可同时显示对应文字，支持按句子/单词/逗号分段
- **M4B 格式**：支持章节标记的有声书专用音频格式
