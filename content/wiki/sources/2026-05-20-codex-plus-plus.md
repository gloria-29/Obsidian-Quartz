# Codex++ 增强版

## 概要

Codex++ 是 OpenAI Codex 的社区增强版本，解决了原版缺少删除功能、API Key 模式下插件灰掉等问题。该项目在 GitHub 上获得了开发者社区的广泛关注。

## 核心内容

### 原版 Codex 的问题
- 缺少文件删除功能，影响代码重构效率
- API Key 模式下部分插件功能被禁用（灰色不可点击）
- 社区反馈的问题长期未得到官方修复

### Codex++ 的改进
- 补全了删除等缺失的核心功能
- 修复了 API Key 模式下的插件兼容性问题
- 保持与原版 Codex 的兼容性，便于迁移

### 社区反响
- GitHub 上获得大量关注和 star
- 开发者社区积极贡献代码和反馈
- 成为 Codex 生态中重要的社区分支

## 关键概念

- **OpenAI Codex**：OpenAI 推出的 AI 编程助手
- **Codex++**：社区维护的 Codex 增强版本
- **API Key 模式**：使用自定义 API Key 调用服务的方式
