# 沉浸式翻译Prompt分享

## 概要

来自 LINUX DO 社区的沉浸式翻译 Prompt 分享帖，针对 DeepSeek-v3-0324 模型优化。原帖作者在社区大佬的基础上进行了精简和改进，大幅缩减了 Prompt 长度、降低了口语化表达，在保证翻译质量的同时节省了 token 消耗。提供了 System Prompt、普通 Prompt、Multiple Prompt 和 Subtitle Prompt 四种场景的完整 Prompt。

## 核心内容

### System Prompt（核心翻译指令）
- 要求：符合目标语言母语者表达习惯、灵活转换语气、意译而非直译
- 结构：from→to 语言方向、内容类型、参考资料（标题/摘要/术语）
- 关键技巧：重复"仅输出译文"防止模型自作主张添加说明

### 四种 Prompt 场景
1. **System Prompt**：通用翻译场景，最完整的指令
2. **Prompt**：简化版，仅保留核心翻译要求
3. **Multiple Prompt**：批量翻译 YAML 格式内容
4. **Subtitle Prompt**：字幕翻译，保持 YAML 结构仅修改内容

### DeepSeek-v3 的 Prompt 特性
- V3 对中文 Prompt 响应更好，英文 Prompt 效果明显下降
- 需要重复"仅输出译文"和"Output ONLY translation"才能稳定输出
- 每次请求最大段落数设为1以上，避免两段译文挤在一起

### 测试样例
- 修仙小说评论翻译（网文语境）
- 国际新闻翻译（正式语境）
- 不同内容类型展示了 Prompt 的适应性

## 关键概念

- **沉浸式翻译（Immersive Translate）**: 浏览器翻译插件，支持自定义翻译Prompt
- **System Prompt**: 系统级指令，设定AI的整体行为模式
- **Token优化**: 精简Prompt长度以减少API调用成本
- **意译 vs 直译**: 翻译策略选择，意译更注重目标语言的自然表达
