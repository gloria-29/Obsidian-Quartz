# 小小的4c16g里承载了太多服务

## 概要
作者分享在 4c16g 服务器上搭建 Homelab 的经验，详细列出选用的 Docker 服务和多次选型迭代的过程，涵盖支持维护、基础服务、小工具和已弃用服务四类。

## 核心内容

### Support & Maintenance 工具
- **Nginx Proxy Manager** — 管理 Nginx 配置和 Certbot 证书更新
- **Portainer** — 管理容器及远端容器
- **Syncthing** — 数据同步与备份
- **Rustdesk Server** — 远程桌面中继服务器
- **Bark** — iOS 通知推送（比 ntfy 更好用）
- **Glances** — 服务器资源监控
- **Uptime-Kuma** — 服务健康监控，通过 Bark/Webhook 推送通知

### 基础服务
- **Home Assistant** — 智能家居管理，将小米设备桥接到 HomeKit
- **TriliumNext** — 笔记软件，Trilium 的重构优化版
- **n8n** — 低代码自动化：定时备份、每日早报、AI 文章总结等
- **LobeChat** — AI 聊天助手，配合 New-API 使用
- **Vaultwarden** — 密码托管
- **Gitea** — 本地 Git 仓库
- **NocoDB** — 低代码数据库

### 选型迭代经验
- 从 Dify 迁移到 n8n（AI 自动化转向更稳定的 n8n）
- 从 one-api 迁移到 new-api（更好维护的 AI Gateway）
- 从 NextChat 到 LobeChat（新模型支持更好）
- 弃用 NextCloud、Wallabag 等服务，逐步用更轻量的替代

## 关键概念
- **Homelab** — 自建家庭服务器环境，用于托管各类服务
- **选型迭代** — 经过长期使用和比较，不断淘汰和替换服务的过程
