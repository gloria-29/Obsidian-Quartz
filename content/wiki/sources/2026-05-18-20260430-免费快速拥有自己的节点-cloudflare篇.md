# 免费快速拥有自己的节点：[[Cloudflare]] 篇

## 概要

一篇面向零基础用户的 Cloudflare Pages 免费代理节点搭建教程，利用 EdgeTunnel 项目在 Cloudflare 全球网络上部署自建节点，实现无需自有服务器即可拥有翻墙能力。教程发布于 linux.do 社区，详细覆盖从账号注册到域名绑定的完整流程。

## 核心内容

### 部署流程

1. **创建 Pages 应用程序**：下载 Cloudflare Pages 演示压缩包，在 Cloudflare 控制台创建新 Pages 项目并上传
2. **设置管理员变量**：在项目设置中添加 `ADMIN` 文本变量，值为 WebUI 管理员密码
3. **绑定 KV 命名空间**：创建 Workers KV 命名空间（建议命名 `EDT2`），返回项目设置绑定变量名为 `KV` 的 KV 命名空间
4. **正式部署**：下载 EdgeTunnel 最新版本压缩包，上传部署到生产环境，使变量生效
5. **绑定自定义域名**：通过 CNAME 记录将自定义域名指向 Pages 项目地址

### 免费域名注册商

- DNSHE：部分域名可托管 Cloudflare
- DigitalPlat：部分域名可托管 Cloudflare
- ClouDNS：免费 DNS 托管
- dynv6 / ZoneABC

### 关键注意事项

- 项目名称必须全新，避免 1101 错误，建议末尾补数字
- ClouDNS 域名必须多加一级子域名（如 `edt2.xxx.cloudns.org`）
- 修改管理员密码后必须重新上传部署，否则变量不生效
- 部署完成后通过 `/admin` 路径访问管理页面

## 关键概念

- **EdgeTunnel**：开源项目，基于 Cloudflare Workers/Pages 的代理方案
- **Cloudflare Pages**：Cloudflare 提供的静态网站托管服务，可运行 Workers 脚本
- **Workers KV**：Cloudflare 的键值存储服务，用于 EdgeTunnel 存储配置
- **CNAME 记录**：域名解析记录类型，将自定义域名指向 Cloudflare Pages 地址
