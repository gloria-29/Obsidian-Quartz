# Dify 应用模板设计方案

## 概要

一套完整的 Dify 工作流模板设计方案，实现知识库搜索 + 多轮对话 + 工具调用功能，可通过 API 发布为外部可调用的智能助手。包含工作流 JSON 模板、部署配置、API 调用示例及与 GPTs/ChatGPT 插件的集成方案。

## 核心内容

- **核心工作流**：用户输入 → 输入判断（常规问题/指令操作）→ 知识库搜索 → LLM 生成回答 → 格式化输出
- **知识库检索节点**：配置 datasets ID、top_k=3、score_threshold=0.7 进行语义检索
- **LLM 处理节点**：基于检索上下文 + 用户问题 + 历史对话生成回答，temperature=0.2
- **部署配置**：
  - MEMORY_TYPE=redis 启用对话记忆，保留最近 5 轮
  - TOOL_ENABLED=true 开启工具调用
  - 支持自定义 Python 工具（如文件搜索）
- **API 集成**：通过 `/v1/workflows/run` 端点调用，支持 session_id 维持多轮对话
- **外部系统集成**：支持 GPTs Actions（OpenAPI 规范）和 ChatGPT 插件开发
- **最佳实践**：使用 txt/csv/pdf 格式文档、添加元数据标签、设置文档过期时间、启用 LLM 缓存、Rate Limit 30 req/min

## 关键概念

- **Dify 工作流**：Dify 平台的可视化 AI 应用编排方式，通过节点和边定义数据处理流程
- **知识库语义检索**：基于向量嵌入的文档检索，通过 score_threshold 控制相关性门槛
- **会话记忆（Memory）**：维持多轮对话上下文的机制，支持 Redis 持久化
- **工具调用（Tool Use）**：LLM 在生成过程中主动调用外部工具/API 的能力
