# Chat Plus：适配器驱动的 MCP 编排浏览器扩展

## 概要

Chat Plus 是一个面向 AI 聊天网站的浏览器扩展，通过适配器驱动架构将网页聊天 UI 接入 MCP 服务器与 Skills。核心特点是将 MCP 工具从"薄连接器"提升为"可编程运行时"，模型可在沙箱中编写 JavaScript 编排多个工具调用。

## 核心内容

### 架构设计

- **适配器驱动**：每个宿主站点一份独立 JS 适配器脚本，遵循四钩子契约（`transformRequest`、`extractResponse`、`decorateBubbles`、`continueConversation`）
- **按标签页独立编排**：每个页面可分别启用扩展、预设、服务器与工具
- **沙箱执行**：适配器和 Code Mode 都在隔离环境中运行，不直接操作页面上下文

### 工作流程

1. Chat Plus 连接已启用的 MCP 端点，发现并标准化工具清单
2. 注入完整的 `tools.*` 目录及描述到模型上下文
3. 模型输出 JavaScript 代码块调用工具（非原始 MCP 传输调用）
4. 沙箱执行代码，通过桥接层转发给后台 MCP 客户端（SSE/Streamable HTTP）
5. 结果流回沙箱，作为执行输出返回对话

### Code Mode

- 通过 `tools.<serverAlias>.<toolAlias>(args)` 访问已启用 MCP 工具
- 支持 `await`、`Promise.all`、`toolDocs.describe(ref)` 按需查看工具文档
- 禁止：DOM 访问、`window`/`document`/`fetch`、`import`/`export`

### 与 MCP-Gateway 集成

本地 `stdio` MCP 服务器或 `SKILL.md` 工作流需通过 [MCP-Gateway](https://github.com/510myRday/MCP-Gateway) 暴露为 SSE/HTTP 端点，再在 Chat Plus 中注册。

### 站点支持

已适配 ChatGPT、Gemini、Google AI Studio、豆包、Qwen Chat、Arena、小米 Mimo、Z.ai 等平台。

## 关键概念

- **适配器四钩子契约**：`transformRequest`（注入指令）、`extractResponse`（提取输出）、`decorateBubbles`（UI 渲染协议块）、`continueConversation`（自动续聊）
- **Code Mode 编排**：模型编写 JS 代码串联多个工具调用，检查中间结果，返回干净最终值
- **协议标记系统**：`toolCall`、`toolResult`、`codeMode` 等结构化协议块
- **适配器调试工作流**：基于真实请求/响应/DOM 证据开发，非猜测
