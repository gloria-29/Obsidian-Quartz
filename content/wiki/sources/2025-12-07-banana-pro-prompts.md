# Nano Banana Pro提示词大全：来自宝玉的26+模板

## 概要

宝玉(@dotey)在X上发布的26+个[[Nano Banana Pro]]高质量提示词合集，涵盖天气卡片、信息图、3D微缩场景、塔罗牌、素描画、漫画、日历插画、蜡笔旅行日记等创意场景。每个提示词都是可复用的框架模板而非一次性的炫技作品，体现了[[AI提示词工程]]中"提供模板而非成品"的设计哲学。

## 核心内容

### 提示词分类体系

1. **天气城市卡片**：等距3D微缩场景 + 实时气象数据 + 城市地标，文本匹配城市语言
2. **信息图系列**：手绘漫画风、黑板粉笔风、手写卡片风，支持多语言内容转换
3. **品牌微缩概念店**：3D Q版盲盒风模型（星巴克、麦当劳等），Cinema 4D渲染质感
4. **少儿涂色页 / 蜡笔旅行日记**：黑白线稿 + 彩色参考版，自动规划城市景点路线
5. **塔罗牌占卜**：星座运势 + 四张塔罗牌（爱情/事业/财富/健康）+ 魔法仪式圈
6. **股票微缩场景**：3D等距 + 实时股价数据，公司标志性建筑 + 产品元素
7. **古今混搭水墨画**：传统工笔 + 现代元素（如三英飙车战吕布）
8. **漫画转写实 / 写实名片**：保留角色特征的超写实转换，赛博美学名片设计

### 设计哲学

- 不追求单一惊艳作品，而是提供**可复用框架模板**
- 用户可将逻辑应用到自己的城市、场景甚至虚构地点
- Gemini + Nano Banana Pro 可在一回合内完成"联网获取数据 + 生成图像"
- 天气卡片概念此前在GPT-4o上无法实现，因需自定义API获取实时数据

### 技术亮点

- 等距3D（Isometric 3D）微缩场景风格贯穿多个模板
- 支持动态参数注入：城市名、日期、品牌名、生日等
- 融合PBR材质、柔和光照、电影级景深等专业渲染参数
