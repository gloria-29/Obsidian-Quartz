## 核心要点
- MCP Gateway 是一个 MCP（Model Context Protocol）服务器网关。
- 最常见的用途：把本地 MCP 服务转换成远程可访问的 MCP 服务，供桌面端或浏览器端 AI 客户端接入，使得网页端的ai聊天窗口可以使用工具和skills。
- 统一管理多个 MCP 服务（可视化 + JSON 双编辑模式） - 网关统一转发 ：默认 - 网关统一转发 ：默认 - 内置安全认证（Admin Token / MCP Token） - 标签页支持内置 Skill MCP 服务管理 - Skill 根目录校验（检测 ） - 路径守卫（白名单目录 + 越界策略） - 执行限制（超时、最大输出） - 策略规则（ ） - 待确认命令审批（Approve / Reject）。
