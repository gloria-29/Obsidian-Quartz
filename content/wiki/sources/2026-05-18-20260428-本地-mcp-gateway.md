# 本地 MCP Gateway

## 概要

MCP Gateway 是一个 Model Context Protocol 服务器网关，将多个 MCP Server 统一接入一个入口，提供代理转发、认证和管理 API。最常见的用途是把本地 stdio MCP 服务转换成远程可访问的 SSE/Streamable HTTP MCP 服务，使网页端 AI 聊天窗口也能使用工具和 Skills。

## 核心内容

### 功能总览

- 统一管理多个 MCP 服务（可视化 + JSON 双编辑模式）
- 网关统一转发 SSE 和 HTTP 请求
- 内置安全认证（Admin Token / MCP Token）
- SKILLS 标签页支持内置 Skill MCP 服务管理
- 策略规则（allow / confirm / deny）和待确认命令审批

### SKILLS 能力

- Skill 根目录校验（检测 SKILL.md）
- 路径守卫（白名单目录 + 越界策略）
- 执行限制（超时、最大输出）
- 策略规则配置（id/action/commandTree/contains/reason）

### 使用流程

1. 在 MCP 标签页配置监听地址和路径
2. 设置 Admin Token 和 MCP Token（建议生产环境开启）
3. 添加 MCP 服务并保存配置
4. 切换到 SKILLS 标签页完成 Skill 能力配置（可选）
5. 点击启动，复制生成的 SSE/HTTP 地址到 MCP 客户端

## 关键概念

- **MCP (Model Context Protocol)**：模型上下文协议，AI 工具调用的标准化协议
- **SSE (Server-Sent Events)**：服务端推送事件，用于流式数据传输
- **Streamable HTTP**：可流式传输的 HTTP 协议，MCP 的远程通信方式
- **stdio MCP**：基于标准输入输出的本地 MCP 服务通信方式
