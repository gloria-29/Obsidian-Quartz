# memos 生态

## 概要

memos 相关开源工具生态系统汇总。memos 本身是隐私优先的轻量级笔记服务，围绕它发展出多个客户端和展示方案：memos.top（静态展示页）、Memospot（桌面客户端）、MeowNocode（Cloudflare 无服务器方案）。

## 核心内容

### memos 核心服务

- **定位**：隐私优先的轻量级笔记和微内容记录服务
- **部署方式**：支持 Docker 自托管部署
- **特点**：类似微博/便签的快速记录体验，支持 Markdown，API 开放

### 生态工具

- **memos.top**：由 eallion 开发的 memos 静态展示页，通过 Memos API 渲染，使用纯 HTML + CSS + 原生 JS，支持暗黑模式和移动端自适应，兼容旧版（<v0.25.0）和新版 API
- **Memospot**：memos 的独立桌面客户端，支持 Windows/macOS/Linux，无需 Docker 即可本地使用，支持数据在实例间无缝迁移，特性包括易用、完整体验、最小开销、数据可移植、增强隐私
- **MeowNocode**：基于 Cloudflare 的无服务器方案，降低 memos 的部署和运维门槛

### 使用场景

- 个人知识碎片化记录和管理
- 微博客/轻量社交内容发布
- 自托管隐私笔记替代方案
- 与 Obsidian 等工具配合构建知识管理系统

## 关键概念

- **memos**：开源隐私优先轻量笔记服务，类似 Flomo 的自托管替代品
- **自托管（Self-hosted）**：在自己的服务器上部署和运行服务，掌握数据主权
- **Memos API**：memos 提供的开放接口，支持第三方客户端和展示页接入
- **无服务器架构**：MeowNocode 利用 Cloudflare Workers 等实现零服务器成本运行
