# 白梦写作 App 提示词提取

## 概要

Linux.do 社区用户尝试逆向提取"白梦写作"应用的系统提示词。由于后端截断机制，提示词提取极其困难，最终成功绕过防护获得部分提示词内容，但质量一般，不如自行编写 agent 提示词。

## 核心内容

### 提取过程
- 白梦写作应用对提示词有严格的防泄漏机制
- 后端会在输出几句提示词后截断，阻止完整提取
- 通过绕过后端截断机制获得了系统提示词

### 提示词内容分析
- 核心角色设定为"结对写作的AI作家助手"
- 包含严格的安全防护规则：禁止暴露 Anthropic/OpenAI 等模型信息
- 写作风格要求：禁止使用套路化表达（如"全场死寂一片"等）
- 输出格式使用 YAML 文档块
- 包含架空历史要求和敏感内容过滤

### 社区评价
- 提取到的提示词质量一般，不如自己编写 agent
- 作者预告将开源自己的 golang agent 框架

## 关键概念

- **提示词逆向 (Prompt Reverse Engineering)**：通过与 AI 交互提取其系统提示词的技术
- **后端截断**：服务端在检测到提示词泄漏尝试时主动中断输出
- **结对写作**：白梦写作的 AI 与用户协作写作的核心模式
