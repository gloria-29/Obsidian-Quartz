# L站福利及项目信息汇总（AI服务篇）

## 概要

LINUX DO 社区维护的 AI 领域资源、工具、教程和福利汇总文档（第三篇），系统整理了主流 AI 服务（Gemini CLI、Claude Code、AugmentCode、Cursor）的深入使用技巧、2API 转换方案、MCP 协议应用、自建 AI 系统、提示词工程以及客户端定制等资源。资源按社区用户等级（Lv0-Lv3）分级访问，核心价值在于通过逆向工程和开源工具降低获取高级 AI 服务的门槛。

## 核心内容

### 主流 AI 服务利用

| 服务 | 核心玩法 | 使用门槛 |
|------|---------|----------|
| **Gemini CLI** | Windows/Mac/Linux 配置、Deno 部署、MCP 集成（如查询 Obsidian）、API Pool 搭建 | Lv0-Lv1 |
| **Claude Code** | Windows/VSCode 教程、API 免费调用、Docker 化代理、接入 Gemini 1M 上下文 | Lv0-Lv1 |
| **AugmentCode** | 无限邮箱重置、自动注册脚本、AURA-X 协议 Rule、活动额度白嫖 | Lv0-Lv1 |
| **Cursor** | 教育邮箱白嫖 Pro、MCP 次数倍增（500次抵2500次）、注册脚本、Rule 模板 | Lv0-Lv3 |
| **Google One** | 学生优惠 BUG 获取 Pro 权限 | Lv0 |

### 两大技术热点

1. **MCP（Model Context Protocol）**：应用极其广泛——Excel 自动化、Chrome 浏览器控制、小红书自动化发布、飞书集成、Google 搜索、A 股分析。社区提供 5 万字实战教程、聚合管理服务器和 MCP Marketplace
2. **2API 转换**：将网页端 AI 服务逆向转换为 OpenAI 兼容 API 格式，支持 CodeGPT、Cursor、Augment、Trae、Gemini Canva 等，高难度转换需 Lv2-Lv3 权限

### 自建 AI 与工作流

- **部署方案**：手机端搭建酒馆、Docker/Deno/Cloudflare Workers 部署号池、Ollama 负载均衡
- **n8n 自动化**：汉化部署、Flux 绘图流、GitHub Star 通知、Notion 同步
- **知识库（RAG）**：Dify/RAGFlow 本地部署、文档预处理工具 VerbaAurea

### 提示词工程生态

- 破限/越狱提示词（如明澈-萌-色 V2）
- 实用工具型：文献阅读、代码开发 Rules、简历优化、深度搜索
- 生成美化：文生图（GPT-4o/Flux）、HTML 卡片、SVG 绘图

### 分级访问体系

| 等级 | 典型资源 |
|------|---------|
| Lv0 | Warp Pro 会员、Google One 学生优惠 BUG、基础 CLI 教程 |
| Lv1 | Augment/Cursor 活动额度白嫖、部分 2API 转换、Dify 本地部署 |
| Lv2 | 猛犸象 2API（Claude4）、cursor 半自动注册、高级 MCP 规则（RIPER-5） |
| Lv3 | v0.dev BUG 教程、Trae2API、Acli2Api、硅基注册机 |

## 关键概念

- **2API 转换**：将 Web/IDE 独占的 AI 服务逆向转换为 OpenAI 兼容 API 格式，实现自由集成
- **MCP（Model Context Protocol）**：模型上下文协议，用于扩展 AI 模型调用外部工具的能力
- **号池（Pool）**：多账号负载均衡系统，用于分散 API 调用压力和绕过单账号限制
- **破限提示词**：用于绕过模型安全限制的特殊提示词
- **公益 API**：社区共享的免费 API 代理服务
