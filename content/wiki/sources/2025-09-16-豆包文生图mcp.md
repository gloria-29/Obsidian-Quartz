# DouBaoFreeImageGen 豆包文生图MCP

## 概要

DouBaoFreeImageGen 是基于 FastMCP 框架开发的智能文生图 MCP 服务，通过浏览器插件与豆包客户端深度集成，提供标准化的 MCP 服务接口，支持无限次调用豆包文生图功能。项目开源，托管于 GitHub。

## 核心内容

### 项目概况
- **作者**: HuChundong
- **仓库**: github.com/HuChundong/DouBaoFreeImageGen
- **技术栈**: FastMCP 框架 + 浏览器插件 + 豆包客户端
- **特点**: 免费、无限次调用、标准化 MCP 接口

### MCP 协议集成
- MCP（Model Context Protocol）是 AI 工具间通信的标准协议
- 通过 MCP 接口，豆包文生图能力可被其他 AI 工具（如 Claude Desktop）调用
- 实现了 AI 绘画能力的标准化接入

### 豆包文生图能力
- 豆包是字节跳动旗下的 AI 产品
- 文生图质量较高，支持多种风格和场景
- 通过此项目，用户无需直接使用豆包 App 即可调用其图像生成能力

### 使用场景
- 与其他 MCP 工具链组合，构建 AI 创作工作流
- 批量图像生成需求
- 集成到自动化流程中

## 关键概念

- **MCP（Model Context Protocol）**: AI 模型与外部工具通信的标准协议，由 Anthropic 提出
- **FastMCP**: MCP 协议的快速开发框架，简化 MCP Server 的构建
- **文生图（Text-to-Image）**: 根据文字描述自动生成图像的 AI 技术
- **浏览器插件桥接**: 通过浏览器插件与豆包客户端通信的技术方案
