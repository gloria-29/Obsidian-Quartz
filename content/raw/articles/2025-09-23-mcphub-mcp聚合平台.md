# MCPHub - MCP 服务器聚合平台

MCPHub 是一站式 MCP 服务器聚合平台，将多个 MCP 服务器组织为灵活的流式 HTTP（SSE）端点。
支持按需访问全部服务器、单个服务器或按场景分组的服务器集合。
提供控制面板进行管理，简化了 MCP 服务器的管理与扩展工作。
