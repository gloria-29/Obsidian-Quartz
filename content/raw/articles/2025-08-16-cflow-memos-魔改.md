# cflow — memos 魔改版

基于 memos 0.18.2 版本的个人魔改版，主要定制功能包括：
- 标签分类优化、每日随机回顾、统计页改版、阅读打卡功能
- 图床支持：OSS/S3/R2/本地/docker环境兼容
- 微信号分享功能、@提及用户功能
- 优化 API 返回字段、界面 UI 改造

借助 GPT-4 辅助开发，"能运行就行"原则。
