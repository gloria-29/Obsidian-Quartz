# Elog — 开放式跨平台博客解决方案

Elog 是一款批量导出 Markdown 的工具，支持从语雀/Notion/FlowUs/飞书云文档等写作平台同步文档到 Hexo/VitePress/Hugo 等博客平台。

**支持的写作平台**：语雀（Token/账号密码）、Notion、FlowUs（息流）、飞书云文档、wolai、Outline

**支持的部署平台**：本地 Markdown、Halo、Confluence、WordPress

**图床支持**：本地、腾讯云 COS、阿里云 OSS、七牛云、又拍云、GitHub

**CLI 命令**：elog init / elog sync / elog clean / elog upgrade

**自动化**：支持 GitHub Actions + Serverless API + Webhooks 持续集成
