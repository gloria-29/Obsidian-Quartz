# iFlow CLI — 终端 AI 编程助手

一款直接在终端中运行的 AI 助手，能分析代码仓库、执行编程任务、理解上下文需求。

**核心特性**：免费 AI 模型（Kimi K2、Qwen3 Coder、DeepSeek v3 等）；支持 OpenAI 协议模型；预配置 MCP 服务器和专业代理。

**安装**：macOS/Linux 用 curl 脚本安装；Windows 通过 npm 或 nvm 安装。需要 Node.js 18+。

**使用**：`iflow` 启动；`/init` 命令初始化项目理解；支持自然语言描述需求。

**身份验证**：通过 iFlow 原生认证或 OpenAI 兼容 API 连接。
