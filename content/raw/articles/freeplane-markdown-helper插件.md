# Freeplane Markdown Helper 插件

Freeplane 思维导图软件的 Markdown Helper 插件（alpha 版），支持在 Freeplane 中以思维导图方式创建 Markdown 文档，是连接思维导图与 Markdown 写作的工作流工具。
