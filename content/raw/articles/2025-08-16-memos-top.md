# memos.top — memos 静态页面

通过 Memos API 渲染的静态网页。简单的 HTML、纯净的 CSS、原生的 JS。支持暗黑模式和移动端自适应。兼容老版（<v0.25.0）和新版（>=v0.25.0）两种 API。前端依赖：Highlight.js、Markedjs、ViewImage.js。
