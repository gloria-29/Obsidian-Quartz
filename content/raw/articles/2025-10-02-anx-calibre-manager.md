# Anx Calibre Manager - 电子书管理应用

一款移动端优先的 Web 电子书库管理应用，与 Calibre 集成，提供个人 WebDAV 服务器。
支持 Anx-reader 兼容设备，方便在移动设备上管理和阅读电子书。
使用 GPL-3.0 许可证，支持 Docker 部署，提供多语言界面。
