# 完善的轻量说说笔记系统及memos的开源替代品

基于 Ech0 开源框架二次开发的轻量说说笔记系统，类似朋友圈风格。支持 API 发布内容、一键部署、多平台推送（webhook/Telegram/企业微信/飞书）、B站/YouTube/网易云解析、一键生成内容图片、标签系统和热力图组件。

**核心特性**：一键部署到 fly.io/zeabur/railway/vercel；支持 SQLite/PostgreSQL/MySQL；图片上传和备份恢复；Popclip 快捷发布。

**技术栈**：Go 后端 + Vue 前端 + Docker 部署

**实体**：Ech0, memos, fly.io, Neon PostgreSQL
