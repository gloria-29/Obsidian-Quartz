# BaiTTS-CLI-rs - 有声书生成命令行工具

基于 MultiTTS API 的命令行工具（Rust 版本），用于将文本文档转换为有声书音频（.wav）并可生成同步 LRC 歌词文件。
是原 Python 版本 BaiTTS-CLI 的 Rust 重写版本，使用 GPL-3.0 许可证。
支持 .txt 文件输入，适用于有声书制作场景。
