# JiMeng4.0/即梦图片4.0模型 提示词手册.md at main · gloria-29/JiMeng4.0

### 《即梦图片4.0模型提示词手册》阅读笔记

---

#### 一、 全面摘要

该手册是为“即梦图片4.0模型”（JiMeng 4.0）编写的一份详尽的用户指南和提示词（Prompt）宝典。其核心内容围绕模型的三大一体化功能展开：**文生图、图像编辑、组图生成**。手册不仅介绍了模型在指令遵循、特征保持、意图理解、多图处理及生成速度与分辨率方面的五大亮点，还通过大量实例展示了其在**商业设计、艺术创作、娱乐玩法**等领域的广泛应用。更重要的是，手册提供了极具实践价值的“提示词秘籍”，指导用户如何撰写清晰、有效的指令来实现理想的图像生成与编辑效果，并附带了丰富的风格、美学、材质等关键词库作为创作参考。

#### 二、 主要观点与核心功能

文章的核心观点是，即梦4.0模型通过多模态技术的融合，将图像生成带入了一个“可控编辑”与“高效创作”的新阶段。其主要功能点可分解如下：

1.  **多模态一体化创作**：同一模型无缝支持从文本生成图像、对现有图像进行编辑修改，以及一次性生成多张有关联的组图，打通了创意工作流的多个环节。
2.  **精准的自然语言编辑**：用户可以通过日常语言（大白话）对图像进行精确操作，如对画面元素进行**增、删、改、换**，甚至可以参考另一张图的风格或内容进行融合。
3.  **高度的特征与画面保持**：
    *   **角色保持**：在不同风格（如插画、3D、摄影）之间转换时，能高度还原核心角色的特征。
    *   **画面保持**：编辑过程中能最大化保留原图细节，避免了AI常见的“油腻感”，实现无损编辑。
4.  **深度的意图理解与推理**：
    *   **知识升级**：具备专家级知识储备，能准确理解并生成包含专业知识（如数学公式）和复杂逻辑（如教程步骤）的图像。
    *   **灵感成形**：能将模糊、抽象的草图或想法具象化为高完成度的作品。
    *   **推理预测**：具备一定的逻辑推理能力，可以根据输入图像预测下一刻的状态或进行概念转换（如“把毯子叠好”）。
5.  **强大的批量处理能力**：
    *   **多图输入**：支持同时输入多张图片，进行复杂的组合、迁移和衍生创作。
    *   **组图输出**：能够一次性生成多张内容关联的图像，非常适合创意构思（脑暴）和故事分镜创作。
6.  **极致的性能**：生成速度快（2K图像不到1.8秒），且最高支持4K分辨率，为后期编辑提供了充足空间。

#### 三、 重要细节与提示词策略

手册提供了详尽的提示词撰写指南，是实现高质量输出的关键：

*   **编辑提示词公式**：遵循 **“变化动作 + 变化对象 + 变化特征”** 的结构，例如：“将（对象）骑士的头盔（特征）变为金色”。
*   **生图提示词结构**：建议用 **“连贯的自然语言描述画面内容”** + **“短词语/关键词描述画面美学”**。例如：“一个女孩撑着伞在林荫道上，莫奈油画风格，绿色调，低对比度”。
*   **关键技巧**：
    *   **保持一致性**：当需要保持特定角色或风格时，输入参考图效果最佳。
    *   **提升响应度**：使用专业词汇的源语言（如用`Macro lens shot`代替“微距镜头”）效果更准确。
    *   **明确用途**：在提示词中加入应用场景（如“手机壁纸”、“电影海报”）有助于模型生成更适配的构图和风格。
    *   **生成文字**：将需要生成的文字内容放入英文引号 `\\"\\"` 中，可提升准确率。
*   **问题自查清单**：手册提供了一个自查表，帮助用户修正指代不明、描述矛盾、缺少限定等常见问题，从而优化指令。

#### 四、 结论与要点

*   **结论**：即梦图片4.0模型是一款功能强大、高度集成的多模态图像工具，其核心优势在于通过自然语言实现了对图像的精准控制和高效编辑，极大地降低了专业级图像创作的门槛。
*   **核心要点**：
    1.  **从“生成”到“编辑”的转变**：模型的核心价值不仅在于创造，更在于对已有内容的精细化修改和迭代。
    2.  **提示词是第一生产力**：输出效果的好坏与用户指令的清晰度、结构性和准确性直接相关。
    3.  **多功能融合提升效率**：将文生图、编辑、组图功能整合，为商业设计、艺术创作等提供了“一站式”解决方案。
    4.  **实践性极强**：手册本身就是一份“即学即用”的宝典，通过大量的案例和关键词库，为用户提供了丰富的创作灵感和直接可用的方法论。

## 编辑撰写指南

- 用 **清晰明确** 的指令通常能实现更好的编辑效果，常见公式为 **`变化动作` + `变化对象` + `变化特征`** ，如： 将骑士的头盔变为金色

**变化动作**

> 指变化的动作方式
> 
> 如 移除/ 添加/ 替换/ 参考 等

**变化对象**

> 指发生变化的对象
> 
> 如 主体/ 背景/ 光影/ 色彩等

**变化特征**

> 指希望变化后呈现的效果
> 
> 如 明亮/ 粗糙/ 雨天背景等

- 当有多图生成意图时，可以通过 **“一系列”“组图”“帮我生成几张图”** 等提示词触发组图，最多支持生成9张
- 当有明确需要保持的角色形象、产品信息、风格等特征时，你可以 **输入图像作为参考** 来保持一致性

## 生图撰写指南

- 建议用 **连贯的自然语言** 描述 **画面内容（主体+行为+环境等），** 用 **短词语** 描述 **画面美学（风格、色彩、光影、构图等）**
	- 一个女孩，撑伞，林荫街道，油画般的细腻笔触使画面生动美好 ⚠️
	- 一个女孩穿着华丽的服装，撑着遮阳伞走在林荫道上，莫奈油画风格 ✅
- **提升指令响应：** 专业词汇使用词源语言，效果更准确
