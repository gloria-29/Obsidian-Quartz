# Groq Docs Chat - AI文档聊天应用

基于 AI 的文档助手，利用 Groq 的快速推理能力和 Cloudflare AI 搜索，帮助开发者与网站内容进行交互式对话。
开源项目，提供在线演示，让开发者能够更高效地查阅和理解文档。
专注于辅助开发者使用 Groq 平台构建 AI 应用。
