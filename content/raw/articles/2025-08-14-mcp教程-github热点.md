# 微软MCP教程与GitHub热门项目

微软开源 MCP 教程，系统讲解原理与最佳实践。同期热门项目：
- Tinyauth：Go语言零代码身份认证中间件，Docker部署，一键添加OAuth登录（4.4k星）
- kiss-translator：开源双语对照翻译浏览器插件（6.3k星），支持Google/DeepL/OpenAI
- KittenTTS：高质量英文TTS模型（6k星）
- LangExtract：谷歌开源，从非结构化文本提取结构化信息
