# Free API — LLM免费接口集合

LLM-Red-Team项目，提供多个大模型的免费API封装：Kimi(Moonshot)、跃问(阶跃星辰)、通义千问(Qwen)、智谱清言(GLM)等。支持高速流式输出、联网搜索、长文档解读、图像解析、多轮对话。零配置部署，多路token支持。
