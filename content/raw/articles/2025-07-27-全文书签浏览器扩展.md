# 全文书签浏览器扩展

Chrome 扩展「全文书签」（Fulltext Bookmark），自动记录浏览过的网页并支持全文搜索。开源免费，数据本地存储，最长可保存 36500 天（100 年）。

**核心功能**：自动记录浏览历史全文；全文搜索已浏览内容；支持导出/导入数据；支持接入 GPT API 进行 AI 检索；无需登录无隐私问题。

**缺点**：部分网页标题识别不准（如微信公众号）；非首次加载内容搜索不稳定；AI 检索功能实用性有限。

**源码**：https://github.com/RauX333/fulltext-bookmark
