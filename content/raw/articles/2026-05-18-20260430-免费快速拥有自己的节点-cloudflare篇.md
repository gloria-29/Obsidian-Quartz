# [部署](https://linux.do/t/topic/2076732#p-17301619-h-2)

## [创建 Pages 应用程序](https://linux.do/t/topic/2076732#p-17301619-pages-3)

1. 点击 [direct-upload-demo.zip](https://pages.cloudflare.com/direct-upload-demo.zip) 下载 Cloudflare Pages 演示项目压缩包备用；
2. 准备一个 Cloudflare 账号，点击 `计算和AI` > `Workers 和 Pages` > `创建应用程序` ；  

![创建Pages应用程序](https://github.com/gloria-29/OB-assets/releases/download/img-e8/e855c662a77809e0a23f94414eb86491924f95c4e835666043b1a054eb01c049.png)  

或  

![创建Pages应用程序](https://github.com/gloria-29/OB-assets/releases/download/img-c3/c32677bd5bff59429d3a29844bceaea7e0b5f844331f75b1fcf5f5c061fdb501.png)
3. 选择 `Pages` 选项卡，点击 `拖放文件` > `开始使用` ；  

![创建Pages应用程序](https://github.com/gloria-29/OB-assets/releases/download/img-81/81049300e38505831febfc34b557ec2260d8fbd4f4126f0b540c517f89e077a2.png)
4. 项目名称 **填写任意值**，**但必须是全新的名字**，**避免出现 1101 错误**，推荐末尾补上任意数字，如 `edt123123123` ；  

![创建Pages应用程序](https://github.com/gloria-29/OB-assets/releases/download/img-21/21efef11f5167a56a4992cfabfadcca0bf3aa0866d25f3cbd700dce0303ad03a.png)
5. 点击 `从计算机中选择` > `上传压缩文件`，选择第一步下载的 `direct-upload-demo.zip` 压缩包，等待上传完成；  

![上传项目压缩包](https://github.com/gloria-29/OB-assets/releases/download/img-ed/ed13fb101abea5bb35d43b3ee7facfd55f52f679c7779721fbb48a444f8cb9a2.png)
6. 点击 `部署站点`，等待部署完成；  

![部署Pages应用程序](https://github.com/gloria-29/OB-assets/releases/download/img-95/95b590878446d182888b6d734c8a95165e8588781ca79f6ea4472f53c9a78da6.png)
7. 提示成功，代表初始化部署完成！点击 `继续处理项目` 进入下一步设置变量绑定 KV 的操作；  

![部署成功](https://github.com/gloria-29/OB-assets/releases/download/img-dc/dc8f36f3866b62eb587544279a76c6b918853c351a7b13c97fa9ce3239909fa4.png)

## [设置管理员变量](https://linux.do/t/topic/2076732#p-17301619-h-4)

1. 进入项目设置页面，点击 `设置` 选项卡，添加变量和机密：  

![进入项目设置页面](https://github.com/gloria-29/OB-assets/releases/download/img-d7/d7b055fdc4446ffc0bca9eadae4a2077faeab41bf217bbad4fdb6d2f64d50860.png)
2. 点击 `+ 添加`，类型 `文本` 变量名称 `ADMIN` 变量，变量值为 **WebUI 管理员密码**，建议设置复杂密码，避免被暴力破解；  

![添加ADMIN变量](https://github.com/gloria-29/OB-assets/releases/download/img-ae/ae69d1532ef9107f052b41f48ef20414e6480c851cc602af1b76928d12849f66.png)
3. 变量即可设置完成，如忘记密码可返回此页面查看  

[[image]](https://blog.cmliussss.com/img/edt2/2-3-1.png)

## [绑定 KV 命名空间](https://linux.do/t/topic/2076732#p-17301619-kv-5)

1. 点击 `存储和数据库` > `Workers KV` > `+ Create Instance` 创建一个命名空间；  

![创建KV命名空间](https://github.com/gloria-29/OB-assets/releases/download/img-b2/b23f78c17678354a0492b535d789dce2c8691451b53fbb2478438d6cbb046f8d.png)
2. 命名空间名称可自定义，建议命名为 `EDT2` 以便区分，点击 `创建` 完成创建  

![命名空间创建完成](https://github.com/gloria-29/OB-assets/releases/download/img-8d/8d608b90259acc8d1b799bd13c5c002e376bf2d0f7a6b25cb59cf1c9be04256a.png)
3. 返回项目设置页面，点击 `设置` > `绑定` > `+ 添加` > `KV 命名空间`；  

[[image]](https://blog.cmliussss.com/img/edt2/3-3-1.png)  

![绑定命名空间](https://github.com/gloria-29/OB-assets/releases/download/img-33/3315652cd249fa302756231a6868fe0557eae08e1a900fa51427c28aea9d1b1a.png)
4. 变量名称必须填写大写 **KV** ，命名空间选择刚刚创建的 `EDT2`，点击 `保存` 完成绑定；  

![完成绑定](https://github.com/gloria-29/OB-assets/releases/download/img-d0/d0294cdae733dd592a583f5af01518c088c392ea04c49ec9ad0e06158e0cc185.png)
5. 返回项目设置页面，确认绑定成功；  

![绑定成功](https://github.com/gloria-29/OB-assets/releases/download/img-00/00c8cdb1ed4fb5f1371351ec6d16432922d99f7fd402fb0f572eda95c858d5f8.png)

## [重试部署，使其变量生效！](https://linux.do/t/topic/2076732#p-17301619-h-6)

1. 点击 [edgetunnel-main.zip](https://github.com/cmliu/edgetunnel/archive/refs/heads/main.zip) 下载最新版本项目压缩包备用；
2. 点击右上角 `创建部署` ，上传**上一步刚刚下载**的 `edgetunnel-main.zip` 压缩包；  

![重试部署](https://github.com/gloria-29/OB-assets/releases/download/img-d7/d7485fd748a1a685d25b872f8193321e1f7a2103c421f3061c769d7d4783aee0.png)
3. 部署环境选择 `生产`，点击 `从计算机中选择` > `上传压缩文件`，选择第一步下载的 `edgetunnel-main.zip` 压缩包，等待上传完成；  

![重试部署上传压缩包](https://github.com/gloria-29/OB-assets/releases/download/img-cc/cc3600041336933a226eab70276cc5ded1b4543fbf258a6a899aa83f47140ace.png)
4. 点击 `保存并部署`，等待部署完成；  

![重试部署保存并部署](https://github.com/gloria-29/OB-assets/releases/download/img-8b/8bde8cde034b625ad9a45d2172fffa5b122a45a910ea35fcbe212fbd0d10f717.png)  

![重试部署等待完成](https://github.com/gloria-29/OB-assets/releases/download/img-dd/ddf82215dcf4b7ce1042d44973c4b213d98d4259eb1e7048a90aa9d5a084db7a.png)

- 注意：如需修改管理员密码，修改完变量之后**必须重新上传部署，否则变量无法生效！**

## [绑定 自定义域名](https://linux.do/t/topic/2076732#p-17301619-h-7)

- **可免费注册的 CNAME 域名**

1. **DNSHE**：[https://www.dnshe.com/](https://my.dnshe.com/aff.php?aff=41810) *部分域名可托管 CF*，邀请码：`CY483A4A4B`
2. **DigitalPlat**: [https://domain.digitalplat.org/](https://domain.digitalplat.org/) *部分域名可托管 CF*
3. **ClouDNS**：[免费 DNS 托管，Cloud DNS 托管和域名 | ClouDNS](https://www.cloudns.net/index/lang/chs)
4. **dynv6**：[https://dynv6.com/](https://dynv6.com/)
5. **ZoneABC**：[https://zoneabc.net/](https://zoneabc.net/)

若无域名可使用以上免费域名注册商注册一个 CNAME 域名使用，图文教程使用 ClouDNS 域名演示：

1. 进入 Pages 应用程序，点击 `自定义域` 选项卡，点击 `设置自定义域` ；  

![设置自定义域](https://github.com/gloria-29/OB-assets/releases/download/img-1d/1dede956db8c67aa76f43653045a83d5d5c5918531e5224eeb17a0a624d78c0e.png)
2. 添加自定义域

- 注意！你的域名如果是 **[fxxk.cloudns.org](http://fxxk.cloudns.org/)** ，则**必须必须必须**多加一级域名，例如 **edt2.**[fxxk.cloudns.org](http://fxxk.cloudns.org/)  

![添加自定义域](https://github.com/gloria-29/OB-assets/releases/download/img-09/09a3a99dafa3e55ba009072833b209709ac9eaade4b671e080747532d34a387a.png)

1. 选择`开始 CNAME 设置`；  

![开始CNAME设置](https://github.com/gloria-29/OB-assets/releases/download/img-4b/4b6d9100265b901c29d57e89c7a19c019f2220e2294e08da7dadd72288654e0a.png)
2. 记录名称 `edt2` 和 CNAME 记录值 `edt123123123.pages.dev` ；  

![CNAME记录值](https://github.com/gloria-29/OB-assets/releases/download/img-bf/bff2301a0011da61cf2861c9ab1327d8442a8806f7d94b168e178dea5d879019.png)
3. 添加前往域名服务商添加 CNAME 记录；  

![添加自定义记录](https://github.com/gloria-29/OB-assets/releases/download/img-e1/e17f099b47c0a5f155af0ab53a90f01e7a631ff22f73caecbe925b8f981cfae2.png)
4. 返回 `自定义域` 选项卡，点击 `稍后完成 DNS 设置` 等待域名验证成功；  

![等待域名验证成功](https://github.com/gloria-29/OB-assets/releases/download/img-28/2801f8aa62fd4353c1ea7d75d47deddd6c211c6595d3086adab70ef4e3cbb9db.png)
5. **等待 10~30 分钟**，域名验证成功后即可看到域名绑定成功提示；  

![域名绑定成功](https://github.com/gloria-29/OB-assets/releases/download/img-00/00ce7d797e6f71f864201d042a6b8660b8a7ad8e772df6b6353951cfacbe9c80.png)

## [管理页面](https://linux.do/t/topic/2076732#p-17301619-h-8)

- 访问 `/admin` 即可登录管理页面，例如您绑定的自定义域名 `edt2.fxxk.cloudns.org` ，则您需访问 `https://edt2.fxxk.cloudns.org/admin`；

1. 输入管理员密码，点击 `登录` 即可进入管理页面；  

![登录](https://github.com/gloria-29/OB-assets/releases/download/img-86/86822cadd2cb61aec9e0ea38a918d35b175e121bfd1a32266964a9a6ed613280.jpeg)
2. 登录成功后，即可看到管理页面，无需折腾直接订阅使用即可；  

![登录](https://github.com/gloria-29/OB-assets/releases/download/img-f1/f1c130023aa79e305eb4d12f00e19c7fda953338030782e6aef31f549a17a826.jpeg)
