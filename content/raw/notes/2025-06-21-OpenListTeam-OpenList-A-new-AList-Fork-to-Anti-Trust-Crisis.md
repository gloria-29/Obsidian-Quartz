Features
--------

*    Multiple storages
    *    Local storage
    *    [Aliyundrive](https://www.alipan.com/)
    *    OneDrive / Sharepoint ([global](https://www.office.com/), [cn](https://portal.partner.microsoftonline.cn),de,us)
    *    [189cloud](https://cloud.189.cn) (Personal, Family)
    *    [GoogleDrive](https://drive.google.com/)
    *    [123pan](https://www.123pan.com/)
    *    FTP / SFTP
    *    [PikPak](https://www.mypikpak.com/)
    *    [S3](https://aws.amazon.com/s3/)
    *    [Seafile](https://seafile.com/)
    *    [UPYUN Storage Service](https://www.upyun.com/products/file-storage)
    *    WebDav(Support OneDrive/SharePoint without API)
    *    Teambition([China](https://www.teambition.com/),[International](https://us.teambition.com/))
    *    [Mediatrack](https://www.mediatrack.cn/)
    *    [139yun](https://yun.139.com/) (Personal, Family, Group)
    *    [YandexDisk](https://disk.yandex.com/)
    *    [BaiduNetdisk](http://pan.baidu.com/)
    *    [Terabox](https://www.terabox.com/main)
    *    [UC](https://drive.uc.cn)
    *    [Quark](https://pan.quark.cn)
    *    [Thunder](https://pan.xunlei.com)
    *    [Lanzou](https://www.lanzou.com/)
    *    [ILanzou](https://www.ilanzou.com/)
    *    [Aliyundrive share](https://www.alipan.com/)
    *    [Google photo](https://photos.google.com/)
    *    [Mega.nz](https://mega.nz)
    *    [Baidu photo](https://photo.baidu.com/)
    *    SMB
    *    [115](https://115.com/)
    *    Cloudreve
    *    [Dropbox](https://www.dropbox.com/)
    *    [FeijiPan](https://www.feijipan.com/)
    *    [dogecloud](https://www.dogecloud.com/product/oss)
    *    [Azure Blob Storage](https://azure.microsoft.com/products/storage/blobs)
*    Easy to deploy and out-of-the-box
*    File preview (PDF, markdown, code, plain text,...)
*    Image preview in gallery mode
*    Video and audio preview, support lyrics and subtitles
*    Office documents preview (docx, pptx, xlsx,...)
*    &#96;README.md&#96; preview rendering
*    File permalink copy and direct file download
*    Dark mode
*    I18n
*    Protected routes (password protection and authentication)
*    WebDav (waiting for detail documents)
*    Docker Deploy (rebuilding)
*    Cloudflare Workers proxy
*    File/Folder package download
*    Web upload(Can allow visitors to upload), delete, mkdir, rename, move and copy
*    Offline download
*    Copy files between two storage
*    Multi-thread downloading acceleration for single-thread download/stream
