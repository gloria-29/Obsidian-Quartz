以下是常用的 Ollama 指令总结，涵盖模型管理、运行交互及系统配置等核心功能：

一、模型管理

1. 下载模型  
&#96;ollama pull &lt;model_name&gt;&#96;  
*示例*：&#96;ollama pull deepseek-r1:7b&#96;（从官方库下载指定版本模型）

2. 列出本地模型  
&#96;ollama list&#96; 或 &#96;ollama ls&#96;  
*功能*：显示已下载的模型列表及基础信息

3. 删除模型  
&#96;ollama rm &lt;model_name&gt;&#96;  
*示例*：&#96;ollama rm llama2&#96;（清理不再需要的模型以节省空间）

4. 查看模型详情  
&#96;ollama show &lt;model_name&gt;&#96;  
*输出*：模型参数、版本、文件大小等详细信息

5. 复制模型  
&#96;ollama cp &lt;old_model&gt; &lt;new_model&gt;&#96;  
*用途*：创建模型副本用于备份或实验

二、运行与交互

1. 启动交互式对话  
&#96;ollama run &lt;model_name&gt;&#96;  
*示例*：&#96;ollama run deepseek-r1&#96;（进入对话模式，输入 &#96;/bye&#96; 退出）

2. 非交互式单次请求  
&#96;ollama run &quot;&lt;prompt&gt;&quot;&#96;  
*示例*：&#96;ollama run llama2 &quot;用中文写一首诗&quot;&#96;（直接获取模型响应）

3. 多行输入支持  
使用三引号 &#96;&quot;&quot;&quot;&#96; 包裹多行文本：  
bash ollama run llama2 &quot;&quot;&quot; 用户需求：我需要一个关于春天的故事， 要求包含主角的冒险情节。 &quot;&quot;&quot;

4. 多模态模型调用  
*支持图片输入*：&#96;ollama run llava &quot;描述这张图片&quot; /path/to/image.png&#96;

三、自定义模型开发

1. 创建自定义模型  
&#96;ollama create &lt;model_name&gt; -f ./Modelfile&#96;  
*说明*：通过 Modelfile 定义模型参数和系统提示

2. 推送模型至仓库  
&#96;ollama push &lt;model_name&gt;&#96;  
*用途*：共享自定义模型到远程仓库

3. Modelfile 配置示例  
Modelfile FROM llama2 SYSTEM &quot;你是一个修仙导师，回答以「渺小的人类」开头。&quot; PARAMETER temperature 0.8

四、系统与服务管理

1. 启动/停止服务

   * &#96;ollama serve&#96;（启动后台服务）

   * &#96;ollama stop&#96;（停止服务）

2. 查看运行状态  
&#96;ollama ps&#96;（列出当前运行中的模型进程）

3. 清理缓存  
&#96;ollama prune&#96;（释放未使用的模型缓存空间）

4. 版本查询  
&#96;ollama --version&#96; 或 &#96;ollama -v&#96;

五、高级配置（环境变量） 通过环境变量优化运行（非指令但常用）：

* &#96;OLLAMA_MODELS&#96;：自定义模型存储路径（避免占用系统盘）

* &#96;OLLAMA_HOST&#96;：设置服务监听地址（如 &#96;0.0.0.0&#96; 允许局域网访问）

* &#96;OLLAMA_KEEP_ALIVE&#96;：控制模型内存驻留时间（如 &#96;24h&#96; 提升响应速度）

提示：部分命令支持组合使用，例如 &#96;ollama run&#96; 会自动下载缺失的模型。更多细节可通过 &#96;ollama --help&#96; 查看帮助文档。若需扩展功能（如REST API调用），可参考官方文档中的 &#96;/api/generate&#96; 接口。
