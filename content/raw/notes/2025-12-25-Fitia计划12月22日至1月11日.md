## 🍳 每日食谱详情

### 12月22日

**营养成分：** 42克 蛋白质 | 17克 碳水 | 28克 脂肪

* **午餐：** 无
* **晚餐：牛至烤牛肉配红薯 (1份, 243克)**

| **食材** | **用量** |
| --- | --- |
| 红薯 | 1/2 个中等大小 (90克) |
| 牛肉 | 200 克 |
| 油 | 1/2 汤匙 (5毫升) |
| 牛至 | 1/2 汤匙 (2克) |

**烹饪步骤：**

1. 中火加热平底锅。热锅后倒入油，摊开并放入牛肉。
2. 每面煎4分钟，然后撒上牛至。
3. 盖上盖子，如有必要加少许水，转中小火慢煮。
4. 红薯去皮切片。将红薯放入沸水中煮8-10分钟。
5. 煮好后捞出沥干。
6. 将牛肉与红薯一同装盘即可。

### 12月23日

**营养成分：** 47克 蛋白质 | 27克 碳水 | 19克 脂肪

* **午餐：** 无
* **晚餐：西葫芦胡萝卜豌豆炖鱼 (1份, 478克)**

| **食材** | **用量** |
| --- | --- |
| 鱼 | 200 克 |
| 西葫芦 | 1/2 个 (100克) |
| 胡萝卜 | 1/2 根中等大小 (30克) |
| 豌豆 | 1/4 杯 (50克) |
| 大蒜 | 1 瓣 (3克) |
| 蔬菜高汤 | 1/4 杯 (60克) |
| 油 | 1 汤匙 (10毫升) |

**烹饪步骤：**

1. 胡萝卜去皮切丁。
2. 西葫芦切片，大蒜切碎。
3. 大火加热锅具。热锅后加入一半的油并摊开。
4. 加入大蒜炒几秒钟。
5. 加入剩余的蔬菜和高汤。煮沸后转中火。
6. 不盖盖子继续煮，直到熟透，大约需要6-7分钟。
7. 同时，清洗鱼肉，加盐和胡椒调味。
8. 大火加热烤盘/平底锅。热锅后倒入剩余的油，摊开并放入鱼。
9. 盖上盖子，中火每面煎3-4分钟。熟透后取出。
10. 将鱼和蔬菜炖菜装盘即可。

### 12月25日

**营养成分：** 60克 蛋白质 | 43克 碳水 | 12克 脂肪

* **午餐：** 无
* **晚餐：豌豆甜椒鸡肉 (1份, 589克)**

| **食材** | **用量** |
| --- | --- |
| 鸡胸肉 | 200 克 |
| 豌豆 | 1/2 杯 (100克) |
| 红甜椒 | 1/2 个 (60克) |
| 鸡高汤 | 1/2 杯 (120克) |
| 大蒜 | 1 瓣 (3克) |
| 油 | 1/2 汤匙 (5毫升) |
| 孜然 | 1 撮 (1克) |

**烹饪步骤：**

1. 中高火在锅或深平底锅中加热一半的油。同时，给鸡胸肉加盐和胡椒调味并切块。
2. 油热后，加入鸡肉翻炒约3-4分钟至变色。
3. 同时，将大蒜和甜椒切碎。
4. 鸡肉变色后，加入豌豆、大蒜和甜椒。加入孜然和一撮盐调味。
5. 加入高汤，搅拌，盖上盖子，中小火煮10分钟。如喜欢可添加更多香料。
6. 时间到后，揭开盖子再煮几分钟直到汤汁收干。
7. 趁热享用豌豆甜椒鸡肉。

### 12月27日

**营养成分：** 48克 蛋白质 | 41克 碳水 | 15克 脂肪

* **午餐：** 无
* **晚餐：蒜香豌豆烤鸡胸 (1份, 404克)**

| **食材** | **用量** |
| --- | --- |
| 鸡胸肉 | 150 克 |
| 豌豆 | 1/2 杯 (100克) |
| 胡萝卜 | 1/2 根中等大小 (30克) |
| 大蒜 | 1/2 瓣 (2克) |
| 油 | 1 汤匙 (10毫升) |

**烹饪步骤：**

1. 大火在锅中烧水，加一撮盐。同时，胡萝卜去皮切片。
2. 水开后，加入胡萝卜和豌豆。
3. 煮6分钟或直到变软。捞出沥干。
4. 同时，中高火预热烤盘/平底锅，鸡肉加盐和胡椒调味。
5. 热锅后，加入一半的油，摊开后放入鸡肉。
6. 中火每面煎4-6分钟，根据喜好熟度取出。
7. 大蒜切碎，与豌豆、胡萝卜和剩余的油混合。如有必要加一撮盐。
8. 将鸡肉与蒜香豌豆胡萝卜装盘。如喜欢可撒少许牛至。

### 12月29日

**营养成分：** 36克 蛋白质 | 30克 碳水 | 29克 脂肪

* **午餐：** 无
* **晚餐：四季豆胡萝卜玉米炖牛肉 (1份, 328克)**

| **食材** | **用量** |
| --- | --- |
| 玉米 | 1/2 个 (125克) |
| 牛肉 | 150 克 |
| 四季豆 | 1/2 杯 (50克) |
| 胡萝卜 | 1/2 根中等大小 (30克) |
| 油 | 1 汤匙 (10毫升) |

**烹饪步骤：**

1. 剥下玉米粒，放入沸水中。煮12-15分钟后捞出。
2. 胡萝卜去皮切薄片，放入沸水中煮6分钟后捞出。
3. 四季豆去头尾，切成三段。
4. 牛肉切片、条或块。
5. 大火加热平底锅。加入剩余的油并摊开。
6. 加入牛肉和四季豆，加盐和胡椒。中火煸炒4分钟。
7. 如果有牛至或喜欢的香草，与胡萝卜一起加入。
8. 盖盖中火再煮4分钟。如有必要加少许水。
9. 将剩余的油加到玉米中，如喜欢可加牛至、欧芹或蒜粉。混合均匀。
10. 将炖牛肉与玉米一同上桌。

### 12月30日

**营养成分：** 48克 蛋白质 | 32克 碳水 | 23克 脂肪

* **午餐：** 无
* **晚餐：胡椒鸡肉配红薯泥 (1份, 371克)**

| **食材** | **用量** |
| --- | --- |
| 鸡胸肉 | 200 克 |
| 红薯 | 1 个中等大小 (180克) |
| 黄油 | 1/2 汤匙 (15克) |
| 牛奶 | 2 汤匙 (30毫升) |
| 油 | 1/2 汤匙 (5毫升) |

**烹饪步骤：**

1. 红薯去皮切丁。放入沸水中煮10-12分钟或直到变软。
2. 同时，中高火预热烤盘，鸡胸肉加盐和胡椒调味。
3. 热锅后，加入油摊开，放入鸡肉。
4. 每面煎4-6分钟，取决于肉的厚度。
5. 达到理想熟度后取出。
6. 制作红薯泥：将煮好的红薯放入碗中，捣碎至理想的稠度。
7. 加入黄油和牛奶混合使其更顺滑。加盐和胡椒调味。
8. 将胡椒鸡肉与红薯泥装盘。

### 12月31日

**营养成分：** 42克 蛋白质 | 23克 碳水 | 23克 脂肪

* **午餐：** 无
* **晚餐：咖喱蘑菇鸡 (1份, 344克)**

| **食材** | **用量** |
| --- | --- |
| 鸡胸肉 | 150 克 |
| 蘑菇 | 1 杯 (70克) |
| 大蒜 | 1 瓣 (3克) |
| 牛奶 | 1/2 杯 (120毫升) |
| 黄油 | 1/2 汤匙 (15克) |
| 面粉 | 2 汤匙 (16克) |
| 咖喱粉 | 1 茶匙 (2克) |
| 油 | 1/2 汤匙 (5毫升) |

**烹饪步骤：**

1. 在大平底锅或锅中中火热油，同时将鸡肉切成一口大小并调味。
2. 大蒜和蘑菇切碎。
3. 油热后，加入大蒜和鸡胸肉。
4. 翻炒约5分钟。
5. 加入蘑菇，转小火继续煮。
6. 同时制作酱汁：在另一个锅中中火融化黄油，将面粉溶解在其中。
7. 离火，慢慢加入牛奶，用打蛋器或木勺搅拌。
8. 放回火上煮至沸腾。离火，调味，加入咖喱粉。
9. 将酱汁与鸡肉和蘑菇混合。
10. 趁热享用。可撒上喜欢的香草。

**烹饪步骤：**

2. 油热后，放入肉块，将各面煎黄约5分钟。取出备用。
3. 同时，洋葱切碎，苹果切块。
4. 在同一个锅中，加入剩余的油，热锅后加入洋葱。
5. 中火煸炒5分钟，加入红酒醋。
6. 煮沸几分钟后，加入苹果煎两面。
7. 把肉放回锅中，盖盖，转中小火。
8. 再煮10分钟，取出趁热享用。顶部撒少许欧芹。

| --- | --- |

**烹饪步骤：**

1. 猪肉切块，加盐和胡椒调味。
2. 洋葱和甜椒切条（可用红椒或绿椒）。

4. 油热后，放入猪肉和蔬菜，加一撮盐。翻炒5分钟。关火。
5. 盖盖，转中小火焖煮8-10分钟，期间偶尔翻动。
6. 煮至喜欢的程度后取出。
7. 薄饼每面在锅中加热30秒。
8. 用薄饼包裹混合好的肉和菜组装塔可。可加少许柠檬汁调味。
9. 享用。

### 1月7日

**营养成分：** 43克 蛋白质 | 12克 碳水 | 29克 脂肪

* **午餐：** 无
* **晚餐：洋葱红椒炒牛肉 (1份, 308克)**

| **食材** | **用量** |
| --- | --- |
| 牛肉 | 200 克 |
| 洋葱 | 1/2 个 (75克) |
| 青甜椒 | 1/2 个 (60克) |
| 大蒜 | 1/2 瓣 (2克) |
| 姜 | 1/2 片 (1克) |
| 耗油 | 1/2 汤匙 (7克) |
| 酱油 | 1/2 汤匙 (7克) |
| 油 | 2 茶匙 (6.6毫升) |

**烹饪步骤：**

1. 牛肉切条，加盐和胡椒。大蒜和姜切碎。
2. 将姜、蒜、酱油、耗油和一撮盐混合。
3. 大火在锅或炒锅中加热一半的油。
4. 将牛肉煎至各面上色，约需3-4分钟。
5. 倒入一半的混合酱汁，搅拌再煮1分钟。取出备用。
6. 将洋葱和甜椒切条。
7. 加入剩余的油，中火翻炒蔬菜约6-7分钟。
8. 倒入剩余的酱汁，再煮1分钟。
9. 倒回牛肉，混合均匀，关火。
10. 将牛肉与甜椒洋葱装盘。

### 1月8日

**营养成分：** 48克 蛋白质 | 40克 碳水 | 12克 脂肪

* **午餐：** 无
* **晚餐：豌豆橄榄炖鸡 (1份, 455克)**

| **食材** | **用量** |
| --- | --- |
| 鸡胸肉 | 150 克 |
| 豌豆 | 1/2 杯 (100克) |
| 大蒜 | 1 瓣 (3克) |
| 欧芹 | 1 汤匙 (4克) |
| 橄榄 | 4 颗 (20克) |
| 鸡高汤 | 1/4 杯 (60克) |
| 油 | 1/2 汤匙 (5毫升) |

**烹饪步骤：**

1. 鸡肉切成均匀块状，加盐和胡椒。大火在锅中热油。
2. 加入鸡肉煮2-3分钟至表面煎黄。偶尔翻动。
3. 同时，大蒜和欧芹切碎加入锅中。与鸡肉一起翻炒1分钟。
4. 加入豌豆和高汤。煮沸后，盖盖煮6分钟。
5. 同时，橄榄对半切开加入锅中。
6. 熟透后，加盐和胡椒调味，趁热上桌。

### 1月9日

**营养成分：** 36克 蛋白质 | 14克 碳水 | 21克 脂肪

* **午餐：** 无
* **晚餐：洋葱甜椒炒猪肉 (1份, 326克)**

| **食材** | **用量** |
| --- | --- |
| 猪肉 | 150 克 |
| 洋葱 | 1/2 个 (75克) |
| 甜椒 | 1 个 (120克) |
| 大蒜 | 1 瓣 (3克) |
| 油 | 1 汤匙 (15毫升) |

**烹饪步骤：**

1. 猪肉切块，洋葱和甜椒切细条。大蒜切碎。
2. 中火热锅，将油摊开。
3. 加热时，给猪肉撒盐和胡椒。
4. 油热后，加入碎蒜、洋葱和甜椒。翻炒2-3分钟。
5. 加入猪肉。边搅拌边煮8-10分钟。
6. 关火取出。
7. 装盘上桌。
8. 可选：撒上芝麻。

### 1月10日

**营养成分：** 38克 蛋白质 | 29克 碳水 | 14克 脂肪

* **午餐：** 无
* **晚餐：牛至鸡肉配炒土豆四季豆甜椒 (1份, 369克)**

| **食材** | **用量** |
| --- | --- |
| 鸡胸肉 | 150 克 |
| 土豆 | 1/2 个中等大小 (90克) |
| 甜椒 | 1/2 个 (60克) |
| 四季豆 | 1 杯 (100克) |
| 牛至 | 1 撮 (1克) |
| 油 | 1 汤匙 (10毫升) |

**烹饪步骤：**

1. 大火烧开一锅水。同时土豆去皮切丁。
2. 水开后放入土豆。煮8-10分钟至变软。沥干。
3. 同时，中高火在平底锅中热油。鸡胸肉加盐和胡椒并切块。
4. 油热后，加入鸡肉，中火煎至各面变黄，约3-4分钟。撒上牛至。
5. 同时，切好四季豆，甜椒切条。
6. 加入锅中继续煮6分钟，偶尔翻动。
7. 加盐和胡椒调味。如有必要加少许水。
8. 熟透后，加入土豆再煮1-2分钟使其入味。
9. 装盘享用。
