## pdf-craft 项目阅读笔记

### 核心摘要

**pdf-craft** 是一个专注于处理**扫描版书籍**的开源工具，能够利用 **DeepSeek OCR** 技术，在本地通过 GPU 加速将 PDF 文档高精度转换为 Markdown 或 EPUB 格式。v1.0.0 版本后彻底去除了对 LLM 的依赖，实现了完全离线、高速的转换流程，同时采用更宽松的 MIT 协议。

---

### 主要功能与特性

#### 1. 高精度文档识别与还原

- **扫描件专攻**：专为扫描版 PDF 优化，而非简单的文本提取。
- **复杂元素处理**：
- **表格与公式**：支持高精度识别，提供多种渲染方式（如 MathML, SVG, HTML 或直接裁剪原图）。
- **脚注处理**：能够妥善提取脚注及其中的图片资源。
- **结构化输出**：
- **自动去噪**：自动识别并过滤页眉、页脚等非正文干扰信息。
- **目录生成**：转换为 EPUB 时会自动生成书籍目录（支持基于 PDF 目录页提取或基于标题推断）。

#### 2. 本地化与高性能 (v1.0.0 变革)

- **DeepSeek OCR 驱动**：全面拥抱 DeepSeek OCR 模型，替代了旧版本中的 LLM 文本矫正。
- **完全离线**：无需网络请求，解决了网络延迟和失败问题，大幅提升转换速度。
- **隐私与稳定**：所有处理在本地完成，数据更安全，流程更稳定。
- *注：若必须使用 LLM 文本矫正功能，需回退至 v0.2.8 版本。*

#### 3. 灵活的模型与渲染配置

- **多尺寸模型**：提供 5 种 OCR 模型尺寸（&#96;tiny&#96;, &#96;small&#96;, &#96;base&#96;, &#96;large&#96;, &#96;gundam&#96;）。
- 默认使用 &#96;gundam&#96;（最大模型，质量最高）。
- **渲染可选项**：
- **表格**：HTML 代码或图片裁剪 (Clipping)。
- **公式**：MathML, SVG 或图片裁剪。
- **内联 LaTeX**：EPUB 模式下可选择保留内联 LaTeX 代码供阅读器渲染。

---

### 关键技术细节

#### 1. 环境依赖

- **基础环境**：Python (&#96;torch&#96;, &#96;torchvision&#96;).
- **OCR 核心**：需要配置 CUDA 环境（GPU 加速）。
- **PDF 解析**：必须安装 **Poppler** (用于 &#96;pdf2image&#96; 解析)。

#### 2. 转换流程控制 (Python API)

工具通过 Python 代码调用，核心函数为 &#96;transform_markdown&#96; 和 &#96;transform_epub&#96;。

- **输入输出**：指定 PDF 路径、输出路径及资源文件夹。
- **模型缓存**：支持自定义模型路径 (&#96;models_cache_path&#96;) 和纯离线模式 (&#96;local_only&#61;True&#96;)，适合生产环境预下载部署。
- **容错机制**：设置 &#96;ignore_pdf_errors&#61;True&#96; 可在单页渲染失败时跳过该页并继续转换，避免任务中断。
- **目录策略**：&#96;toc_assumed&#96; 参数控制是否信任 PDF 自带的目录页来构建结构。

#### 3. 协议与生态

- **开源协议**：**MIT License**（因移除了 AGPL 依赖，协议更宽松）。
- **生态联动**：推荐与 &#96;epub-translator&#96; 配合使用，实现“扫描 PDF -&gt; EPUB -&gt; 双语对照翻译书”的工作流。

---

### 总结与应用场景

pdf-craft 是一个**“重型”但在本地极具效率**的文档转换工具。它不仅是简单的 OCR，更是一个**文档重构器**。

- **适用人群**：需要数字化大量扫描书籍、学术论文的技术人员或电子书爱好者。
- **主要优势**：在保留原书排版结构（尤其是脚注、公式、目录）的同时，实现了格式的现代化（MD/EPUB），且完全不依赖外部 API 服务，适合搭建私有化的文档处理管线。
