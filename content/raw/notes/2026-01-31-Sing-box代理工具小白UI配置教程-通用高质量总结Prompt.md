# Sing-box代理工具小白UI配置教程 - 阅读笔记

## 一、教程背景与定位

### 1.1 教程缘起

本教程源于作者在IDC Flare站点发布的征文稿，因观察到网络代理工具问题咨询量激增，特别是小白用户和懒人用户对&quot;不折腾就能有好体验&quot;的强烈需求，作者决定在L站重新发布并完善这份教程。作者自谦为&quot;入门小白水平&quot;,但正因如此,教程更贴近初学者视角。

### 1.2 核心价值主张

教程承诺实现以下目标：

- **零代码编写**：全程UI界面操作
- **全平台通用**：一份配置文件适配手机、平板、电脑全设备
- **核心功能保障**：无DNS泄露、精准分流、裸核运行、低功耗无感代理
- **附加工具**：集成sub-store订阅管理工具
- **一劳永逸**：配置一次,多端同步使用

## 二、准备工作详解

### 2.1 必备条件

1. **硬件要求**：一台电脑(教程以Windows为例,Mac通用)
2. **软件资源**：GUI.for.SingBox安装包,需从GitHub官方仓库获取
3. **网络环境**：必须在科学网络环境下进行,因部分GitHub资源需翻墙下载
4. **安全提示**：杀毒软件可能误报,原因是作者开源代码特征值被不法分子利用制作病毒并上传病毒库,导致特征匹配即判定为病毒。解决方案是临时关闭杀毒软件。

### 2.2 技术原理铺垫

教程虽面向小白,但作者在后续章节埋下了关键概念的解释伏笔,如DNS泄露、分流规则、入站模式等,为深入理解打下基础。

## 三、懒人配置流程(快速上手)

### 3.1 基础设置三步走

1. **软件初始化**：
  - 解压安装包至指定路径
  - 双击.exe文件启动GUI面板
2. **界面本地化**：
  - 点击setting(设置)
  - 切换为简体中文语言
  - 在页面可见性选项中勾选&quot;规则集&quot;(为后续高级配置预留入口)
3. **内核更新**：
  - 进入&quot;内核&quot;页面
  - 更新第一个singbox内核(主流稳定版)
  - 忽略下方Alpha内核(测试版,不推荐小白使用)

### 3.2 订阅导入与启动

操作路径：概览页面 → 快速开始 → 输入singbox格式订阅链接和自定义名称 → 保存 → 启动内核

**关键点**：订阅链接必须是singbox格式,若机场仅提供Clash等其他格式,需先进行订阅转换(详见3.4节)。

### 3.3 配置文件导出

完成上述步骤后,通过以下路径导出配置：  
配置页面 → 右键配置文件 → 更多 → 复制到剪切板 → 新建.json文件粘贴保存

此时已获得**无DNS泄露的基础配置文件**,满足多端科学上网需求的用户可直接跳转至&quot;多端同步&quot;章节。

### 3.4 订阅转换方案

#### 方案一：本地转换(sub-store)

**优势**：本地运行,无订阅泄露风险,功能强大

**操作流程**：

1. 插件页面 → 插件中心 → 搜索&quot;sub&quot; → 添加&quot;Sub-Store纯净版&quot;
2. 安装 → 运行 → 在浏览器中打开管理界面
3. 点击&quot;立即添加&quot; → 选择&quot;单条订阅&quot; → 输入名称和原始订阅链接
4. 点击添加的订阅 → 选择singbox格式复制链接

#### 方案二：在线转换

**优势**：操作便捷,无需安装工具

**风险警示**：订阅内容会经过第三方服务器,存在隐私泄露风险

**资源推荐**：作者引用sing-box-node.com网站的转换工具汇总,可搜索&quot;singbox订阅转换&quot;获取多个在线服务。

## 四、进阶配置详解(完善配置文件)

### 4.1 通用设置

在配置页面右键点击配置文件可修改名称,通用设置部分提供高级参数调整,但作者建议小白用户跳过此步,保持默认即可。

### 4.2 入站设置深度解析

#### 核心概念辨析

- **mixed-in(系统代理模式)**：
  - 原理：开启SOCKS+HTTP代理端口
  - 比喻：如同&quot;插排&quot;,应用主动插入才走代理
  - 适用场景：主要为浏览器等支持系统代理的应用提供服务
  - 性能特点：速度较快,但部分应用不会自动走系统代理
- **tun-in(虚拟网卡模式)**：
  - 原理：创建虚拟网卡接管全局流量
  - 比喻：如同&quot;总电闸&quot;,控制所有网络连接
  - 适用场景：需要全局代理的场景
  - 安全特点：更难DNS泄露,但速度略慢于系统代理

#### 推荐配置方案

作者建议**同时启用mixed-in和tun-in**,兼顾速度与安全性。可通过上下拖动调整两种模式的优先级,其余参数保持默认即可。

### 4.3 精准分流实战

#### 4.3.1 分流概念解构

**本质**：制定访问规则,指定特定网站/IP使用特定节点

**实战场景**：作者以&quot;使用Gemini时走美国节点,其余网站直连&quot;为例进行演示,用户可举一反三应用到其他场景。

#### 4.3.2 规则集配置(核心步骤一)

**规则集定义**：汇总特定场景下涉及的所有域名和IP地址

**操作流程**：

1. 进入规则集页面(需在设置中先勾选&quot;规则集&quot;可见性)
2. 点击&quot;规则集中心&quot; → 更新列表(获取2000+预制规则集)
3. 搜索目标规则(如&quot;gemini&quot;,注意使用小写)
4. 点击&quot;添加源文件&quot;(作者说明源文件可视可编辑,二进制文件运行效率更高)
5. 移动光标至规则集右上角 → 编辑 → 复制远程链接(用于多设备同步)

**添加到配置**：

- 配置页面 → 右键配置文件 → 路由设置 → 规则集
- 点击&quot;+&quot;添加规则集
- 填写参数：名称(自定义)、类型(远程)、远程链接(粘贴刚复制的链接)、自动更新间隔(默认1天)

#### 4.3.3 出站设置(核心步骤二)

**目标**：为规则集指定流量出口(即使用哪些节点)

**操作流程**：

1. 配置页面 → 右键配置文件 → 出站设置
2. 点击&quot;+“新建出站 → 输入名称(如&quot;Gemini专用美国节点”)
3. 滑动至&quot;订阅&quot;部分 → 选择目标节点(作者选择所有美国节点)
4. 设置类型：
  - **手动选择**：用户手动切换节点
  - **自动选择**：自动测速并选择延迟最低节点
5. 点击保存

#### 4.3.4 路由设置(核心步骤三)

**本质**：建立规则集与出站的关联关系

**操作流程**：

1. 点击&quot;下一步&quot;进入路由设置
2. 点击规则 → 点击&quot;+ 新规则将插入到这里&quot;
3. 关联配置：
  - 出站标签：选择刚创建的出站(如&quot;Gemini专用美国节点&quot;)
  - 规则集：选择Gemini规则集
4. 连续点击两次&quot;保存&quot;

**实现效果**：所有访问Gemini的流量自动通过美国节点路由,实现精准分流。

## 五、多端同步方案

### 5.1 前提准备

在目标设备安装singbox客户端：

- **iOS/iPadOS**：直接在App Store搜索下载
- **Android**：Google Play或下载APK安装包
- **其他平台**：参考sing-box官方文档获取图形界面客户端

### 5.2 方案一：局域网同步导入

**优势**：操作便捷,扫码即用

**操作流程**：

1. 插件页面 → 插件中心 → 滑至底部找到&quot;共享配置到手机&quot;
2. 添加 → 安装 → 运行
3. 选择目标设备的singbox内核版本(Android选最新,iOS选主流版)
4. 按插件提示扫描二维码完成导入

**隐藏技巧**：点击二维码旁链接可在浏览器打开配置文件,右键另存为即可保存.json文件。

### 5.3 方案二：配置文件导入

**步骤**：

1. 按2.3章节方法生成配置文件
2. 目标设备singbox配置页面 → 添加 → 从文件导入
3. 选择.json配置文件即可

### 5.4 方案三：云端自动同步(推荐)

**优势**：一次配置,自动更新,所有设备保持配置一致

**操作流程**：

1. 获取配置文件并上传至支持直链的云存储(如GitHub Gist、对象存储等)
2. 目标设备新建配置 → 选择&quot;远程&quot; → 填入直链URL和名称
3. 后续电脑端修改直链文件,其他设备仅需更新配置即可同步

**核心价值**：实现配置文件的中心化管理,适合多设备用户。

## 六、优化体验实现无感运行

### 6.1 Windows/Mac优化方案

#### 裸核运行配置

1. 启动内核确认正常运行
2. 设置页面 → 取消勾选&quot;程序退出时关闭核心&quot;
3. 关闭GUI面板,内核继续后台运行

**性能优势**：裸核运行大幅降低资源占用,实现无感代理。

#### 内核管理

- **停止方法**：重新打开GUI点击&quot;停止内核&quot;,或在任务管理器终止singbox进程
- **版本维护**：
  - singbox内核更新频繁,需及时更新避免配置不兼容
  - 配置文件会自动覆写匹配最新协议
  - 建议安装&quot;滚动发行&quot;插件并启用,获取更稳定的更新体验

### 6.2 Android优化方案

#### 裸核配置流程

1. 配置正常运行后退出singbox并清理后台
2. 系统设置 → VPN → 找到singbox → 点击右侧箭头
3. 开启&quot;始终开启VPN&quot;选项

**效果**：后台进程不可见,实现真正的无感运行。

#### 注意事项

- 再次杀后台可能弹出&quot;始终开启的VPN已断开&quot;提示
- 解决方法：进入VPN设置 → 取消勾选&quot;始终开启VPN&quot; → 重新勾选

#### 附加优化

- **状态栏图标隐藏**：部分Android设备(如小米)支持隐藏VPN图标
- **分应用代理**：设置页面 → 配置覆盖 → 可选择特定应用走代理

### 6.3 Apple系列(iOS/iPadOS)优化

#### 裸核配置

1. 配置正常运行
2. 设置 → 按需启动 → 始终启动
3. 杀死后台即可裸核运行

#### 界面优化

设置 → 配置重载 → 隐藏VPN图标,状态栏VPN标识即可隐藏。

**适用场景**：需要为特定网站自定义分流规则

**方法一(仅电脑端)**：  
规则集页面 → 添加手动管理的规则集文件

**方法二(多端同步)**：

### 7.2 DNS泄露深度解析

#### 概念阐释

**DNS泄露定义**：使用代理时,DNS请求未通过代理加密通道,而是由本地网络直接处理和记录。

**通俗比喻**：  
开车去境外已有秘密通道(代理),但问路(DNS查询)时未走秘密通道,导致问路人(ISP)知晓你的位置和意图。

#### 防护机制

**GUI.for.SingBox内置方案**：  
作者强调GUI面板已预配置DNS防泄露规则,使用默认选项生成的配置文件即可防止DNS泄露,无需额外配置。

**技术基础**：  
基于singbox的DNS分流特性,可精准控制不同域名使用不同DNS服务器,实现DNS请求的安全路由。

#### 检测方法

推荐两个检测网站：

1. **BrowserLeaks DNS Leak Test**
  - 解析50个随机域名(25个IPv4 + 25个IPv6)
  - 检测DNS服务器归属地
2. **[ipleak.net](http://ipleak.net)**
  - 检测IP、DNS、Torrent IP等信息
  - 显示信息发送给网站的详情

**判断标准**：检测结果中的国家/地区旗帜应与所用节点地区一致,若出现不同地区旗帜即存在DNS泄露。

### 7.3 插件生态推荐

#### 核心插件详解

1. **sub-store纯净版**
  - 功能：订阅管理、节点管理、订阅转换、订阅合并、格式化
  - 特点：开源、本地运行、功能全面
2. **共享配置到手机**
  - 功能：设备间配置快速导入
  - 优势：支持选择不同内核版本,对iOS用户友好
3. **滚动发行**
  - 功能：获取更快、更新、更稳定的版本更新
  - 价值：减少版本不兼容导致的报错
4. **节点转换**
  - 功能：多协议节点转换为singbox格式
  - 用法：转换后导出复制,直接在订阅中添加
5. **配置同步 - Gists**
  - 功能：使用GitHub Gists同步GUI配置
  - 价值：方便备份与恢复
6. **metacubexd仪表盘**
  - 功能：创建mihomo仪表盘
  - 适用：裸核运行时查看管理,Clash用户过渡友好
7. **链式代理助手**
  - 功能：快速生成链式代理配置
  - 场景：需要多层代理的高级用户
8. **解除UWP应用本地回环限制**
  - 功能：解决Windows UWP应用联网问题
  - 典型场景：微软商店、Xbox等服务连接异常

#### 其他插件

插件中心还包含定时签到等丰富功能,作者鼓励用户自行探索。
