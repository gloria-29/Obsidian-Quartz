### 1\. 前摇

你是否曾因看到野王们动辄上万的 Key 而艳羡不已？是否也曾想像公益大佬们那样提供点公益服务但奈何囊中无 Key？现在，你不用再羡慕，因为你也可以是野王（甚至更野）；不用再无奈，因为你也有能力手握大把 Key。而这一切，你只差一个工具 。

项目是从 [ai-collector](https://github.com/wzdnzd/ai-collector) 刚拆分出来的。事实上，最近 L 站流行的 Gemini 打野，本项目在 2024 年的时候就支持。而我自己从 2023 年就开始打野，但纯粹是爱好，打到的 Key 从未使用，也因为功能性质所以从未在任何地方宣传过该项目。不过现在既然人人都在打野，不如索性将它推荐给佬们。

[![图片](https://linux.do/uploads/default/optimized/4X/c/4/2/c424a2d619e7897624946939e2f734ef00e1eea8_2_690x99.png)](https://linux.do/uploads/default/original/4X/c/4/2/c424a2d619e7897624946939e2f734ef00e1eea8.png &quot;图片&quot;)

### 2\. 优势

*   全：啥都能打，你能想到的都能扫
    
*   快：啥都池化，支持 session 池、token 池、线程池等，最大程度避免限流
    
*   活：啥都能配，全部功能都可以通过配置自定义
    
*   简：啥都能省，配置基本都有默认值，搜索条件一个正则表达式全覆盖，无需枚举
    

一个字： **强** 。通用、快速、可配、简单。

*   &#96;Valid&#96; ：调用接口成功，能正常使用
*   &#96;No Quota&#96; ：Key 有效，但没有额度
*   &#96;Wait&#96; ：调用接口时返回 429 状态码
*   &#96;Invalid&#96; ：无效的 Key

### 3\. 使用方法

参考 [**快速开始**](https://github.com/wzdnzd/harvester/blob/main/README.zh-CN.md#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B) ，使用时可选择使用 Github API（需要 Github Token）或者 Github Web（需要 Github User Session）。推荐配置 &#96;sessions&#96; 并将 &#96;use_api&#96; 设置为 &#96;false&#96; 使用 Web 模式（等同于手动在 Github 页面进行代码搜索）， **Github Session 获取** ：浏览器 &#96;F12&#96; → &#96;Application&#96; → &#96;Cookie&#96; 。有疑问也可以在评论区讨论，共同进步。

[![6a4b2f4f-cd0a-418c-8639-f378f8e9ef57](https://linux.do/uploads/default/optimized/4X/b/a/9/ba95944267a202799322faef0d5af6622e6b4a8f_2_690x118.png)](https://linux.do/uploads/default/original/4X/b/a/9/ba95944267a202799322faef0d5af6622e6b4a8f.png &quot;6a4b2f4f-cd0a-418c-8639-f378f8e9ef57&quot;)

&gt; Fofa 一类的服务，目前可以先手动搜索并下载得到网址列表，然后再加任务里。

&gt; 添加新的 &#96;Provider&#96; 类型，继承 &#96;IProvider&#96; 接口并实现 &#96;check&#96; 、 &#96;inspect&#96; 方法就能采集其它东西，比如机场订阅 / 代理等。
