## [前言](https://linux.do/t/topic/1416459#p-12259881-h-1)

最近 [opencode](https://opencode.ai/) 似乎爆火了，我也在自己电脑上下载了一个（搭配 &#96;oh-my-opencode&#96;）试了一下，用 &#96;Anthropic&#96; 正版的账号走浏览器登录（&#96;OAuth&#96;）是没问题的，但用公益站（[AnyRouter](https://anyrouter.top/) 等）、中转站（[claude-rely-service](https://github.com/Wei-Shaw/claude-relay-service)、[sub2api](https://github.com/Wei-Shaw/sub2api) 等）、本地代理（[CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)、[Antigravity-Manager](https://github.com/lbjlaq/Antigravity-Manager) 等）配置起来**极其繁琐**，苦不堪言

## [正文](https://linux.do/t/topic/1416459#p-12259881-h-2)

假设你已经安装了 &#96;opencode&#96;（&#96;oh-my-opencode&#96; 可有可无），可以有两种方式去配置任何非官方模型渠道：

### [简单粗暴版（推荐，不折腾）](https://linux.do/t/topic/1416459#p-12259881-h-3)

1. 命令行输入 &#96;opencode auth login&#96;
2. 选择 &#96;Anthropic&#96;
3. 选择 &#96;Manually enter API Key&#96;
4. 输入你的对应渠道的 &#96;API Key&#96;（这个我相信你肯定能自己找到并输入）
5. 打开 &#96;opencode.json&#96;（mac 用户的话就在 &#96;~/.config/opencode/opencode.json&#96;，其他平台需要搜一下文档之类的）
6. 在 &#96;provider&#96; 插入 &#96;anthropic&#96; 对象，重载 &#96;baseURL&#96;（这是最基础的 JSON 编辑，如果编辑出来有问题别找我，去让 AI 帮你改）：

&#96;&#96;&#96;

 &quot;provider&quot;: {

   &quot;anthropic&quot;: {

     &quot;options&quot;: {

       &quot;baseURL&quot;: &quot;你的渠道的Claude Code API URL地址/v1&quot;

     }

   },

   ...其他原有的配置

 }


&#96;&#96;&#96;

&gt; 注意，大概率要在渠道给你的 &#96;API_URL&#96; 后面加个 &#96;/v1&#96;，例如 &#96;WONG公益站&#96;的话就是 &#96;https://wzw.pp.ua/v1&#96;

7. 改一下模型，因为渠道里用的模型名可能是 &#96;claude-sonnet-4-5-20250929&#96; 和 &#96;claude-opus-4-5-20251101&#96;，在 &#96;opencode.json&#96; 里加入或修改字段：

&#96;&#96;&#96;

&quot;model&quot;: &quot;anthropic/claude-sonnet-4-5-20250929&quot;, // 或 anthropic/claude-opus-4-5-20251101


&#96;&#96;&#96;

8. 如果用了 &#96;oh-my-opencode&#96; 则需要顺便配置一下 &#96;oh-my-opencode.json&#96;（mac 用户的话就在 &#96;~/.config/opencode/oh-my-opencode.json&#96;，其他平台需要搜一下文档之类的），把里面全部用到 &#96;claude-*&#96; 的模型都改一下：

&#96;&#96;&#96;

&quot;model&quot;: &quot;anthropic/claude-sonnet-4-5-20250929&quot; // 或 anthropic/claude-opus-4-5-20251101


&#96;&#96;&#96;

### [自定义供应商](https://linux.do/t/topic/1416459#p-12259881-h-4)

1. 命令行输入 &#96;opencode auth login&#96;
2. 选择 &#96;Other&#96;
3. 输入你渠道名，英文全小写，这个就是 &#96;provider id&#96;（例如我们这里输入 &#96;test&#96;）
4. 输入你的对应渠道的 &#96;API Key&#96;（这个我相信你肯定能自己找到并输入）
5. 打开 &#96;opencode.json&#96;（mac 用户的话就在 &#96;~/.config/opencode/opencode.json&#96;，其他平台需要搜一下文档之类的）
6. 在 &#96;provider&#96; 插入新对象，把你的渠道加进去（这是最基础的 JSON 编辑，如果编辑出来有问题别找我，去让 AI 帮你改）：

&#96;&#96;&#96;

 &quot;provider&quot;: {

     &quot;test&quot;: {

       &quot;npm&quot;: &quot;@ai-sdk/anthropic&quot;,

       &quot;name&quot;: &quot;你的渠道名，用于显示到opencode的界面的&quot;,

       &quot;options&quot;: {

         &quot;baseURL&quot;: &quot;你的渠道的Claude Code API URL地址/v1&quot;

       },

       &quot;models&quot;: {

         &quot;claude-sonnet-4-5-20250929&quot;: {

           &quot;name&quot;: &quot;Claude 4.5 Sonnet&quot;,

           &quot;attachment&quot;: true,

           &quot;limit&quot;: {

             &quot;context&quot;: 1048576,

             &quot;output&quot;: 65535

           },

           &quot;modalities&quot;: {

             &quot;input&quot;: [

               &quot;text&quot;,

               &quot;image&quot;

             ],

             &quot;output&quot;: [

               &quot;text&quot;

             ]

           }

         },

         &quot;claude-opus-4-5-20251101&quot;: {

           &quot;name&quot;: &quot;Claude 4.5 Opus&quot;,

           &quot;attachment&quot;: true,

           &quot;limit&quot;: {

             &quot;context&quot;: 1048576,

             &quot;output&quot;: 65535

           },

           &quot;modalities&quot;: {

             &quot;input&quot;: [

               &quot;text&quot;,

               &quot;image&quot;

             ],

             &quot;output&quot;: [

               &quot;text&quot;

             ]

           }

         }

       }

     },

   ...其他原有的配置

 }


&#96;&#96;&#96;

&gt; 注意，大概率要在渠道给你的 &#96;API_URL&#96; 后面加个 &#96;/v1&#96;，例如 &#96;WONG公益站&#96;的话就是 &#96;https://wzw.pp.ua/v1&#96;

7. 改一下模型，因为渠道里用的模型名可能是 &#96;claude-sonnet-4-5-20250929&#96; 和 &#96;claude-opus-4-5-20251101&#96;，在 &#96;opencode.json&#96; 里加入或修改字段：

&#96;&#96;&#96;

&quot;model&quot;: &quot;test/claude-sonnet-4-5-20250929&quot;, // 或 test/claude-opus-4-5-20251101


&#96;&#96;&#96;

8. 如果用了 &#96;oh-my-opencode&#96; 则需要顺便配置一下 &#96;oh-my-opencode.json&#96;（mac 用户的话就在 &#96;~/.config/opencode/oh-my-opencode.json&#96;，其他平台需要搜一下文档之类的），把里面全部用到 &#96;claude-*&#96; 的模型都改一下：

&#96;&#96;&#96;

&quot;model&quot;: &quot;test/claude-sonnet-4-5-20250929&quot; // 或 test/claude-opus-4-5-20251101


&#96;&#96;&#96;

&gt; 注意，记得把这里的 &#96;test&#96; 换成你自己的 &#96;provider id&#96;

## [限制](https://linux.do/t/topic/1416459#p-12259881-h-6)

某些平台禁止非 &#96;Claude Code CLI&#96; 使用（如 &#96;88code&#96;、&#96;WONG公益站的Claude Code 0.25倍率专属分组&#96;）

&gt; &#96;WONG公益站&#96;可以用 &#96;default&#96; 分组，但这样就是 1 倍率了，小心使用…如果有大佬知道咋解决请在评论区里教教我

![问题图](https://dinox-new.5984f2df14671be265c2d2fc0e21b3f8.r2.cloudflarestorage.com/dinox_note/assets/019126f0-2672-7286-b640-feeb1616b906/images/019bb7e7-3eaa-790a-894b-f80ccdc3de6d.png)
