## 一、总体架构与设计目标

### 1.1 项目名称与定位

**项目名（建议）：** &#96;notion-mirror-agent&#96;

**定位：**

&gt; 一个由 **OpenClaw + MCP + Skills + Playwright + R2** 驱动的  
&gt; **Notion 单向镜像系统** ，用于将「团队工作区」中的数据库  
&gt; **完整、增量、可过滤地镜像到个人工作区** ，并实现 **文件真实备份** 。

### 1.2 目标能力

-   **单向同步** ：团队工作区 → 个人工作区
    
-   **增量同步** ：基于 &#96;last_edited_time + Source ID&#96;
    
-   **完整内容复制** ：
    
    -   页面
        
    -   子页面（无限层级）
        
    -   所有 block（文本、列表、callout、toggle、代码块等）
        
-   **文件真实备份** ：
    
    -   从 Notion 网页抓取文件 URL
        
    -   下载文件
        
    -   上传到 Cloudflare R2
        
    -   在目标页面中使用 R2 URL 替代
        
-   **过滤同步** ：
    
    -   支持通过 filter（模拟视图）只同步部分页面
        
-   **结构保持** ：
    
    -   保持属性结构
        
    -   目标库增加 &#96;Source ID&#96; 字段用于关联
        
-   **自动化执行** ：
    
    -   OpenClaw 负责任务编排、重试、补偿
        
    -   Cloudflare Worker 负责触发
        
-   **可扩展** ：
    
    -   MCP 工具可扩展
        
    -   Skills 可复用
        
    -   OpenClaw 可新增任务（例如只同步某个 Tag）

### 2.2 设计原则

-   **MCP：只做“原子能力”**
    
    -   不做复杂流程
        
    -   不做跨工具协调
        
-   **Skills：只做“能力组合”**
    
    -   把多个 MCP 工具组合成一个可复用的高层操作
        
-   **OpenClaw：只做“任务编排”**
    
    -   决定什么时候调用哪个 Skill
        
    -   处理失败、重试、补偿
        

## 三、MCP 工具层（底座）

这一层是你真正“接触外部世界”的地方。

### 3.1 工具列表与职责

1.  **&#96;notion_api&#96;**
    
    -   封装 Notion 官方 API
        
    -   负责：查询数据库、获取页面、获取 block、创建/更新页面、追加 children
        
2.  **&#96;notion_web&#96; （Playwright）**
    
    -   自动化 Notion 网页
        
    -   负责：登录、打开页面、抓取文件 URL（或导出）
        
3.  **&#96;r2_upload&#96;**
    
    -   与 Cloudflare R2 通信
        
    -   负责：下载文件 → 上传到 R2 → 返回 R2 URL 映射
        
4.  **&#96;diff_engine&#96;**
    
    -   纯逻辑工具
        
    -   负责：比对源/目标数据库，生成同步计划
        
5.  **&#96;sync_engine&#96;**
    
    -   纯逻辑 + Notion API 调用
        
    -   负责：根据 diff + file\_map 执行创建/更新 + 递归复制 block
        

### 3.2 每个 MCP 工具的输入/输出（终版定义）

#### 3.2.1 notion\_api

-   **命令： &#96;query_database&#96;**
    
    -   输入：
        
        -   &#96;database_id: string&#96;
            
        -   &#96;filter?: object&#96; （Notion API filter JSON）
            
    -   输出：
        
        -   &#96;results: NotionPage[]&#96;
            
-   **命令： &#96;get_page&#96;**
    
    -   输入：
        
        -   &#96;page_id: string&#96;
            
    -   输出：
        
        -   &#96;page: NotionPage&#96;
            
-   **命令： &#96;get_block_children&#96;**
    
    -   输入：
        
        -   &#96;block_id: string&#96;
            
    -   输出：
        
        -   &#96;results: NotionBlock[]&#96;
            
-   **命令： &#96;create_page&#96;**
    
    -   输入：
        
        -   &#96;parent: { database_id: string } | { page_id: string }&#96;
            
        -   &#96;properties: object&#96;
            
    -   输出：
        
        -   &#96;page: NotionPage&#96;
            
-   **命令： &#96;update_page&#96;**
    
    -   输入：
        
        -   &#96;page_id: string&#96;
            
        -   &#96;properties: object&#96;
            
    -   输出：
        
        -   &#96;page: NotionPage&#96;
            
-   **命令： &#96;append_block_children&#96;**
    
    -   输入：
        
        -   &#96;block_id: string&#96;
            
        -   &#96;children: NotionBlockInput[]&#96;
            
    -   输出：
        
        -   &#96;results: NotionBlock[]&#96;
            

&gt; 设计原则： &#96;notion_api&#96; 不做任何业务逻辑，只是“API 封装”。

#### 3.2.2 notion\_web（Playwright）

-   **命令： &#96;export_files_for_pages&#96;**
    
    -   输入：
        
        -   &#96;pages_to_sync: { id: string }[]&#96;
            
    -   输出：
        
        -   &#96;files: { page_id: string; url: string }[]&#96;
            

&gt; 终版建议：
&gt; 
&gt; -   第一阶段：只抓取页面中 [&#96;secure.notion-static.com&#96;](https://secure.notion-static.com) 的 URL（轻量、稳定）
&gt;     
&gt; -   第二阶段（你以后想升级）：
&gt;     
&gt;     -   使用 Notion 导出功能（导出为 HTML/Markdown）
&gt;         
&gt;     -   解压 zip
&gt;         
&gt;     -   提取文件
&gt;         
&gt;     -   这部分可以在 &#96;notion_web&#96; 内部扩展，不影响上层接口。
&gt;         

#### 3.2.3 r2\_upload

-   **命令： &#96;upload_files&#96;**
    
    -   输入：
        
        -   &#96;files: { page_id: string; url: string }[]&#96;
            
    -   输出：
        
        -   &#96;file_map: { [original_url: string]: string /* r2_url */ }&#96;
            

&gt; 设计原则：
&gt; 
&gt; -   不关心 Notion，只关心“URL → R2 URL 映射”。
&gt;     

#### 3.2.4 diff\_engine

-   **命令： &#96;diff_databases&#96;**
    
    -   输入：
        
        -   &#96;source_pages: { results: NotionPage[] } | NotionPage[]&#96;
            
        -   &#96;target_pages: { results: NotionPage[] } | NotionPage[]&#96;
            
    -   输出：
        
        -   &#96;pages_to_create: NotionPage[]&#96;
            
        -   &#96;pages_to_update: { source: NotionPage; target: NotionPage }[]&#96;
            
        -   &#96;pages_to_skip: NotionPage[]&#96;
            
        -   &#96;pages_to_sync: NotionPage[]&#96; （create + update 的源页面）
            

&gt; 设计原则：
&gt; 
&gt; -   只做“差异计算”，不做任何 API 调用。
&gt;     

#### 3.2.5 sync\_engine

-   **命令： &#96;apply_changes&#96;**
    
    -   输入：
        
        -   &#96;diff: diff_engine.diff_databases 的输出&#96;
            
        -   &#96;file_map: { [original_url: string]: string }&#96;
            
        -   &#96;source_db_id: string&#96;
            
        -   &#96;target_db_id: string&#96;
            
    -   输出：
        
        -   &#96;summary: { created: number; updated: number; skipped: number }&#96;
            

&gt; 设计原则：
&gt; 
&gt; -   负责：
&gt;     
&gt;     -   创建/更新页面（属性 + &#96;Source ID&#96; ）
&gt;         
&gt;     -   删除目标页面 children
&gt;         
&gt;     -   递归复制 block
&gt;         
&gt;     -   替换文件 URL 为 R2 URL
&gt;         

## 四、Skills 层：能力图谱（终版）

这一层是你真正“复用”的地方。

### 4.1 能力图谱总览

我们设计以下 Skills（建议）：

1.  &#96;skill.query_source_database&#96;
    
2.  &#96;skill.query_target_database&#96;
    
3.  &#96;skill.compute_diff&#96;
    
4.  &#96;skill.collect_files_for_sync&#96;
    
5.  &#96;skill.backup_files_to_r2&#96;
    
6.  &#96;skill.sync_database_changes&#96;
    
7.  &#96;skill.sync_notion_database&#96; （顶层 Skill）
    

它们之间的依赖关系：

&#96;&#96;&#96;
skill.sync_notion_database
  ├─ skill.query_source_database
  ├─ skill.query_target_database
  ├─ skill.compute_diff
  ├─ skill.collect_files_for_sync
  ├─ skill.backup_files_to_r2
  └─ skill.sync_database_changes
&#96;&#96;&#96;

### 4.2 每个 Skill 的详细定义（终版）

&gt; 这里用“伪 YAML”描述，方便你映射到实际 Skills 配置格式。

#### 4.2.1 skill.query\_source\_database

-   **描述：** 查询源数据库（可带 filter）
    
-   **输入：**
    
    -   &#96;source_db_id: string&#96;
        
    -   &#96;filter?: object&#96;
        
-   **调用链：**
    
    -   &#96;notion_api.query_database&#96;
        
-   **输出：**
    
    -   &#96;source_pages: NotionPage[]&#96;
        

&#96;&#96;&#96;
name: skill.query_source_database
description: 查询源 Notion 数据库（支持 filter）
inputs:
  - name: source_db_id
    type: string
  - name: filter
    type: object
    optional: true
steps:
  - use: notion_api.query_database
    with:
      database_id: ${source_db_id}
      filter: ${filter}
outputs:
  source_pages: ${steps[0].output.results}
&#96;&#96;&#96;

#### 4.2.2 skill.query\_target\_database

-   **描述：** 查询目标数据库
    
-   **输入：**
    
    -   &#96;target_db_id: string&#96;
        
-   **调用链：**
    
    -   &#96;notion_api.query_database&#96;
        
-   **输出：**
    
    -   &#96;target_pages: NotionPage[]&#96;
        

&#96;&#96;&#96;
name: skill.query_target_database
description: 查询目标 Notion 数据库
inputs:
  - name: target_db_id
    type: string
steps:
  - use: notion_api.query_database
    with:
      database_id: ${target_db_id}
outputs:
  target_pages: ${steps[0].output.results}
&#96;&#96;&#96;

#### 4.2.3 skill.compute\_diff

-   **描述：** 比对源/目标数据库，生成同步计划
    
-   **输入：**
    
    -   &#96;source_pages: NotionPage[]&#96;
        
    -   &#96;target_pages: NotionPage[]&#96;
        
-   **调用链：**
    
    -   &#96;diff_engine.diff_databases&#96;
        
-   **输出：**
    
    -   &#96;diff: { pages_to_create, pages_to_update, pages_to_skip, pages_to_sync }&#96;
        

&#96;&#96;&#96;
name: skill.compute_diff
description: 比对源/目标数据库，生成同步计划
inputs:
  - name: source_pages
    type: array
  - name: target_pages
    type: array
steps:
  - use: diff_engine.diff_databases
    with:
      source_pages: ${source_pages}
      target_pages: ${target_pages}
outputs:
  diff: ${steps[0].output}
&#96;&#96;&#96;

#### 4.2.4 skill.collect\_files\_for\_sync

-   **描述：** 为需要同步的页面收集文件 URL
    
-   **输入：**
    
    -   &#96;pages_to_sync: NotionPage[]&#96;
        
-   **调用链：**
    
    -   &#96;notion_web.export_files_for_pages&#96;
        
-   **输出：**
    
    -   &#96;files: { page_id, url }[]&#96;
        

&#96;&#96;&#96;
name: skill.collect_files_for_sync
description: 为需要同步的页面收集文件 URL
inputs:
  - name: pages_to_sync
    type: array
steps:
  - use: notion_web.export_files_for_pages
    with:
      pages_to_sync: ${pages_to_sync}
outputs:
  files: ${steps[0].output.files}
&#96;&#96;&#96;

#### 4.2.5 skill.backup\_files\_to\_r2

-   **描述：** 将文件上传到 R2，生成 URL 映射
    
-   **输入：**
    
    -   &#96;files: { page_id, url }[]&#96;
        
-   **调用链：**
    
    -   &#96;r2_upload.upload_files&#96;
        
-   **输出：**
    
    -   &#96;file_map: { [original_url: string]: string }&#96;
        

&#96;&#96;&#96;
name: skill.backup_files_to_r2
description: 将文件上传到 R2，生成 URL 映射
inputs:
  - name: files
    type: array
steps:
  - use: r2_upload.upload_files
    with:
      files: ${files}
outputs:
  file_map: ${steps[0].output.file_map}
&#96;&#96;&#96;

#### 4.2.6 skill.sync\_database\_changes

-   **描述：** 根据 diff + file\_map 执行同步
    
-   **输入：**
    
    -   &#96;diff: object&#96;
        
    -   &#96;file_map: object&#96;
        
    -   &#96;source_db_id: string&#96;
        
    -   &#96;target_db_id: string&#96;
        
-   **调用链：**
    
    -   &#96;sync_engine.apply_changes&#96;
        
-   **输出：**
    
    -   &#96;summary: { created, updated, skipped }&#96;
        

&#96;&#96;&#96;
name: skill.sync_database_changes
description: 根据 diff + file_map 执行同步
inputs:
  - name: diff
    type: object
  - name: file_map
    type: object
  - name: source_db_id
    type: string
  - name: target_db_id
    type: string
steps:
  - use: sync_engine.apply_changes
    with:
      diff: ${diff}
      file_map: ${file_map}
      source_db_id: ${source_db_id}
      target_db_id: ${target_db_id}
outputs:
  summary: ${steps[0].output}
&#96;&#96;&#96;

#### 4.2.7 顶层 Skill：skill.sync\_notion\_database

-   **描述：** 完整执行一次数据库同步（你对外只需要用这个 Skill）
    
-   **输入：**
    
    -   &#96;source_db_id: string&#96;
        
    -   &#96;target_db_id: string&#96;
        
    -   &#96;filter?: object&#96;
        
-   **调用链：**
    
    -   &#96;skill.query_source_database&#96;
        
    -   &#96;skill.query_target_database&#96;
        
    -   &#96;skill.compute_diff&#96;
        
    -   &#96;skill.collect_files_for_sync&#96;
        
    -   &#96;skill.backup_files_to_r2&#96;
        
    -   &#96;skill.sync_database_changes&#96;
        
-   **输出：**
    
    -   &#96;summary: { created, updated, skipped }&#96;
        
    -   &#96;diff: object&#96; （可选，用于日志）
        

&#96;&#96;&#96;
name: skill.sync_notion_database
description: &gt;
  从源数据库同步到目标数据库，包含增量、文件备份、过滤同步。

inputs:
  - name: source_db_id
    type: string
  - name: target_db_id
    type: string
  - name: filter
    type: object
    optional: true

steps:
  - name: query_source
    use: skill.query_source_database
    with:
      source_db_id: ${source_db_id}
      filter: ${filter}

  - name: query_target
    use: skill.query_target_database
    with:
      target_db_id: ${target_db_id}

  - name: compute_diff
    use: skill.compute_diff
    with:
      source_pages: ${steps.query_source.output.source_pages}
      target_pages: ${steps.query_target.output.target_pages}

  - name: collect_files
    use: skill.collect_files_for_sync
    with:
      pages_to_sync: ${steps.compute_diff.output.diff.pages_to_sync}

  - name: backup_files
    use: skill.backup_files_to_r2
    with:
      files: ${steps.collect_files.output.files}

  - name: sync_changes
    use: skill.sync_database_changes
    with:
      diff: ${steps.compute_diff.output.diff}
      file_map: ${steps.backup_files.output.file_map}
      source_db_id: ${source_db_id}
      target_db_id: ${target_db_id}

outputs:
  summary: ${steps.sync_changes.output.summary}
  diff: ${steps.compute_diff.output.diff}
&#96;&#96;&#96;

&gt; 这是你整个系统的“对外能力入口”。

## 五、OpenClaw 层：终版任务与 Agent

### 5.1 Agent 定义（终版）

&#96;&#96;&#96;
# openclaw/agents/notion_mirror_agent.yaml
name: notion_mirror_agent
description: &gt;
  负责执行 Notion 数据库的单向镜像任务，调用 Skills 与 MCP 工具。

tools:
  - notion_api
  - notion_web
  - r2_upload
  - diff_engine
  - sync_engine
  - skill.sync_notion_database

defaults:
  model: gpt-4.1
  temperature: 0.1
&#96;&#96;&#96;

&gt; 说明：
&gt; 
&gt; -   这里把顶层 Skill 也注册为“工具”，方便任务直接调用。
&gt;     

### 5.2 任务定义（终版）

&#96;&#96;&#96;
# openclaw/tasks/sync_notion.yaml
task: sync_notion
description: &gt;
  从源 Notion 数据库同步到目标数据库，支持过滤与增量。

agent: notion_mirror_agent

params:
  source_db_id: ${SOURCE_DB_ID}
  target_db_id: ${TARGET_DB_ID}
  filter: ${SOURCE_FILTER_JSON}

steps:
  - name: sync
    tool: skill.sync_notion_database
    input:
      source_db_id: ${source_db_id}
      target_db_id: ${target_db_id}
      filter: ${filter}
&#96;&#96;&#96;

&gt; 说明：
&gt; 
&gt; -   &#96;SOURCE_DB_ID&#96; / &#96;TARGET_DB_ID&#96; / &#96;SOURCE_FILTER_JSON&#96; 可以来自 OpenClaw 的环境变量或任务参数。
&gt;     
&gt; -   你也可以在 Worker 里通过 HTTP body 传入这些参数。

## 六、部署与配置（终版建议）

## 七、同步策略与边界说明（终版）

### 7.1 增量同步策略

-   通过 &#96;diff_engine&#96; 实现：
    
    -   如果目标库中不存在 &#96;Source ID &#61; 源页面 ID&#96; → 创建
        
    -   如果存在：
        
        -   若 &#96;target.last_edited_time &gt;&#61; source.last_edited_time&#96; → 跳过
            
        -   否则 → 更新属性 + 覆盖内容
            

### 7.2 过滤同步策略

-   通过 &#96;SOURCE_FILTER_JSON&#96; 或任务参数中的 &#96;filter&#96; 实现
    
-   格式为 Notion API 的 filter JSON，例如：
    

&#96;&#96;&#96;
{
  &quot;property&quot;: &quot;Status&quot;,
  &quot;select&quot;: { &quot;equals&quot;: &quot;Done&quot; }
}
&#96;&#96;&#96;

-   这相当于“模拟某个视图的过滤条件”。
    

### 7.3 文件备份策略

-   &#96;notion_web&#96; 抓取页面中的 [&#96;secure.notion-static.com&#96;](https://secure.notion-static.com) URL
    
-   &#96;r2_upload&#96; 下载并上传到 R2
    
-   &#96;sync_engine&#96; 在复制 block 时：
    
    -   如果 block 中的文件 URL 在 &#96;file_map&#96; 中 → 替换为 R2 URL
        
    -   否则 → 保留原 URL（作为降级策略）
        

### 7.4 结构保持策略

-   属性：
    
    -   &#96;sync_engine&#96; 使用 &#96;cloneProperties&#96; 深拷贝源页面属性
        
    -   删除只读字段（如 &#96;id&#96; ）
        
    -   强制写入 &#96;Source ID&#96;
        
-   block：
    
    -   深拷贝 block
        
    -   删除只读字段
        
    -   保持原 block 类型与内容
        

### 7.5 失败与恢复策略（建议）

-   OpenClaw 层：
    
    -   对 &#96;skill.sync_notion_database&#96; 设置：
        
        -   最大重试次数（例如 3 次）
            
        -   失败通知（例如发到你的 Telegram / 邮件）
            
-   &#96;sync_engine&#96; 层：
    
    -   对单个页面失败时：
        
        -   记录错误
            
        -   不影响其他页面
            
    -   你可以在后续版本中增加“只重试失败页面”的任务。
