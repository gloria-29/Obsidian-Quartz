### 核心功能设计

&#96;&#96;&#96;mermaid
graph TD
    A[用户输入] --&gt; B{输入判断}

### 如何部署使用

1. **导入工作流**：

   * 在Dify控制台 &gt; 工作流 &gt; 导入JSON

   * 替换&#96;datasets&#96;中的知识库ID（在知识库设置页面查看）

2. **配置关键参数**：

   &#96;&#96;&#96;yaml
   # .env 环境变量配置
   MEMORY_TYPE：redis         # 启用对话记忆
   MEMORY_SIZE：5             # 保留最近5轮对话
   TOOL_ENABLED：true         # 开启工具调用功能
   &#96;&#96;&#96;

3. **添加自定义功能（可选）**：

### 发布为外部工具的API调用方式

1. 在Dify应用设置中开启「API访问」

2. 获取API密钥和应用ID

#### 调用示例代码

&#96;&#96;&#96;python
import requests

DIFY_API &#61; &quot;https://api.dify.ai/v1/workflows/run&quot;
HEADERS &#61; {
    &quot;Authorization&quot;: &quot;Bearer {API_KEY}&quot;,
    &quot;Content-Type&quot;: &quot;application/json&quot;
}

def ask_dify(question, session_id&#61;None):
    payload &#61; {
        &quot;inputs&quot;: {&quot;query&quot;: question},
        &quot;session_id&quot;: session_id,  # 用于维持多轮对话
        &quot;config&quot;: {&quot;tool_enabled&quot;: True}  # 开启工具调用
    }
    response &#61; requests.post(DIFY_API, json&#61;payload, headers&#61;HEADERS)
    return response.json()

# 调用示例
response &#61; ask_dify(&quot;Dify的计费方式是什么？&quot;, session_id&#61;&quot;user_123&quot;)
print(response[&quot;output&quot;][&quot;answer&quot;])
print(&quot;参考来源：&quot;, response[&quot;output&quot;][&quot;sources&quot;])

### 在外部系统集成的方案

1. **GPTs集成**：

   * 在GPTs配置的Actions中添加OpenAPI规范：

     &#96;&#96;&#96;yaml
     openapi: 3.1.0
     paths:
     /v1/query:
       post:
         description: 查询Dify知识库
         parameters:
           - name: Authorization
             in: header
             required: true
         requestBody:
           content:
             application/json:
               schema:
                 type: object
                 properties:
                   question:
                     type: string
                   session_id:
                     type: string
     &#96;&#96;&#96;

2. **ChatGPT插件开发**：

### 最佳实践建议

1. **知识库优化**：

   * 使用&#96;txt/csv/pdf&#96;格式文档

   * 添加元数据标签（如：&#96;department:finance&#96;）

   * 设置文档过期时间

2. **安全增强**：

   &#96;&#96;&#96;python
   # 在工具调用前增加权限检查
   def check_permission(session_id):
       return session_id in valid_sessions
   &#96;&#96;&#96;

3. **性能优化**：

   * 启用&#96;LLM缓存&#96;减少重复计算

   * 设置&#96;Rate Limit&#96;: 30 requests/min

   * 使用&#96;异步调用&#96;处理长文本

此模板提供了完整的对话式知识库搜索能力，并通过标准化API支持与其他AI系统（如GPTs、自定义助手等）集成。当知识库更新时，所有连接的系统会自动获得最新知识支持。
