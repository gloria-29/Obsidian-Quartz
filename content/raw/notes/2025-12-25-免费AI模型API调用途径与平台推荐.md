# [稳定但质量不行](https://linux.do/t/topic/1342562#p-11455226-h-1)

1. 硅基流动不必多言

2.GLM 官方 flash 版本

3. 美团 小米（但是审核高不建议）

# [看平台政策综合实力 OK 的](https://linux.do/t/topic/1342562#p-11455226-ok-2)

4. 火山引擎（数据共享计划，每天单模型 2m，可多模型叠加拓展用量，有审查）

5.mistral (官网 free key 1r/s ，刷多几个号搞号池啥的基本没啥限制)

6.[pollinations](https://enter.pollinations.ai/)（每天刷新 1usd，可用 gemini2.5flashlite 或者 3flash 等，当然高级模型全系列也可以用，看用量自行选择即可）（**最推荐自用的一个**）（注意该平台模型名有自己编码，划到网页最下面执行查找）

7.groq ollama cerebras 等

8.opencode 本身也提供免费模型比如 Big Pickle/Grok Code Fast 1/GPT 5 Nano，用量也没咋限制，就是质量不行还慢，gpt5nano 是强制思考模型其实没必要薅

9. 各种公益站的 4omini 或者 4.1mini

10.neo 的 [deeplx](https://linux.do/t/topic/111911)

# [等等党的胜利](https://linux.do/t/topic/1342562#p-11455226-h-3)

nebius 蹲它的兑换码，虽然说最近少很多而且模型还更新慢，但随便个兑换码就 20/50usd，用半年一年应该不是什么问题，且好像不过期

## [综上](https://linux.do/t/topic/1342562#p-11455226-h-4)

白嫖党最推荐 pollinations ，按照官方预估用量**单号**每天 1usd 大概 12k 次 gemini2.5flashlite 调用 ， 1.6k 3flash，当然沉浸式翻译消耗更少估计还能用更多次

这提供个 mistral 号池 API（其实也就论坛里 [hello](https://linux.do/t/topic/1222221) 给的，没能力自己爬主要是）（本服务不担责不担能用和稳定，只作为测试用途，请符合中国相关法律法规进行使用）（理论上并发 300，但是我服务器扛不住）
