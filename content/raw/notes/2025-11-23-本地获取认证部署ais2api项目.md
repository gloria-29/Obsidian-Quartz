# [](https://linux.do/t/topic/1185056#p-10444450-h-1)获取账号认证文件


*原作者：11.20：修复了单账号不会自动重启的 bug。（据说）修复了流数据的报错问题*


原教程作者有新增手机端获取的教程但是风险很大有需要的可以访问[原教程](https://gcn02iwpisfi.feishu.cn/wiki/UMDzwFu0ki3AEfkQ3A7c7bHvnIL)


首先前往： [Releases · daijro/camoufox · GitHub](https://github.com/daijro/camoufox/releases) ，Windows 系统一般应该下载后缀为 win.x86_64.zip 的文件，安装 Git 和 Node.js 还有 docker 这些就不需要过多赘述了。


然后在 Windows 本地获取认证文件需要梯子


- 在你想要保存文件的地方建个文件夹，进去文件夹后，打开 cmd 或者 shell  

获取这个项目 [GitHub - Ellinav/ais2api](https://github.com/Ellinav/ais2api)



&#96;&#96;&#96;
git clone https://github.com/Ellinav/ais2api.git
&#96;&#96;&#96;



- 然后进入 **ais2api** 文件夹建立 camoufox 然后解压之前下载的 camoufox-135.0.1-beta.24-win.x86_64_4.zip  

[![PixPin_2025-11-19_06-43-43](https://linux.do/uploads/default/original/4X/6/6/5/665cbb90a54b4ddfe9a6e5ae63cd009e7e16ed2e.png)](https://linux.do/uploads/default/original/4X/6/6/5/665cbb90a54b4ddfe9a6e5ae63cd009e7e16ed2e.png)  

注意解压过后是这样的  

[![PixPin_2025-11-19_06-44-11](https://linux.do/uploads/default/optimized/4X/b/b/3/bb314d919447f78647ddcd76e119d8f833192d2b_2_690x397.png)](https://linux.do/uploads/default/original/4X/b/b/3/bb314d919447f78647ddcd76e119d8f833192d2b.png)  

再回到 **ais2api** 文件夹 shift 打开 cmd 或者 shell 输入  

[![PixPin_2025-11-19_06-47-16](https://linux.do/uploads/default/optimized/4X/f/c/8/fc8bf86d33ca45459fe96d615bf535582887d814_2_689x500.png)](https://linux.do/uploads/default/original/4X/f/c/8/fc8bf86d33ca45459fe96d615bf535582887d814.png)



&#96;&#96;&#96;
npm install
&#96;&#96;&#96;



可能会转会儿圈耐心等待成功安装过后继续输入


&#96;&#96;&#96;
node save-auth.js
&#96;&#96;&#96;



然后按照界面的提示获取 json 就是了，需要多几个账号？继续在 cmd 输入 &#96;node save-auth.js&#96;，并重复以上步骤即可。


# [](https://linux.do/t/topic/1185056#p-10444450-h-2)部署项目


接下来在 Linux 内进行


- 建立项目文件夹并进去



&#96;&#96;&#96;
mkdir ai2api

cd ai2api
&#96;&#96;&#96;



- 建立认证文件夹



&#96;&#96;&#96;
mkdir -p ./auth
&#96;&#96;&#96;



- 防止没权限



&#96;&#96;&#96;
sudo chown -R 1000:1000 ./auth
&#96;&#96;&#96;



- 去 ai2api 文件夹内建立 docker-compose.yml 文件



&#96;&#96;&#96;
nano docker-compose.yml
&#96;&#96;&#96;



- 粘贴下面的内容



&#96;&#96;&#96;
services:
  ais2api:
    container_name: ais2api
    image: ellinalopez/cloud-studio:latest
    restart: unless-stopped
    ports:
      - &quot;7860:7860&quot;
    env_file:
      - .env
    volumes:
      - ./auth:/app/auth
    # --- 代理配置 ---
    environment:
      - HTTP_PROXY&#61;
      - HTTPS_PROXY&#61;
&#96;&#96;&#96;



- ctrl+x 然后输入 y 回车俩下确认退出
- 建立.env 导入环境变量



&#96;&#96;&#96;
nano .env
&#96;&#96;&#96;



- 根据需求自己修改然后粘贴进去



&#96;&#96;&#96;
# webui访问密钥也是api请求密钥一定要修改！！！
API_KEYS&#61;sk-xxxxxxxxxxxxxxx

# 如果你需要使用.env加载认证信息，删除 # 以去除注释，并填入之前获取的认证文件夹auth里的文件的全部内容！
# AUTH_JSON_1&#61;
# 如果还需要添加更多账号，依此类推增加 AUTH_JSON_2、AUTH_JSON_3

# 以下为可选参数
# （选填）账号使用多少次后切换到下一个账号
SWITCH_ON_USES&#61;40

# （选填）服务器端重试次数1次
MAX_RETRIES&#61;1

# （选填）失败3次后重试
FAILURE_THRESHOLD&#61;3

# （选填）遇到429和503报错立刻切换账号
IMMEDIATE_SWITCH_STATUS_CODES&#61;429,503

# （选填）起始账号，默认是第一个

INITIAL_AUTH_INDEX&#61;null

# 使用假流式
STREAMING_MODE&#61;real

&#96;&#96;&#96;



- 一样的退出方式如果没有去除注释那就继续，把你之前 Windows 获取的文件全部上传到 Linux 服务器 auth 文件夹内下面的地址仅供参考



&#96;&#96;&#96;
scp -r &quot;C:\ais2api\auth&quot; &lt;用户名&gt;@&lt;服务器IP&gt;:/aibu2api/

&#96;&#96;&#96;



*注意这样干的前置要求是服务器和本地都有装 ssh 这个就不多说了，或者你自己想办法上传到服务器 auth 文件夹内文件名称为 auth-x.json 上传过后 &#96;cd auth&#96; 去 &#96;ls&#96; 核对一下*


- 最后 &#96;docker compose up -d&#96; 启动容器，大功告成放行服务器的防火墙和云服务商的安全组去浏览器访问



&gt; 
&gt; 
&gt; &lt;服务器 IP&gt;:7860
&gt; 
&gt; 


- 输入你环境变量文件内地 API_KEYS 即可访问  

*注意接入 api 需要以 gemini 接口访问*
